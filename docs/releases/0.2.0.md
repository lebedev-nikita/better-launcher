# Better Launcher 0.2.0

Stable minor release of current `origin/main` implementation (source: rc.60, commit `483b5407c450574449d1b635e3bab25309ccff86`). Kotlin code, resources, permissions/backup format match rc.60; only version/release documentation changed. Android 12+ (API 31), target API 36, versionCode `70`.

## Changes since 0.1.9

- Home uses full safe height without built-in clock/date/bottom buttons. Swipe up opens search, right opens widgets, hold free space opens Settings; keyboard/accessibility retained.
- Separate left widget page fills safe height without panels. Hold empty space to add; home widget centers immediately below status bar/can fill width.
- Apps/folders/widgets reorder in place via ≡ with autosave/keyboard/accessibility. Dragged content stays over wallpaper.
- Drag widget content to move; four edges resize in 12 dp steps with system CLOCK_TICK. Shared widget/favorites gap adjustable 0–32 dp with live preview.
- Unified navy popup menus with blue labels, outline icons/smooth bottom entry. Name hold manages shortcut; icon hold opens notifications/shortcuts/attached apps. Heading renames.
- Quick actions display app-supplied icons/avatars. Separate cross hides shortcuts only in Better Launcher with immediate undo/restore. State keyed by app/profile/shortcut ID, included in backup version 1.
- Full-width app search finds hidden apps for nonempty queries; Show again restores without confirmation. Alphabet immediately updates when hiding/restoring last section app, reserves system Back space and gives letter-change/release haptics.
- Widget picker has one search field, real previews/result alphabet. Settings covers system bars; swipe-dismissable messages preserve working undo.
