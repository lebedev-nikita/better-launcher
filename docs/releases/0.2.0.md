# Better Launcher 0.2.0

Стабильный минорный выпуск текущей реализации из `origin/main` (исходная версия — 0.2.0-rc.60, коммит `483b5407c450574449d1b635e3bab25309ccff86`). Kotlin-код, ресурсы, разрешения и формат backup совпадают с rc.60; изменены версия и документация выпуска. Android 12+ (API 31), target API 36, versionCode `70`.

## Изменения относительно 0.1.9

- Главный экран использует всю безопасную высоту без встроенных часов, даты и нижних кнопок. Поиск открывается свайпом вверх, виджеты — свайпом вправо, настройки — удержанием свободного места; клавиатурные и accessibility-действия сохранены.
- Отдельная страница виджетов слева занимает всю безопасную высоту без панелей. Добавление — удержанием пустого места; главный виджет центрирован сразу под статус-баром и может занимать всю ширину.
- Приложения, папки и виджеты переставляются прямо на своих экранах через ручку ≡, с автосохранением, клавиатурными и accessibility-действиями. Перетаскиваемое содержимое остаётся на фоне обоев.
- Виджет перемещается за содержимое, а размер редактируется четырьмя границами с шагом 12 dp и системным тактильным CLOCK_TICK. Общий отступ между виджетами и избранным настраивается от 0 до 32 dp с живым предпросмотром.
- Единые тёмно-синие всплывающие меню с голубыми подписями, контурными значками и плавным подъёмом снизу. Удержание названия управляет ярлыком; удержание иконки открывает уведомления, shortcuts и прикреплённые приложения. Переименование доступно в заголовке меню.
- Быстрые действия показывают переданные приложением значки и аватарки. Отдельный крестик скрывает shortcut только в Better Launcher; отмена и восстановление доступны сразу. Скрытие сохраняется по ID приложения, профиля и shortcut и входит в backup версии 1.
- Поиск приложений занимает всю доступную ширину и находит скрытые приложения по непустому запросу; «Показывать снова» возвращает их без подтверждения. Алфавит немедленно обновляется после скрытия или восстановления последнего приложения раздела, сохраняет место для системного Back и даёт тактильный отклик при смене буквы и отпускании.
- Выбор виджета использует одно поле поиска, настоящие превью провайдеров и алфавит результатов. Настройки покрывают также системные панели; всплывающие сообщения закрываются свайпом и сохраняют рабочую отмену.

## Проверки выпуска

- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` и сборка test APK прошли; 15 unit-тестов, 0 ошибок.
- Debug lint: 0 ошибок, 27 существующих предупреждений, как в rc.60; новых предупреждений нет.
- Connected-проверка `SystemTransliterationTest` прошла на выделенных Android 12/API 31 и Android 16/API 36: по 5/5 тестов. После connected-тестов APK переустановлен и назначен HOME.
- Результаты итоговой release-сборки, UI smoke, подписи, размера и SHA-256 записываются в GitHub Release после проверки финального APK из чистого опубликованного коммита `main`.

Исторический полный connected-прогон rc.60: Android 16 — 51/51; Android 12 — 50/51 с тайм-аутом `HomeSurfaceTest`, поэтому тот полный прогон не считается успешным. Отдельный повтор HomeSurfaceTest и обоих тестов shortcuts прошёл на обеих версиях: 3/3. Это результаты rc.60, а не новый полный прогон 0.2.0; подробности сохранены в [его отчёте](0.2.0-rc.60.md).

## APK и ограничения

Публикуются `better-launcher-0.2.0-release.apk` и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег `v0.2.0` указывает на этот коммит. Release использует R8 и удаление неиспользуемых ресурсов, не является debuggable и сохраняет прежний сертификат Android Debug для совместимости обновлений.

Production-сертификат и выпуск в магазине не настроены. Полный паритет Niagara не заявляется; оставшиеся возможности перечислены в [таблице покрытия](../features.md). Физические устройства, все OEM, рабочие профили/Private Space, полный TalkBack и реальные аккаунты Telegram/YouTube RV не проверены. Содержимое shortcuts, уведомлений и сторонних виджетов определяют их приложения.
