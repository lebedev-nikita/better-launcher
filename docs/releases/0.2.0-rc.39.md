# Better Launcher 0.2.0-rc.39

Hidden-app search and restoration through hold menus. Version code: 48; Android 12+ (API 31), target API 36.

## Changes

- Nonempty search finds hidden apps by original name/alias. Empty All apps/alphabet still exclude them.
- Hidden-result long-press menu immediately offers Show again with outline eye icon. Unhides, preserves query/results and does not add to favorites.
- Visible apps retain Hide app under More and undo hiding. Backup format/profile-aware IDs unchanged.
- Preserves main rc.36 transparent favorites dragging, rc.37 populated-only alphabet including # and rc.38 widget search.
