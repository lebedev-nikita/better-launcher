# Better Launcher 0.3.0

Stable minor release adding English localization and English project documentation. Android 12+ (API 31), target API 36, versionCode `71`.

## Changes since 0.2.0

- English is the default interface. Russian remains available and follows the device language. Android 13+ also exposes English and Russian in the system per-app language picker.
- Menus, Settings, search, widget management, weather states, calendar text, messages, backup validation and accessible actions use translated Android resources. Notification, widget-page and hidden-app counts use language-specific plurals.
- Calendar dates follow the active locale and times respect the system 12/24-hour setting. Weather city search requests English or Russian results for the active UI language.
- App names, user aliases, shortcuts, notification content and third-party widgets retain their owner-provided text. Existing settings, profile-aware IDs, local widget IDs and backup format 1 remain compatible.
- All repository Markdown documentation is in English, including historical verification and release notes. GitHub release descriptions are translated while preserving historical results and artifact identifiers. Workflow YAML and CI labels are in English.
- CI checks English/Russian resource coverage and positional formatting. Localization tests cover English, Russian, fallback languages, plurals and actual language changes in the Activity. Home UI tests now wait for keyboard dismissal before injecting the next gesture.

## Verification

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest` passed; all 15 unit tests passed.
- Full `:app:connectedDebugAndroidTest` passed on dedicated Android 12/API 31 and Android 16/API 36: **53/53 each**, no failures or skips. Main APK reinstalled and HOME restored after testing.
- `python3 scripts/check-localization.py` passed: **218 localized entries** (215 strings and 3 plurals) have complete English/Russian coverage and compatible numbered format arguments.
- Debug lint: **0 errors, 28 warnings**. The one new warning is `UnusedAttribute` for `android:localeConfig`, used on API 33+ while minSdk is 31. Android 12 ignores this attribute and follows the system language; the warning is retained without suppression. The other 27 warnings match the existing baseline.
- English Android 12 debug smoke passed portrait, narrow 320 dp/font scale 1.3 and actual landscape 2400×1080. Native Settings screenshots were reviewed.
- Initial instrumentation attempts exposed locale cleanup in the new test and IME readiness in an existing home test. Both test issues were corrected, then full suites passed on both versions. Failed attempts are not counted as successful.
- Final signed-APK build, release lint, six UI smoke runs, signing compatibility, size/content comparison and SHA-256 are recorded in the [GitHub Release](https://github.com/better-launcher/better-launcher/releases/tag/v0.3.0) after checking the APK from clean published `main`.

## APK and limitations

Published assets: `better-launcher-0.3.0-release.apk` and `SHA256SUMS.txt`. The signed APK is built with R8 and resource shrinking from a clean `main` commit already pushed to `origin/main`; `v0.3.0` tags that commit. Debugging is disabled and the previous compatible signing certificate is retained.

Other UI languages fall back to English. The A–Z alphabet and system ICU transliteration retain their existing behavior; complete RTL support is not claimed. A previously saved weather-city label keeps its saved spelling until another city is selected. Provider and user text is not machine-translated. Physical phones, all OEMs, real work profiles/Private Space and full TalkBack remain outside confirmed coverage. Production store signing and store publishing are not configured. Full Niagara parity is not claimed. See [localization](../localization.md) and [feature coverage](../features.md).
