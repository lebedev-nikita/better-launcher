# Better Launcher 0.2.0-rc.54

Живой предпросмотр отступа в настройках. Version code — 63; Android 12+ (API 31), target API 36.

## Изменения

- В «Настройки» → «Внешний вид» → «Отступ между виджетами» добавлен нативный предпросмотр двух виджетов и избранного. Оба промежутка показывают выбранное расстояние в масштабе 1:1 и сразу обновляются при движении ползунка.
- Высота предпросмотра остаётся постоянной при выборе 0–32 dp, поэтому соседние настройки не смещаются. Подписи используют выбранный шрифт и растут с системным размером текста; accessibility получает одну сводку с текущим расстоянием.
- Сохранён единый отступ между виджетами и перед избранным: 8 dp по умолчанию, 0–32 dp с автосохранением. Формат резервной копии и существующие размеры/размещение виджетов не меняются.

## Проверки

Debug assembly, все 15 unit-тестов и debug lint прошли после обновления версии: 0 ошибок, 27 прежних предупреждений, новых нет. `git diff --check` и layout detector прошли без замечаний.

Нативные проверки на выделенных Android 12/API 31 и Android 16/API 36 подтвердили немедленное обновление предпросмотра на 0, 8 и 32 dp и постоянные границы блока. Проверены портрет, 945×2100/font scale 1.3 и горизонтальные окна (2160×1080 на API 31, 2400×1080 на API 36); все шесть debug smoke-сценариев прошли. Размер экрана, масштаб шрифта и ориентация восстановлены. Скриншот для пользователя снят с настоящего Android UI. Локальные материалы: `.impeccable/review/spacing-preview/`.

На текущей версии все 17 выбранных connected-тестов хранения/backup, ползунков, системной транслитерации и отступов hosted widgets прошли на API 31. Итоги полного connected-прогона на API 36, smoke итогового подписанного APK и проверки артефакта фиксируются в GitHub Release; логи остаются локально в `.impeccable/review/spacing-preview-release/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Предпросмотр — схема расстояния, сторонние виджеты сохраняют собственные внутренние отступы. Физический телефон пользователя, Todoist и OEM-особенности не проверены; полный паритет Niagara не заявляется.
