# Better Launcher 0.2.0-rc.49

Прозрачный фон при перетаскивании виджетов. Version code — 58; Android 12+ (API 31), target API 36.

## Изменения

- При захвате и перетаскивании виджета за ≡ больше не появляется тёмно-синий прямоугольник вокруг содержимого и ручки. Строка остаётся прозрачной поверх обоев, как при перестановке избранного.
- Сохраняются фон самого провайдера, подъём перетаскиваемого виджета над соседними, перестановка, отмена, прокрутка у края и автосохранение. Widget IDs, привязка главного виджета, размеры, профили и формат backup не меняются.
- Регрессионная проверка захватывает и перемещает настоящий AppWidgetHostView, проверяет прозрачность строки и сохранение оформления провайдера; отмена сохраняет прежний порядок и сбрасывает смещение/подъём.

## Проверки

На исходной реализации тест воспроизвёл непрозрачную заливку внешней строки: ожидаемая alpha 0, фактическая 255. Причина — страница виджетов использовала непрозрачный цвет редактора порядка по умолчанию; теперь она передаёт прозрачный цвет, как избранное.

Debug assembly, все 15 unit-тестов и debug lint прошли: 0 ошибок, 27 прежних предупреждений, новых нет. Результаты проверок на Android 12/API 31 и Android 16/API 36, smoke в портрете, узком окне/font scale 1.3 и landscape, release lint и характеристики итогового APK приведены в GitHub Release. Локальные логи и native-снимки: `.impeccable/review/widget-drag/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Сертификат совместим с предыдущими выпусками. Размер, состав и SHA-256 проверяются перед публикацией и записываются в GitHub Release.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон пользователя и его сторонние провайдеры не проверены; на эмуляторах используется тестовый RemoteViews-провайдер. Полный паритет Niagara, OEM и полный TalkBack-сеанс не заявляются.
