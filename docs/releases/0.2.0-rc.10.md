# Better Launcher 0.2.0-rc.10

Релиз-кандидат на основе main `9a72394`, включая превью виджетов. Исправлено открытие меню долгого удержания приложения: под ним больше не появляется временный отступ с последующим сдвигом вниз.

## Изменения

- Окно меню имеет фиксированный размер от первого показа до закрытия. Меню прижато к нижнему краю внутри этого окна; его фон доходит до системной навигации.
- Сохранены выезд снизу, системное отключение анимаций, отступы для панелей и вырезов, прокрутка и ограничение высоты 85% экрана.
- «Дополнительно» раскрывается на месте. Нажатие на заголовок переименовывает приложение; Back, HOME и нажатие снаружи закрывают меню.
- Сохранены настройки, резервные копии, экран виджетов, превью при выборе виджета и исправления алфавита из main.

## Установка

Скачайте `better-launcher-0.2.0-rc.10-release.apk` и установите поверх предыдущего выпуска без удаления приложения. Минимальная версия — Android 12 (API 31), targetSdk — 36, versionCode — 19. `SHA256SUMS.txt` содержит SHA-256 APK.

Публикуется подписанный release APK с R8 и удалением неиспользуемых ресурсов; отладка отключена. Прежний сертификат Android Debug сохранён для совместимости обновлений. Выпуск отмечен как prerelease; стабильный релиз не заменяется.

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest :app:assembleRelease :app:lintRelease` — успешно после включения main `9a72394`. 4 unit-теста, 0 ошибок; debug/release lint: 27 прежних предупреждений, новых нет.
- `apksigner verify` подтвердил подпись v2; SHA-256 сертификата совпадает с опубликованным rc.4 (`7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`). Manifest: versionCode 19, minSdk 31, targetSdk 36, отладка отключена.
- APK: 2 425 672 байта, на 9 276 байт больше rc.4. Набор ZIP entries совпадает; DEX вырос на 9 256 байт из-за включённого кода превью виджетов и контейнера меню. Отдельной ICU4J в APK нет.
- SHA-256 APK: `f22ab83cf03587baa2376650195cffc5d5cef321227b03ae8f367aea76f04310`.
- Добавлен connected-тест `menuStaysAtScreenBottomThroughoutArrival`: он отслеживает нижнюю границу на кадрах открытия, исключая намеренный выезд содержимого, и учитывает отключённые системные анимации.

Итог connected-прогона — 0 выполненных тестов и отказ установки: `Can't find service: package`. Успешный connected-прогон и исправление на физическом телефоне не подтверждены.

Итоговый release APK установился на выделенный Android 16 (`emulator-5646`). Полный `scripts/smoke-test.py` прервался на первом HOME-шаге: UI Automator завершился с кодом 137. Повторная попытка короткого instrumentation-теста не запустилась после перезапуска системы: `Broken pipe`, затем исчезли сервисы `package` и `activity`. Повторная установка release APK и назначение HOME также не прошли из-за этих системных ошибок. Успешные UI-прогоны на Android 12/16, покадровое воспроизведение исходного дефекта, узкий экран/font scale 1.3, landscape и левосторонний режим в этой проверке не подтверждены. Эмуляторы остановлены; тестовые скрипты с временными размерами и ориентацией не запускались. Кандидат предназначен для дальнейшей проверки меню на устройстве.
