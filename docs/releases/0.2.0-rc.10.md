# Better Launcher 0.2.0-rc.10

Candidate based on main `9a72394`, including widget previews. Fixes a temporary bottom gap and subsequent downward shift when opening the app long-press menu.

## Changes

- Menu window has a fixed size from first display to dismissal. The menu anchors to its bottom; background extends to system navigation.
- Preserves bottom entry, system animation disabling, bar/cutout insets, scrolling and the 85% screen-height limit.
- More expands in place. Heading taps rename the app; Back, HOME and outside taps dismiss.
- Preserves main's settings, backups, widget screen, picker previews and alphabet fixes.

## Installation

Download `better-launcher-0.2.0-rc.10-release.apk` and update without uninstalling. Minimum: Android 12 (API 31), targetSdk: 36, versionCode: 19. `SHA256SUMS.txt` contains the APK SHA-256.

Signed release APK with R8/unused-resource removal, debugging disabled. Previous Android Debug certificate retained for compatibility. Marked prerelease; stable release is not replaced.
