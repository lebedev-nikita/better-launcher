# Better Launcher 0.2.0-rc.25

Short vibration feedback for grid-based widget resizing. Version code: 34; Android 12+ (API 31), target API 36.

## Changes

- Every actual width/height change through four edges requests a short system `CLOCK_TICK`, matching the alphabet index. Keyboard/accessibility resizing also gives feedback.
- Repeated events in the same 12 dp step or attempts beyond provider/window limits give no extra ticks. Release ticks only when applying a new size; cancellation restores geometry silently. Moving widgets remains silent.
- Respects Android haptic settings. No additional permission/app setting.
