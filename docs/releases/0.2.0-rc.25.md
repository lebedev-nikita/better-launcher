# Better Launcher 0.2.0-rc.25

Короткий виброотклик при изменении размера виджета по сетке. Version code — 34; Android 12+ (API 31), target API 36.

## Изменения

- Каждое фактическое изменение ширины или высоты четырьмя границами сопровождается коротким системным `CLOCK_TICK`, таким же, как у буквенного индекса. Отклик работает и при изменении размера с клавиатуры или через accessibility.
- Повторные события внутри того же шага сетки 12 dp и попытки выйти за ограничения провайдера/окна не дают лишних тиков. Отпускание даёт тик только если применяет новый размер; отмена восстанавливает исходную геометрию без дополнительного отклика. Простое перемещение виджета остаётся тихим.
- Учитываются системные настройки тактильного отклика Android. Дополнительное разрешение или настройка приложения не требуется.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 13 unit-тестов, lint — 0 ошибок и 27 существующих предупреждений, новых нет.

Все 28 инструментальных тестов прошли на выделенном Android 16/API 36. Полный `:app:connectedDebugAndroidTest` на Android 12/API 31 завершился с 25 успешными тестами и тремя сбоями: таймаут переименования в AppMenuTest, таймаут завершения Activity в FavoritesOrderTest и ошибка Android Activity client record при запуске WidgetResizeHapticTest. Повторы двух первых классов (3 теста) и нового теста (1 тест) отдельно прошли без изменения исходников. Полный повтор API 31 не выполнялся.

Новый WidgetResizeHapticTest проверяет точный тип и число запросов отклика для всех четырёх границ, повторных координат внутри шага, следующего шага и возврата, отпускания с/без нового размера, отмены и второго пальца, пределов, клавиатуры и accessibility. Перемещение за содержимое и его доступные альтернативы не создают виброотклик. Реальный AppWidgetHost, обновления RemoteViews и сохранение размеров проверены существующим WidgetHostTest на обеих версиях Android.

`python3 scripts/smoke-test.py --serial …` прошёл на debug APK отдельно на Android 12 и Android 16. Первый API 31 smoke остановился из-за отсутствия Phone в избранном: сбой предыдущего теста оставил тестовую папку. После восстановления исходных настроек выделенного эмулятора повтор прошёл полностью.

Нативный AppWidgetHost и редактор проверены на обеих версиях в портрете 1080×2400, на узком экране 945×2100/font scale 1.3 и в landscape 2400×1080: изменения ширины/высоты по сетке, Done, Back и HOME. Исходная попытка поворота API 31 дала портретный кадр; сценарий повторён с явной блокировкой поворота и проверкой размеров PNG. Снимки просмотрены. После проверки восстановлены размер, font scale и ориентация, удалён тестовый виджет и отозвано тестовое разрешение привязки. Логи и снимки сохранены локально в `.impeccable/review/rc25/` изолированной рабочей копии.

Подписанный release APK установлен поверх debug APK с сохранением данных на обеих версиях Android; полные smoke-сценарии также прошли отдельно на Android 12 и Android 16, без аварий лаунчера.

## APK и ограничения

Подписанный release APK с R8 и удалением неиспользуемых ресурсов собирается из чистого main, уже опубликованного в origin/main; публикуются APK и SHA256SUMS.txt. Подпись v2 проверена; SHA-256 сертификата совпадает с rc.24. `apkanalyzer manifest debuggable` возвращает `false`; версия APK — 0.2.0-rc.25/code 34. `:app:lintRelease` — 0 ошибок, 27 существующих предупреждений. Размер — 2 486 238 байт, на 76 байт больше rc.24; состав ZIP не изменился, прирост связан с DEX и профилем оптимизации. Используется прежний сертификат для совместимого обновления. Production-сертификат и магазин не настроены.

Проверки эмулятора подтверждают запрос нативного тактильного отклика, а не ощущение вибрации на физическом телефоне. Физические устройства/OEM, рабочие профили и полный TalkBack остаются вне подтверждённого покрытия. Полный паритет Niagara не заявляется.
