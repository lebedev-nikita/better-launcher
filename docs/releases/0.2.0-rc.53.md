# Better Launcher 0.2.0-rc.53

Единый настраиваемый отступ между виджетами и перед избранным. Version code — 62; Android 12+ (API 31), target API 36.

## Изменения

- Отступ между виджетами на отдельной странице и между верхним содержимым главного экрана и избранным теперь одинаковый: 8 dp по умолчанию вместо 24 dp на странице и 18/30 dp перед избранным.
- «Настройки» → «Внешний вид» → «Отступ между виджетами» регулирует его от 0 до 32 dp с шагом 1 dp. Значение сохраняется сразу; ползунок поддерживает клавиатуру и accessibility. Одинаковое расстояние применяется в коротком окне, landscape и левостороннем режиме, а также между погодой, виджетом и медиастрокой.
- Режим перестановки использует эту же настройку рядом с существующими ручками. Внутренние отступы стороннего виджета и сохранённое перемещение/размер остаются частью его геометрии.
- Настройка входит в резервную копию формата 1. Старые файлы без ключа используют 8 dp; неверные типы и значения вне диапазона отклоняются до записи. Локальные widget IDs, выбор главного виджета и размеры сохраняются при импорте.

## Проверки

Debug assembly, все 15 unit-тестов и debug lint прошли: 0 ошибок, 27 прежних предупреждений, новых нет. `git diff --check` и layout detector прошли без замечаний. Локальные логи, снимки и результаты: `.impeccable/review/widget-spacing/`.

На выделенном Android 12/API 31 прошли 17 выбранных инструментальных тестов: хранение/backup, клавиатура/accessibility ползунков, системная транслитерация и реальные hosted widgets. На Android 16/API 36 первый полный connected-прогон прошёл 44/45: проверка Back/IME в редакторе имени приложения завершилась ошибкой. Отдельный повтор всех 20 выбранных тестов, включая весь AppMenuTest, прошёл без изменения кода приложения. Повторный полный `:app:connectedDebugAndroidTest` на API 36 прошёл все 45/45 тестов без ошибок и пропусков.

Native-проверка и геометрические утверждения подтвердили одинаковые отступы 0, 8 и 32 dp на главном экране и странице виджетов при обеих сторонах алфавита. Проверены портрет, 945×2100/font scale 1.3 и настоящие горизонтальные окна (2160×1080 на API 31, 2400×1080 на API 36), перенос текста настройки и независимый footer. Проверки ползунка подтверждают сохранение после пересоздания Activity и атомарный отказ некорректного импорта. Итоги smoke подписанного APK и проверки артефакта фиксируются в GitHub Release.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256; результаты приводятся в GitHub Release.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Виджеты проверены с native тестовым провайдером, который отсутствует в release APK. Физический телефон пользователя, Todoist, погодный провайдер со скриншота и OEM-особенности не проверены. Полный паритет Niagara не заявляется.
