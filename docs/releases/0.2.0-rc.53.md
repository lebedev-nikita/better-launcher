## Changes

- Widget-page gaps and home top-content/favorites gap now match: default 8 dp instead of 24 dp on page and 18/30 dp before favorites.
- Settings → Appearance → Widget spacing adjusts 0–32 dp in 1 dp steps, autosaved with keyboard/accessibility slider support. Same distance in short windows/landscape/left-handed mode and between weather/widget/media row.
- Ordering uses same spacing beside existing handles. Provider internal padding/saved movement/size remain widget geometry.
- Backup format 1 includes setting. Old files without key use 8 dp; invalid types/out-of-range values rejected before writing. Local IDs/home selection/sizes preserved during import.
