# Better Launcher 0.2.0-rc.23

Haptic feedback on alphabet-index release. Version code: 32; Android 12+ (API 31), target API 36.

## Changes

- Releasing an active index gesture requests one short `CLOCK_TICK`, the same system feedback as letter changes. Applies even on the current letter without repeating section navigation.
- Release below letters still selects final # without the last MOVE. Completion gives one tick, avoiding double vibration from selecting #.
- Cancellation, late release after cancellation and touches outside the index give no release feedback. Android haptic settings remain effective. Shared component used on home, app list and widget picker.
