# Better Launcher 0.2.0-rc.23

Тактильный отклик при отпускании буквенного индекса. Version code — 32; Android 12+ (API 31), target API 36.

## Изменения

- При отпускании пальца после активного жеста по индексу происходит один короткий `CLOCK_TICK` — тот же системный отклик, что при смене буквы. Он срабатывает и при отпускании на текущей букве, без повторного перехода к разделу.
- При отпускании ниже букв сохраняется переход к заключительному «#», даже если последнего MOVE не было. Завершение жеста даёт один тик, без двойной вибрации из-за выбора «#».
- Отмена жеста, позднее отпускание после отмены и касания вне индекса не вызывают отклик отпускания. Настройки тактильного отклика Android сохраняют действие. Общий компонент применяется на главном экране, в списке приложений и выборе виджетов.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 10 unit-тестов; lint — 0 ошибок, 27 существующих предупреждений, новых нет относительно исходного rc.22.

Новый `AlphabetHapticTest` сначала воспроизвёл отсутствие отклика при отпускании, затем прошёл с исправлением. В тестовом подклассе View фиксируются запросы тактильного отклика: смена и сохранение буквы, повторное касание, обе стороны индекса, «#» с последним MOVE и без него, отмена и отпускание без активного жеста.

На Android 12/API 31 первый полный инструментальный прогон выполнил 27 тестов: 26 прошли, один существующий сценарий переименования приложения (`AppMenuTest.titleRenamesAppAndEmptyNameRestoresOriginalLabel`) остановился по тайм-ауту ожидания UI. Его отдельный повтор прошёл без изменения исходников. Все проверки индекса прошли.

На Android 16/API 36 прошли все 4 инструментальных теста `AlphabetHapticTest`, `AlphabetBoundsTest` и `AppNavigationTest`: тот же отклик отпускания, сохранение навигации, заключительный раздел и переиспользование строк списка. Полный набор остальных инструментальных тестов на API 36 в этом кандидате не запускался.

`python3 scripts/smoke-test.py --serial …` — успешно на подписанном release APK отдельно на Android 12 и Android 16, без аварий лаунчера. На Android 12 также прошёл debug smoke.

Нативный UI проверен на обеих версиях в портрете 1080×2400, на узком экране 945×2100 с font scale 1.3 и в landscape 2400×1080: индекс остаётся над footer, выбор разделов и отпускание ниже букв, поиск/IME, настройки, Back/HOME. На API 31 проверки геометрии выполнены на debug APK, на API 36 — на подписанном release APK. Снимки проверены визуально; размер, масштаб, режим принудительного поворота и ориентация восстановлены. Captures и логи сохраняются локально в `.impeccable/review/rc23/`.

## APK и ограничения

Публикуется подписанный release APK с R8 и удалением неиспользуемых ресурсов, собранный из чистого коммита `main`, уже опубликованного в `origin/main`, а также `SHA256SUMS.txt`. `assembleRelease` и `lintRelease` прошли; lint — 0 ошибок и 27 прежних предупреждений. APK не debuggable. Размер — 2 482 202 байта, на 4 байта больше rc.22; состав файлов архива не изменился. Сертификат прежних выпусков Android Debug сохраняется для совместимости обновлений; отдельный production-сертификат и выпуск в магазине не настроены.

Инструментальный тест проверяет тип и количество запросов системного тактильного отклика. Физическое ощущение вибрации на телефоне/OEM не проверено: оно зависит от оборудования и настроек Android. Полный паритет Niagara, все OEM, рабочие профили и TalkBack целиком не подтверждены.
