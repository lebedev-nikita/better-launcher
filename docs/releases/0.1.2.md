# Better Launcher 0.1.2

Fixes delays when opening All apps and moving through the home-screen alphabet.

## Fixes

- The list creates only visible rows and reuses them during scrolling and letter selection.
- App names and order are prepared in advance; search no longer sorts the entire catalog for every query.
- Movement within the same letter still updates the wave, but does not repeat navigation or keyboard commands.
- Section navigation runs directly, without queued deferred scrolls. Deferred keyboard opening is canceled when selecting a letter or returning HOME.
- Search accounts for renaming, hiding and restoring apps after index updates.

## Installation

Download `better-launcher-0.1.2-debug.apk` from this release and install it over 0.1.1 or 0.1.0. Its signature matches the first release APK; settings survive a normal update. Minimum version: Android 12 (API 31), versionCode: 3. `SHA256SUMS.txt` contains the APK SHA-256.

The APK uses the previous debug key. Permanent production signing and store publishing are not configured.

## Verification and limitations

The build, 5 unit tests and 5 connected tests pass. UI was checked on Android 12 and Android 16 in portrait, on a narrow screen with font scale 1.3, and in landscape; Android 12 also covered the left alphabet. Lint: 0 errors, 27 existing warnings, no new warnings.

Diagnosis, measurements and checks: [smoothness verification](https://github.com/better-launcher/better-launcher/blob/v0.1.2/docs/app-navigation-verification.md). Current features and remaining work: [features.md](https://github.com/better-launcher/better-launcher/blob/v0.1.2/docs/features.md).

Optimization was checked on phone emulators; smoothness on a physical phone and work-profile behavior have not been independently confirmed. Full Niagara parity is not claimed.
