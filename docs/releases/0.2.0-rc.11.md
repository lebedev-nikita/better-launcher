# Better Launcher 0.2.0-rc.11

Release candidate fixing third-party widget loading.

## Fix

Some RemoteViews commands produced Android's standard Couldn't add widget message. The Activity's AppCompat/Material factory replaced standard TextView with MaterialTextView, whose overridden methods cannot be invoked by RemoteViews. Reproduced on Android 12 with a real AppWidgetHost: `MaterialTextView can't use method with RemoteViews: setBackgroundResource(int)`.

Added widgets and static previews now receive a separate framework context with the current window configuration. External providers use standard Android Views; font scale, density and orientation are respected. Binding, external configuration, AppWidgetHost ID 1201, saved widget IDs and placement remain. Already-added widgets are fixed after updating without re-adding them.

Regression checks real provider content, RemoteViews styling commands, live updates and transfer between widgets/home. The test provider exists only in the androidTest APK.

## Installation

Update with `better-launcher-0.2.0-rc.11-release.apk` without uninstalling. versionCode: 20, minSdk: 31, targetSdk: 36. Preview release; stable remains separate.

## Limitations

Final Android 12 release APK narrow/font scale 1.3 and landscape remain unverified: after successful smoke the dedicated emulator stopped; test-provider reinstall returned `device not found`. Android 16 passed these modes.

RemoteViews conflict reproduced with a test third-party provider. The photographed physical phone's specific ChatGPT/Todoist versions were not checked; all OEM providers, work profiles, Private Space and full TalkBack coverage are unconfirmed. Full Niagara parity is not claimed.
