# Better Launcher 0.2.0-rc.11

Релиз-кандидат с исправлением загрузки сторонних виджетов.

## Исправление

Некоторые команды RemoteViews приводили к стандартному сообщению Android «Не удалось добавить виджет». Причина — фабрика AppCompat/Material из Activity заменяла стандартный TextView на MaterialTextView, чьи переопределённые методы не разрешены для вызова из RemoteViews. Ошибка воспроизведена на Android 12 с настоящим AppWidgetHost: `MaterialTextView can't use method with RemoteViews: setBackgroundResource(int)`.

Добавленные виджеты и статические превью теперь получают отдельный framework-контекст с конфигурацией текущего окна. Внешний провайдер использует стандартные Android Views; масштаб шрифта, плотность и ориентация учитываются. Привязка, внешний экран конфигурации, AppWidgetHost ID 1201, сохранённые widget IDs и размещение сохраняются. Исправление применяется и к уже добавленным виджетам после обновления, без повторного добавления.

Регрессионный тест проверяет содержимое настоящего провайдера, команды оформления RemoteViews, живые обновления и перенос между страницей виджетов и главным экраном. Тестовый провайдер находится только в androidTest APK.

## Установка

Установите `better-launcher-0.2.0-rc.11-release.apk` поверх предыдущей версии, без удаления приложения. versionCode — 20, minSdk — 31, targetSdk — 36. Это предварительный выпуск; стабильный релиз сохраняется отдельно.

## Проверки и APK

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно; 4 unit-теста, 0 ошибок. Debug/release lint: 0 ошибок, 27 существующих предупреждений, новых нет.
- `ANDROID_SERIAL=emulator-5660 ./gradlew :app:connectedDebugAndroidTest` — итоговый прогон: 20 тестов, 0 ошибок на выделенном Android 12. Проверены хранение, backup, каталог, навигация, меню, выбор/превью и реальные обновления виджета. На Android 16 (`emulator-5662`) отдельно прошли тесты выбора/превью и обновления/переноса; последняя проверка обновлений привязана к конкретному widget ID.
- На подписанном release APK все сценарии `scripts/smoke-test.py` прошли на Android 12 и Android 16: настройки, поиск, Camera, меню Phone, переименование, алфавит, свайпы, Back и HOME. Аварий Better Launcher в этих финальных прогонах нет.
- На release APK Android 16 пройдены системная привязка тестового провайдера, перенос на главный экран и обратно, удаление, портрет, узкий экран 320dp с font scale 1.3 и landscape. Провайдер загружается без ошибки, отдельный footer доступен. Снимки проверены в локальной `.impeccable/review/widget-fix-api36/`; размер, font scale и ориентация восстановлены.
- Обновление опубликованного 0.2.0-rc.4 до кандидата через `adb install -r` прошло на Android 12. SharedPreferences до и после установки совпадают побайтно; удаление приложения при обновлении не выполнялось.
- `apksigner verify` подтвердил подпись и совпадение сертификата с опубликованными 0.1.9 и 0.2.0-rc.4: SHA-256 сертификата `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Сохранён прежний сертификат Android Debug для совместимости обновлений; APK собран как release, отладка отключена, R8 и shrinking ресурсов включены.

APK: 2 425 504 байта, 719 ZIP-записей, один classes.dex. Прирост относительно опубликованного 0.1.9 — 144 байта; новых assets и зависимостей нет. Тестовые провайдеры в основной APK не включены.

SHA-256: `675db1b070f5a215c3706f389970a91b8bd070c499d0e6a5aa37bc6544f56e6b`. Тот же хеш опубликован в `SHA256SUMS.txt`.

Предварительные прогоны не были зелёными: эмуляторы показывали ANR системных процессов, а после connected-установки Android сбрасывал HOME. Первый полный прогон завершился 16/20, следующий — 19/20 с тайм-аутом меню. После восстановления HOME и активного главного экрана полный connected-прогон прошёл 20/20; тест меню также прошёл отдельно. Первый smoke-прогон Android 16 не получил свежую accessibility-иерархию; повторный прошёл полностью. Эти неуспешные попытки не подменяются итоговыми результатами.

## Ограничения

Финальный release APK в узком экране/font scale 1.3 и landscape на Android 12 не проверен: после успешного smoke-прогона выделенный эмулятор прекратил работу, повторная установка тестового провайдера вернула `device not found`. Соответствующие режимы успешно проверены на Android 16.

Конфликт RemoteViews воспроизведён тестовым сторонним провайдером. Конкретные версии ChatGPT и Todoist с фотографии на физическом телефоне не проверены; совместимость всех OEM-провайдеров, рабочих профилей, Private Space и полная проверка TalkBack не подтверждены. Полный паритет Niagara не заявляется.
