# Better Launcher 0.1.3

Патч-релиз алфавитной навигации для Android 12+.

## Изменения

- Сохранены последние изменения main: отдельный экран виджетов слева и один виджет на главном экране.
- Боковой ряд содержит только латинские A–Z, звёздочку избранного и заключительный «#».
- Кириллические названия распределяются по первой латинской букве транслитерации [ICU4J](https://unicode-org.github.io/icu/userguide/icu4j/): Яндекс → Yandeks → Y, Юла → Yula → Y, Журнал → Zhurnal → Z, Банк → Bank → B.
- Цифры, символы и буквы без латинской транслитерации (например, Ь и Ъ) открываются через «#» в конце списка.
- В горизонтальном режиме ряд учитывает боковые системные панели, чтобы «#» и буквы не перекрывались кнопками Android.
- В коротком окне и горизонтальном режиме показываются доступные латинские группы; «#» остаётся последним.
- UI smoke-скрипт ожидает свежее дерево интерфейса и вводит поисковый запрос посимвольно, чтобы перегруженный эмулятор успевал обработать ввод.

## Установка

Скачайте `better-launcher-0.1.3-debug.apk` и установите поверх 0.1.0–0.1.2. Подпись совпадает с APK первого выпуска; настройки сохраняются. Затем при необходимости назначьте Better Launcher домашним экраном в настройках Android.

APK подписан отладочным ключом и предназначен для тестирования. `SHA256SUMS.txt` содержит SHA-256 опубликованного файла. Production-подпись и выпуск в магазине пока не настроены.

## Проверки и ограничения

Сборка, 9 unit-тестов и lint прошли; новых lint-предупреждений нет. Группировка проверена шестью интеграционными тестами на Android 12 до объединения с экраном виджетов. Полный UI-прогон итогового APK и Android 16 не подтверждены: выделенные эмуляторы зависали и перезапускали системные службы.

Результаты проверки патча приведены в [отчёте 0.1.3](https://github.com/better-launcher/better-launcher/blob/v0.1.3/docs/verification-0.1.3.md).

Проверка на физических устройствах, рабочих профилях и с TalkBack не выполнена. Полный паритет Niagara пока не достигнут; оставшиеся функции перечислены в [покрытии возможностей](https://github.com/better-launcher/better-launcher/blob/v0.1.3/docs/features.md). [Отчёт 0.1.0](https://github.com/better-launcher/better-launcher/blob/v0.1.0/docs/verification.md) сохранён как история первого выпуска.
