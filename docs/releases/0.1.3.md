# Better Launcher 0.1.3

Alphabet-navigation patch release for Android 12+.

## Changes

- Preserves the latest main changes: a separate widget screen on the left and one home-screen widget.
- The side rail contains only Latin A–Z, a favorites star and a final “#”.
- Cyrillic names are grouped by the first Latin letter of their [ICU4J](https://unicode-org.github.io/icu/userguide/icu4j/) transliteration: Яндекс → Yandeks → Y, Юла → Yula → Y, Журнал → Zhurnal → Z, Банк → Bank → B.
- Numbers, symbols and letters without Latin transliteration (such as Ь and Ъ) open through “#” at the end of the list.
- In landscape the rail accounts for side system bars so Android buttons do not overlap letters or “#”.
- Short windows and landscape show available Latin groups; “#” remains last.
- The UI smoke script waits for a fresh UI tree and types the search query character by character so an overloaded emulator can process input.

## Installation

Download `better-launcher-0.1.3-debug.apk` and install over 0.1.0–0.1.2. The signature matches the first release APK; settings are preserved. If needed, select Better Launcher as the home app in Android settings.

The APK is signed with a debug key and intended for testing. `SHA256SUMS.txt` contains the published file's SHA-256. Production signing and store distribution are not configured yet.

## Verification and limitations

The build, 9 unit tests and lint passed; no new lint warnings. Six integration tests verified grouping on Android 12 before merging the widget screen. A full UI run of the final APK and Android 16 checks are unconfirmed: dedicated emulators froze and restarted system services.

Patch verification results are in the [0.1.3 report](https://github.com/better-launcher/better-launcher/blob/v0.1.3/docs/verification-0.1.3.md).

Physical devices, work profiles and TalkBack were not checked. Full Niagara parity has not been reached; remaining features are listed in [feature coverage](https://github.com/better-launcher/better-launcher/blob/v0.1.3/docs/features.md). The [0.1.0 report](https://github.com/better-launcher/better-launcher/blob/v0.1.0/docs/verification.md) is retained as first-release history.
