# Better Launcher 0.2.0-rc.58

## Изменения

- Из меню долгого удержания названия приложения удалены «Уведомления и быстрые действия» и «Приложения во всплывающем меню».
- Избранное и «Изменить порядок» остаются наверху. Нижние действия приложения расположены в порядке «Скрыть приложение» → «Удалить приложение» → «О приложении». Настройки Better Launcher остаются под разделителем.
- У скрытых результатов поиска сохраняется «Показывать снова» наверху; повторного скрытия нет. Уведомления, shortcuts и прикреплённые приложения открываются удержанием иконки, выбор прикреплённых приложений — через «Добавить приложения» внутри этого меню.
- Сохранены оформление, анимация, прокрутка, переименование нажатием на заголовок, клавиатура, accessibility и закрытие через Back/HOME. Проверки меню и smoke обновлены для нового состава и порядка.

## Проверки

Debug APK, 15 unit-тестов и lint прошли. Lint: 0 ошибок, 27 прежних предупреждений, новых нет.

Полный повторный инструментальный прогон Android 12/API 31 прошёл: 47/47 тестов. Первый прогон прошёл 45/47: новое ожидание меню захватывало скрытое поле переименования, а прежний HomeSurfaceTest завершился таймаутом после свайпа поиска. Обход теста меню исправлен для видимых действий; повторный полный прогон прошёл без изменения рабочего кода навигации. Нативный снимок и портретный smoke Android 16/API 36 подтвердили порядок меню.

Результаты остальных проверок Android 16/API 36 и smoke итогового подписанного APK в портрете, узком окне/font scale 1.3 и landscape на обеих версиях фиксируются в GitHub Release. Проверки подписи, состава, размера и SHA-256 фиксируются в GitHub Release.

## APK и ограничения

Версия: `0.2.0-rc.58`, versionCode `67`. Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон пользователя и приложение со скриншота не проверены. Полная проверка TalkBack, OEM и рабочих профилей не выполнена; полный паритет Niagara не подтверждён.
