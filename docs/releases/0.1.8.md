# Better Launcher 0.1.8

Fixes the alphabet slider's lower boundary: releasing below the letters keeps the list at its last available section.

## Fixes

- Release uses the final finger coordinate even if the last `MOVE` was not delivered. The slider selects the final `#`; without matching apps, the list remains at the last letter section.
- A canceled gesture does not resume navigation from a late release event.
- Preserves A–Z followed by `#`, short-window behavior and Cyrillic transliteration. In 0.1.2 the old `#` order sent the list to the start; the concurrently published 0.1.3 already corrected that order.
- Adds an end-to-end touch → index → adapter → visible-row regression: 16 combinations of numbers/symbols, full/short alphabet, side and presence of the last `MOVE`, plus gesture cancellation. Smoke checks release below the letters and that Camera does not reappear at the list start.

## Installation

Download `better-launcher-0.1.8-release.apk` and install over 0.1.7. Signing matches the previous published APK; normal updates preserve settings. Minimum: Android 12 (API 31), versionCode: 11, targetSdk: 36. `SHA256SUMS.txt` contains the APK SHA-256.

This release APK enables R8 and unused-resource removal and disables debugging. System Android ICU and the smaller APK from 0.1.7 are retained. The previous certificate remains for upgrade compatibility; a separate production certificate and store publishing are not configured.
