# Better Launcher 0.1.8

Патч нижней границы алфавитного ползунка: отпускание пальца ниже букв оставляет список у последнего доступного раздела.

## Исправления

- При отпускании ниже алфавита учитывается конечная координата пальца, даже если последний `MOVE` не был доставлен. Ползунок выбирает заключительный `#`; при отсутствии таких приложений список остаётся у последнего буквенного раздела.
- Отменённый жест не возобновляет навигацию от позднего события отпускания.
- Сохраняется порядок A–Z и затем `#`, включая короткие окна и транслитерацию кириллицы из предыдущих патчей. В 0.1.2 прежний порядок `#` направлял список в начало; этот порядок уже исправлен в параллельно опубликованной 0.1.3.
- Добавлена регрессия полного пути от touch-событий через индекс и адаптер до видимых строк списка: 16 сочетаний цифр/символов, полного/короткого алфавита, стороны и наличия последнего `MOVE`, плюс отмена жеста. Smoke-скрипт проверяет отпускание ниже букв и отсутствие возврата Camera в начало списка.

## Установка

Скачайте `better-launcher-0.1.8-release.apk` из файлов релиза и установите поверх 0.1.7. Подпись совпадает с предыдущим опубликованным APK; настройки сохраняются при обычном обновлении. Минимальная версия — Android 12 (API 31), versionCode — 11, targetSdk — 36. `SHA256SUMS.txt` содержит SHA-256 APK.

Публикуется release APK с R8 и удалением неиспользуемых ресурсов, без отладки. Системная Android ICU и уменьшенный APK из 0.1.7 сохранены. Для совместимости обновлений используется прежний сертификат; переход на отдельный production-сертификат и публикация в магазине пока не настроены.

- Android 12 (API 31): все 17 connected-тестов прошли на выделенном эмуляторе. После тестов основной APK переустановлен, HOME назначен.
- Android 12: обновление опубликованной 0.1.7 до итогового release APK 0.1.8 выполнено через `adb install -r` без удаления; отображаемое избранное и его порядок совпадают.
