# Better Launcher 0.2.0-rc.21

Объединённый релиз-кандидат из `main`: все ранее невлитые локальные ветки и ветки `origin` входят в историю основной ветки. Version code — 30; Android 12+ (API 31), target API 36.

## Изменения

- Нижняя панель снова содержит только три симметричных значка: поиск, виджеты и настройки. Надписи «Все приложения» нет; доступное название поиска сохранено.
- Крупные буквы алфавита: 16sp, шаг 22dp с адаптацией к высоте и системному шрифту. Показаны только заполненные A–Z; ★ и заключительный # остаются навигационными пунктами. Алфавит сохраняет положение при открытии списка, учитывает footer, IME и системный Back.
- Меню приложения сохраняет исправленную анимацию без нижнего зазора. Переименование происходит в том же меню, «Сохранить» выровнено справа, поле остаётся доступным над клавиатурой.
- Сортировка приложений и папок избранного перетаскиванием с клавиатурными и accessibility-стрелками, автосохранением и сохранением недоступных профилей.
- Превью и алфавит выбора виджетов, меню по удержанию, размеры в пределах провайдера, повторная конфигурация, перенос и удаление. Размеры остаются локальными и сохраняются при импорте backup.
- Поздний callback каталога после уничтожения Activity больше не запускает завершённый executor. Регрессионный тест воспроизвёл прежний `RejectedExecutionException` и проверяет сохранность избранного.
- `AGENTS.md` и README требуют влить ветку и запушить `origin/main` до финальной сборки и публикации кандидата; перед публикацией проверяется принадлежность коммита тега `origin/main`.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:connectedDebugAndroidTest` — успешно. Все 6 unit-тестов и все 26 instrumentation-тестов прошли на выделенном Android 12/API 31. Проверены inline-переименование и отмена, анимация меню, перетаскивание избранного, локальные размеры виджетов, сохранность backup, фильтрация алфавита и поздний callback после уничтожения Activity. Lint: 0 ошибок, 27 существующих предупреждений; новых нет.

## APK

Публикуется подписанный release APK с R8 и удалением неиспользуемых ресурсов, вместе с `SHA256SUMS.txt`. Используется прежний сертификат для совместимых обновлений. Production-сертификат и выпуск в магазине не настроены; полный паритет Niagara, физические устройства, OEM, Private Space и TalkBack целиком не подтверждены.
