# Better Launcher 0.2.0-rc.21

Merged candidate from `main`: all previously unmerged local/`origin` branches are included in main history. Version code: 30; Android 12+ (API 31), target API 36.

## Changes

- Footer again contains only three symmetric icons: Search, Widgets, Settings. No All apps label; accessible search name retained.
- Larger alphabet letters: 16sp, 22dp spacing adapting to height/system font. Only populated A–Z; ★ and final # remain navigation items. Alphabet stays in place on list opening, accounts for footer, IME and system Back.
- App menu preserves corrected animation without bottom gap. Renaming stays in the same menu; Save right-aligned, field accessible above keyboard.
- Drag ordering for favorite apps/folders with keyboard/accessibility arrows, autosave and unavailable-profile preservation.
- Widget previews/picker alphabet, hold menu, provider-limited sizing, reconfiguration, transfer/removal. Sizes remain local/preserved during backup import.
- Late catalog callbacks after Activity destruction no longer start a stopped executor. Regression reproduced previous `RejectedExecutionException` and checks favorites preservation.
- `AGENTS.md`/README require branch merge and `origin/main` push before final candidate build/publication; tag-commit ancestry in `origin/main` checked before publishing.
