# Better Launcher 0.2.0-rc.19

Релиз-кандидат более читаемого алфавитного индекса на основе main с 0.2.0-rc.17. Номер rc.18 оставлен параллельному кандидату настроек виджета; этот кандидат содержит изменение алфавита.

## Изменения

- Обычный размер букв увеличен с 11sp до 16sp, шаг — с 16dp до 22dp. При крупном системном шрифте шаг растёт; короткое окно ограничивает размер букв, чтобы они не накладывались друг на друга.
- Во всех размерах окна показаны только буквенные разделы, содержащие видимые приложения. Скрытие, восстановление и переименование приложения обновляют набор букв; группировка кириллицы через Android ICU сохранена.
- То же оформление и фильтрация действуют в алфавите выбора виджета, по доступным провайдерам.
- Сохранены нижнее положение полосы с отступом над footer, волна, левосторонний режим, системный Back, клавиатура и accessibility. «★» возвращает к избранному, конечный «#» остаётся навигационным пунктом, включая каталог без буквенных разделов.

## Установка

Установите `better-launcher-0.2.0-rc.19-release.apk` поверх предыдущей версии. versionCode — 28, minSdk — 31, targetSdk — 36. Выпуск помечен как prerelease; стабильный 0.1.9 остаётся latest.

Release использует R8 и удаление неиспользуемых ресурсов, отладка отключена. Прежний сертификат сохранён для совместимости обновлений; производственная подпись для магазина не настроена.

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest` — успешно; все 4 unit-теста прошли. Debug lint: 0 ошибок, 27 прежних предупреждений, новых замечаний на изменённых строках нет.
- `:app:assembleRelease :app:lintRelease` — успешно. Release lint: 0 ошибок, те же 27 предупреждений. Есть mapping R8; manifest не содержит debuggable/testOnly; тестовые провайдеры отсутствуют в APK.

Проверены только заполненные буквы, скрытие/восстановление/переименование, кириллица, жесты и оба положения полосы, клавиатура/accessibility, каталог/backup и выбор виджета.

На итоговой версии полный прогон на свежем устройстве прервался после 3 тестов с `RejectedExecutionException` в callback `MainActivity` после завершения Activity; этот lifecycle-код в правке не менялся. - На подписанном release APK полный `scripts/smoke-test.py` прошёл на Android 12/API 31 (`emulator-5700`) и Android 16/API 36 (`emulator-5702`); аварий Better Launcher нет.
