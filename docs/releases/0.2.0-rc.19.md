# Better Launcher 0.2.0-rc.19

More-readable alphabet-index candidate based on main with rc.17. rc.18 reserved for a concurrent widget-settings candidate; this candidate changes the alphabet.

## Changes

- Normal letters grow from 11sp to 16sp, spacing from 16dp to 22dp. Spacing grows with system fonts; short windows limit letter size to prevent overlap.
- Every window shows only letter sections with visible apps. Hiding/restoring/renaming updates letters; Android ICU Cyrillic grouping remains.
- Widget-picker alphabet uses the same appearance/filtering for available providers.
- Preserves bottom rail/footer gap, wave, left-handed mode, system Back, keyboard/accessibility. ★ returns to favorites; final # remains a navigation item, including catalogs without letter sections.

## Installation

Update with `better-launcher-0.2.0-rc.19-release.apk`. versionCode: 28, minSdk: 31, targetSdk: 36. Prerelease; stable 0.1.9 remains latest.

Release enables R8/resource shrinking, disables debugging and retains the compatible certificate. Production store signing not configured.
