# Better Launcher 0.2.0-rc.52

Единый фон настроек под системными панелями. Version code — 61; Android 12+ (API 31), target API 36.

## Изменения

- Тёмно-синий фон настроек теперь принадлежит всему контейнеру экрана, а не только прокручиваемому списку. Статус-бар, нижняя или боковая системная навигация больше не показывают полосы обоев другого цвета.
- Отключение контрастной подложки навигации закреплено в теме окна: на Android 12 трёхкнопочная панель больше не затемняет тёмно-синий фон после создания DecorView.
- Содержимое остаётся внутри system/cutout/IME insets. Прокрутка и открытие вложенного меню сохраняют фон; Back/HOME и переход к поиску или виджетам возвращают прозрачный контейнер с системными обоями.

## Проверки

Debug assembly, все 15 unit-тестов и debug lint прошли: 0 ошибок, 27 прежних предупреждений, новых нет. Визуальная проверка использует выделенные Google APIs arm64-v8a эмуляторы Android 12/API 31 и Android 16/API 36. Локальные снимки, UI hierarchy и логи: `.impeccable/review/settings-bars/`.

По 11 выбранных инструментальных тестов покрывают навигацию, раздельные меню/жесты и системную транслитерацию на обеих версиях Android. API 36 прошёл единым прогоном; на API 31 первый прогон завершился с тайм-аутом удержания в `homeRefreshDuringIconHoldKeepsQuickActions`, затем все четыре теста `AppGesturesTest` прошли при повторе без изменения исходников. Полный набор из 42 инструментальных тестов дополнительно прошёл на локальном выделенном API 36 без падений и пропусков; полный набор на API 31 не запускался. После тестов подписанный release APK установлен снова и назначен HOME.

Native-проверка подтвердила одинаковый цвет фона под статус-баром и навигацией при трёх кнопках и жестах, прокрутке и возврате из меню выбора шрифта, а также возврат системных обоев на главном экране, в поиске и на странице виджетов. Все шесть smoke-прогонов подписанного APK прошли: портрет, узкое окно 945×2100/font scale 1.3 и горизонтальное окно на API 31 и API 36. Проверка цвета на native-скриншотах прошла во всех конфигурациях; левосторонний режим проверен и восстановлен. Размер, шрифт и ориентация эмуляторов восстановлены. Release lint: 0 ошибок, те же 27 предупреждений, что в rc.51. Характеристики итогового APK приведены в GitHub Release.

[GitHub CI](https://github.com/better-launcher/better-launcher/actions/runs/37320031310) успешно завершил build/unit/lint, но device job остановился до запуска тестов из-за системного ANR `com.android.systemui` на эмуляторе runner. Это сбой окружения CI; его device job не считается пройденным. Локальный полный прогон API 36 и native smoke описаны выше.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Совместимость сертификата с предыдущим опубликованным APK, отсутствие debuggable, размер, состав и SHA-256 проверяются перед публикацией и записываются в GitHub Release.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон пользователя и его OEM-оформление системных панелей не проверены. Полный паритет Niagara не заявляется.
