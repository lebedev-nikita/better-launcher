# Better Launcher 0.2.0-rc.52

Uniform Settings background under system bars. Version code: 61; Android 12+ (API 31), target API 36.

## Changes

- Navy Settings background belongs to the entire screen container, not just scroll list. Status/bottom/side navigation no longer reveal mismatched wallpaper strips.
- Navigation contrast scrim disabled in window theme: Android 12 three-button bar no longer darkens navy after DecorView creation.
- Content stays inside system/cutout/IME insets. Scrolling/nested menus preserve background; Back/HOME/search/widgets restore transparent system-wallpaper container.
