# Better Launcher 0.2.0-rc.26

Home-widget layout following the supplied reference: centered above favorites and expandable to full width. Version code: 35; Android 12+ (API 31), target API 36.

## Changes

- Home widget gets a separate full-screen-width area respecting system insets. App-list alphabet margins no longer limit it.
- Default centered widget has about 36 dp side margins plus Android/provider padding. Area starts 56 dp below the status bar, 24 dp in short windows. Favorites/separate widget-page margins remain.
- Side handles expand to exact usable-window width even off the 12 dp grid; keyboard/accessibility also support this. Provider maximum takes precedence; at full width the alphabet overlays the widget, matching the reference.
- Saved size/offsets remain valid. Reset size and position applies the new default width to previously configured widgets. Height remains provider-dependent and adjustable through top/bottom handles.
- AppWidgetHost ID, system binding/configuration, RemoteViews updates, cross-screen transfer, backup format and local IDs remain.

Includes published main's resize haptics ([rc.25](0.2.0-rc.25.md)).
