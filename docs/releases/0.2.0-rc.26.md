# Better Launcher 0.2.0-rc.26

Расположение главного виджета по предоставленному образцу: центрированный виджет выше избранного и возможность растянуть его на всю ширину. Version code — 35; Android 12+ (API 31), target API 36.

## Изменения

- Главный виджет получил отдельную область на всю ширину экрана с учётом системных insets. Отступы списка приложений под алфавит больше не ограничивают его размер.
- По умолчанию виджет центрирован с боковыми отступами около 36 dp плюс внутренний padding Android/провайдера. Начало области — 56 dp ниже статус-бара; в коротком окне — 24 dp. Отступы избранного и отдельной страницы виджетов сохранены.
- Боковые маркеры позволяют растянуть главный виджет до точной ширины доступного окна, даже если она не кратна сетке 12 dp. То же доступно с клавиатуры и через accessibility. Максимальный размер, заданный провайдером, сохраняет приоритет; при полной ширине алфавит остаётся поверх виджета, как в предоставленном примере.
- Сохранённые размеры и смещения остаются действующими. Чтобы применить новую ширину по умолчанию к ранее настроенному виджету, выберите «Сбросить размер и положение» в меню удержания. Высота зависит от провайдера и меняется прежними верхним/нижним маркерами.
- AppWidgetHost ID, системная привязка/конфигурация, обновления RemoteViews, перенос между экранами, формат backup и локальные widget IDs сохранены.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов; lint — 0 ошибок, 27 существующих предупреждений, новых нет. Layout detector не обнаружил замечаний.

Новый тест настоящего AppWidgetHost воспроизвёл исходное ограничение: виджет получал только 787 px из 1080 px. После исправления тест проходит на Android 12/API 31 и Android 16/API 36: отдельная ширина, симметричное центрирование, верхний отступ, точное растягивание и сохранение после перестроения, обе стороны алфавита и сохранённый пользовательский размер/смещения. Узкий экран 945×2100 с font scale 1.3 также проверен на API 36. Снимки получены из эмуляторов; тестовый провайдер находится только в androidTest и отсутствует в основном APK. Локальные материалы — `.impeccable/review/widget-layout/`.

## APK и ограничения

Подписанный release APK с R8 и удалением неиспользуемых ресурсов собирается из чистого main, уже опубликованного в origin/main; публикуются APK и SHA256SUMS.txt. Используется прежний сертификат для совместимого обновления. Production-сертификат и магазин не настроены. Физический Todoist из пользовательских снимков на эмуляторе не установлен: геометрия проверяется на настоящем AppWidgetHost с тестовым провайдером. Физические устройства/OEM, рабочие профили и полный TalkBack остаются вне подтверждённого покрытия. Полный паритет Niagara не заявляется.
