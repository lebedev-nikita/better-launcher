# Better Launcher 0.2.0-rc.16

Favorites-order candidate rebased onto `origin/main` (`a04e631771005d3dcfa3f10ec323363b527072d4`).

## Changes

- Change order in a favorite app's long-press menu; same editor from Settings/folder editing.
- Drag apps/folders by ≡; up/down arrows support keyboard/accessibility. Changes save immediately without closing the editor.
- Heading, close, app selection and folder creation stay outside the scroll list. Narrow-screen names grow above a separate button row; wide landscape places buttons beside names.
- Full app/profile IDs and unavailable apps remain. Order survives Activity recreation, Back/HOME and export/import; backup format unchanged.
- Includes main's widget previews/picker alphabet, RemoteViews loading fix, app-menu heading renaming/entry animation and lower alphabet-boundary fix.

## Installation

Update with `better-launcher-0.2.0-rc.16-release.apk` without uninstalling. versionCode: 25, minSdk: 31, targetSdk: 36. Prerelease; 0.1.9 remains latest stable.

R8/unused-resource removal enabled, debugging disabled. Compatible original Android Debug certificate retained, SHA-256 `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Separate production signing/store distribution not configured.

## Limitations

Main instrumentation/UI matrix used preliminary versionCode 24. Before publication, raised to 25 / rc.16 because another release took rc.15. ZIP comparison shows only `AndroidManifest.xml` changed; DEX, resources, dependencies and profiles identical. Build, unit tests, debug/release lint, signing and portrait editor rerun after version bump. Android 12 landscape also checked on final APK: initial Settings command left portrait, so retry used `wm user-rotation lock 1` and verified PNG dimensions.

Full landscape smoke on both versions stopped launching Camera: Better Launcher remained active. Cause unresolved; full landscape smoke not successful. Independent landscape editor checks passed. Size/font/orientation restored.

Pre-rebase editor checks, including both versions/narrow/font scale 1.3/landscape, remain in the [report](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.16/docs/favorites-order-verification.md); they describe the earlier snapshot, not final-APK verification.

Physical devices, real work profiles, Private Space, TalkBack, keyboard navigation and left-handed mode were not independently checked. Full Niagara parity is not claimed.
