# Better Launcher 0.1.9

Патч выбора виджетов: превью и алфавитная прокрутка справа.

## Изменения

- Превью с несколькими строками измеряется по содержимому, чтобы текст не обрезался минимальной высотой провайдера.
- Выбор виджета показывает его название, приложение и статичное превью до добавления. Используется `previewLayout` провайдера, затем `previewImage`; при отсутствии или повреждении обоих показываются значок и явная подпись «Превью недоступно».
- Справа находится тот же алфавит с волной, что в списке приложений. Звёздочка возвращает к началу, кириллица группируется через системную ICU, «#» остаётся последним. Есть управление клавиатурой и accessibility; короткие окна и крупный шрифт показывают только доступные разделы.
- Заголовок и закрытие закреплены над списком. Строки переиспользуются; каталог и ресурсы превью загружаются в фоне, незавершённая загрузка отменяется при переиспользовании строки и закрытии окна.
- Сохранены новые изменения main: появление меню приложения снизу и переименование нажатием на заголовок.
- Просмотр превью не выделяет widget IDs и не вызывает привязку. Выбор строки запускает прежнюю системную привязку/конфигурацию для экрана виджетов или главного экрана.

## Установка

Скачайте `better-launcher-0.1.9-release.apk` и установите поверх предыдущей версии без удаления приложения. versionCode — 14, minSdk — 31, targetSdk — 36. Подпись совпадает с 0.1.7; сохранён прежний сертификат Android Debug для совместимости обновлений. Сам APK собран как release: R8 и удаление неиспользуемых ресурсов включены, отладка отключена.

Размер APK — 2424472 байт (около 2,42 МБ), на 9445 байт / 0.39% больше 0.1.7. ZIP-записей — 719; прирост соответствует коду списка превью и сохранённым ресурсам анимации меню из main. Тестовые провайдеры находятся только в androidTest APK.

SHA-256: `0f65385c5e3b9bed4d2b6e059991d023574e3d14fff7c3267c208ae815a4e4c7`. Он также записан в `SHA256SUMS.txt`.
