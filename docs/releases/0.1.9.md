# Better Launcher 0.1.9

Widget-picker patch: previews and alphabet scrolling on the right.

## Changes

- Multiline previews are measured by content so the provider's minimum height does not clip text.
- Before adding a widget, the picker shows its name, app and static preview. It uses the provider's `previewLayout`, then `previewImage`; if both are missing or broken, an icon and explicit Preview unavailable label appear.
- The right side uses the app list's wave alphabet. The star returns to the start, system ICU groups Cyrillic, and “#” remains last. Keyboard/accessibility controls are available; short windows and large fonts show only available sections.
- The heading and close action remain above the list. Rows are reused; catalog and preview resources load in the background. Pending loading is canceled when a row is reused or the window closes.
- Preserves new main changes: the app menu appears from below, and tapping its heading renames the app.
- Previewing allocates no widget IDs and performs no binding. Selecting a row starts existing system binding/configuration for the widget screen or home.
