# Better Launcher 0.2.0-rc.28

Left-screen widget ordering and direct favorites-order entry. Version code: 37; Android 12+ (API 31), target API 36.

## Changes

- Home offers Change favorites order with two or more visible favorites, opening the existing app/folder editor. Long-press menus/Settings remain available.
- With two or more widgets, heading ≡ and hold-menu Change order open ordering. Shared RecyclerView editor provides ≡ drag, edge scrolling and named up/down arrows. Boundary arrows disabled; changes save immediately without closing.
- Repeated provider instances receive opening-order numbers. Reordering preserves real host IDs, bindings, sizes/offsets and home selection. Back/Close/HOME dismiss with saved changes.
- Preserves rc.26's separate centered/exact-full-width home-widget area and rc.27's soft haptics: SEGMENT_FREQUENT_TICK on Android 14+, CLOCK_TICK on Android 12/13 via ViewCompat.
