# Better Launcher 0.2.0-rc.28

Перестановка виджетов на левом экране и прямой вход в изменение порядка избранного. Version code — 37; Android 12+ (API 31), target API 36.

## Изменения

- На главном экране при двух и более видимых избранных доступна команда «Изменить порядок избранного». Она открывает существующий редактор приложений и папок; меню удержания и настройки также остаются доступны.
- На экране виджетов при двух и более экземплярах кнопка ≡ в заголовке и команда «Изменить порядок» в меню удержания открывают редактор порядка. Перетаскивание за ≡, прокрутка у края и именованные стрелки вверх/вниз доступны в общем RecyclerView-редакторе. Граничные стрелки выключены; изменения сохраняются сразу без закрытия окна.
- Несколько экземпляров одного провайдера получают номера по исходному порядку при открытии редактора. Перестановка сохраняет их реальные host IDs, привязки, размеры и отступы, а также выбор главного виджета. Back, Close и HOME закрывают редактор с сохранёнными изменениями.
- Сохранены изменения rc.26: отдельная область главного виджета с центрированием и точным растягиванием на всю ширину. Сохранён мягкий тактильный отклик rc.27: SEGMENT_FREQUENT_TICK на Android 14+ и CLOCK_TICK на Android 12/13 через ViewCompat.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов; lint — 0 ошибок и 27 существующих предупреждений, новых нет. Layout detector не обнаружил замечаний. Рабочие Markdown-ссылки и `git diff --check` проверены.

После объединения с rc.26 полный инструментальный прогон Android 16/API 36 прошёл: 30 из 30 тестов. Проверены реальное перетаскивание, стрелки, порядок главного экрана/страницы виджетов, пересоздание Activity, Back/HOME, backup/import, сохранность недоступного app/profile ID, главного widget ID, размеров, смещений и RemoteViews после перестановки. Повторные экземпляры одного провайдера различаются по номеру в редакторе. Финальный `:app:connectedDebugAndroidTest` на Android 12/API 31 прошёл: 30 из 30 тестов после повторной установки и назначения HOME.

Нативные редакторы проверены на Android 12/API 31 и Android 16/API 36: портрет, узкий экран со шрифтом 1.3, реальное широкое окно/landscape и левосторонний режим. Перетаскивание, стрелки, сохранение после перезапуска, Back/HOME и доступность фиксированных действий прошли. На API 31 landscape получен принудительным широким окном, на API 36 — поворотом. Параметры устройств восстановлены, тестовые виджеты удалены. Провайдер находится только в androidTest и не входит в основной APK. Снимки и логи — локально в `.impeccable/review/reorder/`.

Ранние запуски API 31 с ANR `com.android.systemui` не считаются успешными. До объединения с rc.26 полный прогон прошёл 28 из 29 проверок; существующий таймаут превью изображения прошёл на отдельном повторе. Первый прогон после объединения прошёл 29 из 30; тест главного виджета остановился на ожидании маркера редактора, отдельный connected-повтор также не прошёл. После переустановки APK и назначения HOME изолированный инструментальный сценарий прошёл без изменения основного кода. После включения мягкого тактильного отклика из rc.27 снова прошли все 30 тестов на каждой версии: connected-прогон на API 31 и полный инструментальный прогон на API 36. Проверка финального подписанного APK приводится в GitHub Release.

## APK и ограничения

Подписанный release APK с R8 и удалением неиспользуемых ресурсов собирается из чистого main, уже опубликованного в origin/main. Публикуются APK и SHA256SUMS.txt; используется прежний сертификат для совместимого обновления. Production-сертификат и магазин не настроены. Физические устройства/OEM, реальные рабочие профили и TalkBack целиком не проверены; полный паритет Niagara не заявляется.
