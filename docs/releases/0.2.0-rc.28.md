# Better Launcher 0.2.0-rc.28

Главный экран без пустой области над содержимым. Version code — 37; Android 12+ (API 31), target API 36.

## Изменения

- Удалён дополнительный верхний отступ главного экрана: 56 dp над виджетом, 24 dp в коротком окне и прежние 14% высоты над избранным без виджета. Содержимое начинается сразу под системными insets в любом размере окна. Статус-бар и вырезы экрана остаются учтены; собственного верхнего резерва у лаунчера нет.
- Верхний маркер редактора сдвигается внутрь виджета возле статус-бара. Его 48dp область нажатия полностью остаётся ниже системных bars/cutouts; это не добавляет отступ самому виджету.
- Сохранённые пользовательские смещения и размеры остаются действующими. Если виджет был вручную сдвинут вниз, переместите его вверх в редакторе или выберите «Сбросить размер и положение». Нулевая позиция теперь соответствует верхней доступной границе.
- Центрирование, растягивание на всю ширину, сетка 12 dp, клавиатура/accessibility, мягкий виброотклик из rc.27, AppWidgetHost ID и формат backup сохранены. Высота зависит от провайдера и выбранного размера.
- Smoke-сценарий свайпа страницы виджетов начинается на свободных обоях над footer: пустой верхней полосы теперь нет.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов, lint — 0 ошибок и 27 существующих предупреждений; новых нет. Layout detector не обнаружил замечаний.

Обновлённый тест AppWidgetHost воспроизвёл исходный отступ на rc.26: верх виджета находился на 210 px при доступном начале 63 px. Проверка требует точного совпадения с границей системных insets для виджета и первой строки избранного без виджета, а также доступности верхнего маркера ниже статус-бара. Снимки получены из эмуляторов с androidTest-провайдером, который отсутствует в основном APK. Локальные материалы — `.impeccable/review/no-top-gap/`.

На выделенных эмуляторах Android 12/API 31 и Android 16/API 36 прошли все 6 затронутых instrumentation-тестов: WidgetHomeLayoutTest, WidgetHostTest, WidgetGestureTest, WidgetResizeHapticTest и два LauncherNavigationTest. Геометрия отдельно проверена на обеих версиях в портрете, при размере 945×2100/font scale 1.3 и в фактическом горизонтальном окне (API 31: 2160×1080, API 36: 2400×1080), с обоими положениями алфавита. Настройки экрана восстановлены. Полный instrumentation suite для этого изменения не повторялся.

После объединения с rc.27 базовые проверки и затронутые native-тесты повторены; результаты относятся к итоговому кандидату. Дополнительно все 5 SystemTransliterationTest прошли на API 31 и API 36.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением ресурсов, а также SHA256SUMS.txt. APK собирается из чистого опубликованного коммита main; используется прежний сертификат для совместимого обновления. Production-сертификат и магазин не настроены. Физические устройства, OEM и реальное оформление Todoist остаются вне подтверждённого покрытия. Полный паритет Niagara не заявляется.
