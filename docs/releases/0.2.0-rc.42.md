# Better Launcher 0.2.0-rc.42

Меню приложения без дублирующего пункта запуска. Version code — 51; Android 12+ (API 31), target API 36.

## Изменения

- Удалён пункт «Открыть …» внизу всплывающего меню приложения, открываемого свайпом или через «Уведомления и быстрые действия».
- Уведомления, shortcuts, прикреплённые приложения и «Добавить приложения» остаются доступными. Приложение открывается обычным нажатием на его строку в избранном, общем списке или поиске.
- Smoke-проверка открывает меню по свайпу, проверяет «Добавить приложения» и отсутствие «Открыть Phone».

## Проверки

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest` прошли; все 15 unit-тестов успешны.
- Debug lint: 0 ошибок, 27 прежних предупреждений. Новых предупреждений нет.
- Итоговые результаты connected-тестов и UI-сценариев на выделенных эмуляторах Android 12/API 31 и Android 16/API 36, release lint, размер APK, сертификат и SHA-256 публикуются в GitHub Release. Логи и снимки сохраняются локально в `.impeccable/review/remove-open/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. Итоговый APK собирается из чистого коммита main, уже опубликованного в origin/main; тег указывает на этот коммит. Прежний сертификат сохранён для совместимости обновлений. Production-сертификат, магазин, физические телефоны/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
