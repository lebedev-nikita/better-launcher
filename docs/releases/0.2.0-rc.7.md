# Better Launcher 0.2.0-rc.7

Релиз-кандидат после rebase на main (`1835e19`) с правилами публикации из обновлённого AGENTS.md. Стабильный выпуск остаётся Latest; прежние кандидаты сохранены.

## Изменения

- Убрана видимая подпись «Все приложения». Поиск слева внизу, настройки справа внизу, кнопка виджетов по центру. Одинаковые области нажатия 48×48dp и боковые отступы 22dp сохраняют симметрию; доступные названия и фокус клавиатуры сохранены.
- Сохранены изменения main: системная Android ICU вместо ICU4J, кириллическая транслитерация, алфавит, обработанное отпускание пальца ниже алфавита, анимация меню приложений снизу после замера окна и insets и переименование через его заголовок, затемнение обоев, экран виджетов и новый выбор виджета с превью и алфавитом справа.
- Публикуется подписанный release APK с R8 и удалением неиспользуемых ресурсов. Debug APK используется только для локальных тестов.

## Установка

Скачайте `better-launcher-0.2.0-rc.7-release.apk` и установите поверх прежнего выпуска. versionCode — 16, minSdk — 31, targetSdk — 36. `SHA256SUMS.txt` содержит SHA-256 APK.

Сохранён прежний сертификат Android Debug для совместимости обновлений; сам APK является release-сборкой с отключённой отладкой. Приватная настройка подписи хранится вне Git. Отдельный production-сертификат и публикация в магазине пока не настроены.

## Проверки

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно; 4 unit-теста, 0 ошибок и пропусков.
- Debug/release lint: 0 ошибок, по 27 прежних предупреждений; новых сообщений относительно main нет.
- Подпись v2 проверена `apksigner`; сертификат совпадает с опубликованным 0.1.8. SHA-256 сертификата: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`.
- R8 и resource shrinking включены, mapping создан, manifest не содержит `debuggable=true`. APK — 2 425 224 байта: на 10 121 байт больше 0.1.8 из-за нового выбора виджетов и анимации меню из main. Добавлены три XML-ресурса анимации; остальные ZIP-записи сохранены, ICU4J отсутствует.
- SHA-256 APK: `f1649ce8d61fd5cc55bd565a5e3bc51216019a3df2b838424f9177105fc62097`.
- `ANDROID_SERIAL=emulator-5560 ./gradlew --max-workers=2 :app:connectedDebugAndroidTest` — запуск ожидал 19 тестов и прервался: `INSTRUMENTATION_ABORTED: System has crashed`. В логах есть падения `system_server` (`Lost network stack`) и последующие `DeadSystemException`. Полный итоговый connected-набор не подтверждён; падение теста меню в этом прогоне не объявляется устранённым или успешным.
- После connected-тестов итоговый release APK переустановлен на Android 12 и назначен HOME. Попытка полного smoke остановилась на первом чтении UI-дерева: `uiautomator dump` завершился с кодом 137. Финальные визуальные сценарии, поиск и настройки после последнего rebase остаются непроверенными.
- До последнего rebase промежуточная сборка с тем же симметричным footer прошла 17 connected-тестов и полный smoke на Android 12, включая переименование по заголовку и отмену по HOME. На ней также проверены портрет, узкий экран 840×1866/font scale 1.3, алфавит слева и настоящий landscape; поиск и настройки открываются касаниями. Размер, шрифт, сторона алфавита и поворот восстановлены. Эти результаты не заменяют проверку финального APK после включения новых изменений main.
- На Android 16 подготовка прерывалась кодом 134 процесса эмулятора, системными ANR, пустым UI-деревом и исчезновением системного сервиса `input`. Финальный APK после последнего rebase на Android 16 не проверен. Диагностические логи сохранены локально в `.impeccable/review/footer-rc3/` и `.impeccable/review/footer-rc7/` и не входят в Git.

Физические устройства, рабочие профили, Private Space, сторонние провайдеры виджетов и полная проверка TalkBack не проверены. Полный паритет Niagara не заявляется. [Покрытие возможностей](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.7/docs/features.md).
