# Better Launcher 0.2.0-rc.7

Release candidate rebased onto main (`1835e19`), following updated AGENTS.md publication rules. Stable remains Latest; previous candidates are retained.

## Changes

- Removes the visible All apps label. Search bottom-left, Settings bottom-right, widgets centered. Equal 48×48dp touch areas and 22dp side margins preserve symmetry; accessible names and keyboard focus remain.
- Preserves main changes: system Android ICU replacing ICU4J, Cyrillic transliteration, alphabet and release-below-alphabet handling, bottom-entry app-menu animation after window/inset measurement, heading renaming, wallpaper dimming, widget screen and a new picker with previews/right alphabet.
- Publishes a signed release APK with R8/unused-resource removal. Debug APKs are for local testing only.

## Installation

Download `better-launcher-0.2.0-rc.7-release.apk` and update the previous release. versionCode: 16, minSdk: 31, targetSdk: 36. `SHA256SUMS.txt` contains the APK SHA-256.

The previous Android Debug certificate remains for compatibility; the APK is a release build with debugging disabled. Private signing configuration stays outside Git. Separate production signing/store distribution are not configured.
