# Better Launcher 0.2.0-rc.2

Preview release for testing the updated home screen. Stable 0.1.5 remains Latest.

## Changes

- Removes the visible All apps label. Search sits bottom-left; Settings bottom-right.
- Buttons are symmetric: matching 48×48dp touch areas, height, and 22dp margins from the usable screen edges. Accessible names and keyboard controls remain.
- The existing widget-screen button sits between Search and Settings.
- Includes current main changes: one home widget and a separate left screen for remaining widgets. Swipe right on empty space or use the widget button to open it; swipe left, Back and HOME return home.
- Preserves the updated long-press menu with icons/expandable actions, Latin alphabet with ICU4J Cyrillic grouping and automatically saved 0–100% wallpaper dimming.

## Installation

Download `better-launcher-0.2.0-rc.2-debug.apk` and install over 0.1.5. Signing matches published APK 0.1.5; normal updates preserve settings. Minimum: Android 12 (API 31), targetSdk: 36, versionCode: 8. `SHA256SUMS.txt` contains the APK SHA-256.

Uses the previous debug key. Permanent production signing and store publishing are not configured.
