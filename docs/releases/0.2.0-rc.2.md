# Better Launcher 0.2.0-rc.2

Предварительный выпуск для проверки обновлённого главного экрана. Стабильный выпуск 0.1.5 остаётся Latest.

## Изменения

- Убрана видимая подпись «Все приложения». Иконка поиска находится слева внизу, настройки — справа внизу.
- Кнопки симметричны: одинаковые области нажатия 48×48dp, одинаковая высота и отступы 22dp от боковых границ доступной области экрана. Доступные названия и управление с клавиатуры сохранены.
- Существующая кнопка экрана виджетов расположена по центру между поиском и настройками.
- В этот кандидат также входят актуальные изменения основной ветки: один виджет на главном и отдельный экран остальных виджетов слева. Его можно открыть свайпом вправо по свободному месту или кнопкой виджетов; свайп влево, Back и HOME возвращают домой.
- Сохранены обновлённое меню долгого удержания с пиктограммами и раскрывающимися действиями, латинский алфавит с группировкой кириллицы через ICU4J и регулировка затемнения обоев 0–100% с автосохранением.

## Установка

Скачайте `better-launcher-0.2.0-rc.2-debug.apk` из файлов этого предварительного выпуска и установите поверх 0.1.5. Сертификат подписи совпадает с опубликованным APK 0.1.5; обычное обновление сохраняет настройки. Минимальная версия — Android 12 (API 31), targetSdk — 36, versionCode — 8. `SHA256SUMS.txt` содержит SHA-256 APK.

APK подписан прежним отладочным ключом. Постоянная production-подпись и публикация в магазине не настроены.

## Проверки и ограничения

- `ANDROID_SERIAL=emulator-5586 ./gradlew --max-workers=2 :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:connectedDebugAndroidTest` — успешно: 9 unit-тестов и 11 интеграционных тестов Android 12 / API 31, 0 ошибок, 0 пропусков.
- Lint: 0 ошибок, 27 прежних предупреждений; новых сообщений относительно предыдущего отчёта нет.
- Проверки навигации находят поиск по доступному названию. HOME проверяется по видимой Activity с фокусом через стандартный lifecycle-монитор; ожидание фокуса увеличено до 15 секунд. Первые прогоны прерывались задержкой фокуса и сбоем подключения UiAutomation на перегруженном хосте; после изменения теста итоговый набор проходит.
- Подпись APK v2 проверена через `apksigner`; сертификат совпадает с прежними выпусками.
- SHA-256 APK: `be519f0beb5ee324a3df6601fe1608ecc72962162822ac89e044b2aaf7f2a102`.

- Итоговый APK установлен и назначен HOME на Android 12 (`BetterLauncher_FooterRC_API_31`, `emulator-5586`) и Android 16 (`BetterLauncher_API_36`, `emulator-5590`). Поиск и настройки проверены реальными нажатиями.
- На обоих Android проверены портрет 1080×2400, узкий экран 840×1866 (320dp) с font scale 1.3, алфавит слева и landscape. UI-дерево подтверждает отсутствие видимой подписи, одинаковые 48dp области нажатия, общую высоту и равные промежутки вокруг центральной кнопки виджетов. Скриншоты проверены визуально; локальные файлы находятся в `.impeccable/review/footer-rc/` и не входят в Git.
- Для landscape дисплей принудительно повёрнут через `wm user-rotation` с временным игнорированием запросов ориентации. Размер экрана, font scale, поворот, режим ориентации и прежние настройки лаунчера после проверки восстановлены.

- Полный `scripts/smoke-test.py` итогового APK проходит на Android 12 и Android 16: экран виджетов и жесты, настройки/Back, поиск, запуск Camera/HOME, меню свайпа, долгое удержание с дополнительными действиями, алфавит; аварий Better Launcher нет. Скрипт ждёт главный экран после закрытия меню, чтобы не спутать его заголовок Phone со строкой избранного.

Проверка на физическом телефоне, полная проверка TalkBack, рабочих профилей и сторонних провайдеров виджетов не выполнены. Полный паритет Niagara не заявляется.
