# Better Launcher 0.2.0-rc.43

Раздельные меню удержания иконки и названия приложения. Version code — 52; Android 12+ (API 31), target API 36.

## Изменения

- Долгое удержание иконки открывает уведомления, быстрые действия и прикреплённые приложения.
- Долгое удержание названия открывает управление ярлыком: избранное, порядок, переименование, скрытие, сведения и другие команды лаунчера.
- Свайп вправо на главном экране, в том числе по иконке, названию и папке, открывает страницу виджетов. Горизонтальный свайп по приложению больше не открывает меню и отменяет обычное нажатие, чтобы не запускать приложение случайно. Свайп влево на странице виджетов возвращает домой.
- Иконка сохраняет размер 38dp внутри отдельной области 48dp. Название имеет область удержания высотой минимум 48dp; обычные нажатия запускают приложение.
- При скрытых иконках быстрые действия доступны через именованное accessibility-действие названия и существующую команду меню управления. Перестановка и жесты внутри сторонних виджетов сохраняются.
- Сохранены прозрачность перетаскиваемых строк избранного, плоский список управления и отсутствие дублирующей команды запуска во всплывающем меню из main. Обновлены документация, sidecar и smoke-сценарий.

## Проверки

`assembleDebug`, `assembleDebugAndroidTest`, все 15 unit-тестов и `lintDebug` прошли после интеграции main: 0 lint errors и прежние 27 warnings, новых нет. Пользователь выбрал дождаться завершения других задач: свои эмуляторы остановлены, чужие не останавливаются; проверка на устройствах и публикация ожидают освобождения ресурсов. Инструментальные прогоны ранее прерваны нестабильностью эмуляторов на перегруженной машине (device offline, System UI ANR и перезапуск system_server); это не успешная проверка. Итоговая проверка объединённого опубликованного main и native UI подписанного APK записываются в GitHub Release. Новые AppGesturesTest проверяют отдельные меню для иконки/названия, оба направления свайпа по строке и доступ к обоим меню при скрытых иконках. Локальные логи и снимки: `.impeccable/review/menus/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. APK собирается из чистого опубликованного main; коммит, SHA-256, размер и сравнение подписи/состава с предыдущим кандидатом указаны в GitHub Release. Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется. Формат backup, сохранённые приложения и widget IDs не меняются.
