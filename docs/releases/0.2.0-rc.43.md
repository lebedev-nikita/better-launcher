# Better Launcher 0.2.0-rc.43

Смахиваемые всплывающие сообщения с длительностью до трёх секунд. Version code — 52; Android 12+ (API 31), target API 36.

## Изменения

- Все всплывающие сообщения Better Launcher, включая «Приложение скрыто», закрываются горизонтальным смахиванием в любую сторону. Текст следует за пальцем и постепенно исчезает; короткий или отменённый жест возвращает сообщение на место.
- Сообщения с «Отменить» и без действия исчезают максимум через три секунды. Удержание пальца не продлевает срок. Новое сообщение заменяет предыдущее; таймер прежнего сообщения не закрывает новое.
- Смахивание и закрытие сохраняют результат действия, а кнопка «Отменить» по-прежнему восстанавливает скрытое приложение. Доступны Escape/Delete при фокусе и accessibility-действие закрытия.
- Сообщения учитывают system/cutout/IME insets, переносят длинный текст и удаляют таймеры при закрытии или уходе с экрана.
- Сохранены изменения актуального main, включая поиск скрытых приложений, поиск провайдеров виджетов упрощённое меню виджета и плоский список действий меню приложений.

## Проверки

- Debug assembly, 15 unit-тестов и debug lint после объединения с main, включая плоское меню rc.41, — успешно. Lint: 0 ошибок, 27 прежних предупреждений; новых нет.
- Первый instrumentation-запуск API 31 прерван системной аварией перегруженного эмулятора (`System has crashed`); он не считается успешным. Повторный запуск использует аппаратный GPU и экран 720×1600/280 dpi.

- На API 31 в общем прогоне прошли 17/18 сценариев: все проверки скрытия/отмены, свайпов и срока сообщений, каталога, хранения и транслитерации. Последний сценарий ошибочно отправлял клавишу до layout сообщения; после исправления setup он прошёл отдельно (Escape/Delete, короткие/отменённые жесты, замена сообщения). Lint повторно прошёл с теми же 27 предупреждениями.
- Native UI сообщений проверен на API 31: 720×1600/280 dpi, 630×1400 со шрифтом 1.3, фактический landscape 1600×720 и алфавит слева. Текст и действие не обрезаются, footer и системные области остаются доступными. Временные параметры восстановлены.

Результаты проверок API 36, smoke-тестов на обеих версиях и подписанного APK записываются в GitHub Release. Локальные логи и снимки: `.impeccable/review/messages/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного коммита main; коммит, размер и SHA-256 указаны в GitHub Release. Прежний сертификат сохраняется для совместимости обновлений. Физический телефон/OEM, полный TalkBack-сеанс, production-сертификат и магазин не проверены; полный паритет Niagara не заявляется.
