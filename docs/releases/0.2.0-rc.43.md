# Better Launcher 0.2.0-rc.43

Separate icon/name hold menus. Version code: 52; Android 12+ (API 31), target API 36.

## Changes

- Icon hold opens notifications, quick actions/attached apps.
- Name hold opens shortcut management: favorites, order, rename, hide, app info/other launcher actions.
- Home right swipe, including icons/names/folders, opens widgets. Horizontal app swipes no longer open menus and cancel taps to avoid accidental launch. Widget-page left swipe returns home.
- Icon remains 38dp in a separate 48dp area. Name hold area minimum 48dp high; ordinary taps launch.
- With hidden icons, named name-row accessibility action/existing management-menu action access quick actions. Ordering/third-party widget gestures remain.
- Preserves main's transparent dragged favorites, flat management list/no duplicate popup launch. Documentation/sidecar/smoke updated.
