# Better Launcher 0.2.0-rc.9

Alphabet lower-boundary candidate after `git rebase origin/main`. Final base: `08780aa`, including main's widget previews/new menus. `AGENTS.md` reread after rebase. Candidate number/versionCode reserved by fast-forward main commit `9a72394` before building.

## Changes

- Releasing below letters selects the last section even without the final MOVE; canceled gestures do not restart on late release.
- Includes current app menus: bottom entry after size/system-inset calculation and heading-tap renaming.
- Includes widget selection with provider preview, image/icon fallback, row reuse and right alphabet. Previewing allocates no widget IDs and preserves existing binding/configuration.
- Preserves system Android ICU, wallpaper dimming and the separate widget page.
- Alphabet follows main: full A–Z plus final “#”, available sections in short windows. The separate rc.4 compact alphabet is not yet included in this main base.
