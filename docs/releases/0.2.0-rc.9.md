# Better Launcher 0.2.0-rc.9

Релиз-кандидат исправления нижней границы алфавита после `git rebase origin/main`. Итоговая база — `08780aa`, включая превью виджетов и новые меню из main. `AGENTS.md` перечитан после rebase. Номер кандидата и versionCode зарезервированы fast-forward коммитом `9a72394` в main перед сборкой.

## Изменения

- Отпускание ползунка ниже букв выбирает последний раздел, даже без последнего MOVE; отменённый жест не возобновляется при позднем отпускании.
- Включены текущие меню приложения: появление снизу после расчёта размеров и system insets, переименование по нажатию на заголовок.
- Включён выбор виджетов с превью провайдера, запасным изображением/значком, переиспользованием строк и алфавитной навигацией справа. Просмотр не выделяет widget IDs и сохраняет прежнюю привязку и конфигурацию.
- Сохранены системная Android ICU, затемнение обоев и отдельная страница виджетов.
- Алфавит соответствует main: полный A–Z и заключительный «#», доступные разделы в коротком окне. Компактный алфавит отдельного кандидата 0.2.0-rc.4 в эту базу main пока не включён.

## Установка

Скачайте `better-launcher-0.2.0-rc.9-release.apk` и установите поверх предыдущего выпуска без удаления приложения. versionCode — 18, minSdk — 31, targetSdk — 36. `SHA256SUMS.txt` содержит SHA-256 APK.

Это подписанный release APK с R8 и удалением неиспользуемых ресурсов, без отладки. Прежний сертификат сохранён для совместимости обновлений. Отдельная production-подпись и выпуск в магазине не настроены.

Кандидат публикуется как prerelease с `--latest=false`.
