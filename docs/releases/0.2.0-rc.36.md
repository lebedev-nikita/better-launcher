# Better Launcher 0.2.0-rc.36

Прозрачный фон при перетаскивании избранного. Version code — 45; Android 12+ (API 31), target API 36.

## Изменения

- Приложения и папки избранного остаются прозрачными поверх обоев во время захвата и перетаскивания. Тёмно-синяя непрозрачная плашка удалена.
- Перетаскиваемая строка по-прежнему поднимается над соседними. Сохраняются перестановка, прокрутка у края, отмена, автосохранение и действия клавиатуры/accessibility. Оформление перетаскивания виджетов сохранено.
- Включено изменение rc.35: порядок избранного включается из меню долгого удержания приложения или папки; дублирующей кнопки под списком нет.

## Проверки

- На APK rc.34 воспроизведён непрозрачный прямоугольник при удержании ручки. Причина — заливка внешней строки общим редактором порядка. Избранное теперь передаёт прозрачный цвет, виджеты используют прежнюю поверхность.
- Debug assembly, 14 unit-тестов и debug lint после исправления — успешно. Lint: 0 ошибок, 27 прежних предупреждений; новых нет.
- Проверки итоговой объединённой сборки, native UI на Android 12/API 31 и Android 16/API 36 и подписанного APK записываются в GitHub Release. Локальные снимки и логи: `.impeccable/review/transparent-drag/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного main; размер, коммит и SHA-256 указаны в GitHub Release. Прежний сертификат сохранён для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
