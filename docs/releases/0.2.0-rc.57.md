# Better Launcher 0.2.0-rc.57

## Изменения

- С главного экрана удалены нижние кнопки поиска, страницы виджетов и настроек. Их панель больше не резервирует 66 dp: избранное использует всю доступную высоту между системными панелями.
- Алфавит опущен вместе с освободившейся областью, с прежним отступом 24 dp над системной навигацией. Обычный главный экран и список приложений сохраняют одинаковое положение алфавита. Нижняя строка «Готово» появляется только во время перестановки избранного.
- Свободное место главного экрана доступно до нижней безопасной границы: свайп вверх открывает поиск, удержание — настройки. Свайп вправо по главному экрану или ярлыку открывает виджеты; из настроек остаётся переход «Виджеты».
- Клавиши Search и Menu/Shift+F10 открывают поиск и настройки. На главном экране добавлены именованные accessibility-действия поиска, страницы виджетов и настроек. Настройки также доступны из меню приложения.
- Smoke и инструментальные проверки обновлены для навигации без удалённых кнопок. Исправлено устаревшее ожидание теста верхней ручки виджета: у системного верхнего края вся её область нажатия должна оставаться ниже статус-бара.

## Проверки

Debug APK, 15 unit-тестов и lint прошли. Lint: 0 ошибок, 27 прежних предупреждений, новых нет. `git diff --check` и проверка локальных ссылок прошли.

Полные инструментальные проверки Android 12/API 31 и Android 16/API 36 прошли: по 47/47 тестов. Первый полный прогон Android 12/API 31 прошёл 46/47: тест виджета ожидал верхнюю ручку на границе верхнего виджета и не учитывал её размещение внутри безопасной области. Ожидание исправлено; повторный полный прогон прошёл все 47 тестов без изменения рабочего кода виджетов.

HomeSurfaceTest проверяет всю безопасную высоту для избранного, отсутствие трёх кнопок и остаточного резерва алфавита, заполнение свободного места, свайп вверх, удержание, клавиатуру и именованные доступные действия. Проверены портрет, узкий экран 945×2100 с font scale 1.3, левосторонний режим и landscape на выделенных API 31/API 36 эмуляторах. Параметры дисплея восстанавливаются после сценариев. Нативные снимки и логи хранятся локально в `.impeccable/review/no-footer/`.

Результаты smoke итогового подписанного APK в портрете, узком окне/font scale 1.3 и landscape на API 31 и API 36, проверки подписи, состава и SHA-256 фиксируются в GitHub Release.

## APK и ограничения

Версия: `0.2.0-rc.57`, versionCode `66`. Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон пользователя, Todoist и остальные сторонние виджеты со скриншота не проверены. Полная проверка TalkBack, OEM и рабочих профилей не выполнена; полный паритет Niagara не заявляется.
