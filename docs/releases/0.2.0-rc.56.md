# Better Launcher 0.2.0-rc.56

## Изменения

- Со страницы виджетов удалены заголовок «Виджеты», кнопки назад, добавления и перестановки, а также нижняя кнопка «На главный экран».
- Список занимает всю доступную высоту между системными панелями без дополнительных верхних и нижних отступов. Боковые поля 28 dp, сохранённые размеры, размещение и настраиваемые промежутки виджетов сохраняются.
- Долгое нажатие на пустое место сразу открывает выбор нового виджета: работают свободная нижняя часть страницы, промежутки между виджетами и боковые поля. Пустая страница показывает только подсказку об удержании.
- Для клавиатуры доступны Menu/Shift+F10 при фокусе на свободной области, для accessibility — именованное действие «Добавить виджет». Удержание самого виджета по-прежнему открывает управление им; его обычные нажатия и прокрутка сохраняются.
- Перестановка запускается через «Изменить порядок» в меню удержания виджета. Back или удержание свободного места завершает перестановку. Свайп влево и системный Back возвращают на главный экран, HOME всегда открывает главный экран.
- Формат backup и AppWidgetHost ID не меняются.

## Проверки

Прошли debug assembly, все 15 unit-тестов и debug lint: 0 ошибок, 27 прежних предупреждений, новых нет.

На выделенных эмуляторах Android 12/API 31 и Android 16/API 36 прошли по 26 инструментальных тестов: свободное место на странице, клавиатура/accessibility, удержание самих виджетов, навигация и HOME, раздельные меню приложений, перестановка работающих виджетов, общий отступ, хранение/backup и системная транслитерация.

Проверка страницы измеряет отсутствие резерва под панели, начало первого виджета на безопасной верхней границе и доступность пустого места до нижней системной границы. Удержание промежутка между двумя провайдерами и нижней части заполненной/пустой страницы открывает выбор; отмена выбора не выделяет новых widget IDs. Отдельно проверены узкие окна 945×2100 с font scale 1.3 и landscape на обеих версиях Android; параметры дисплея восстановлены. Нативные снимки и логи хранятся локально в `.impeccable/review/widget-page/`.

Первый прогон выявил отсутствие клавиатурного фокуса после касания; оно исправлено и проверено повторно. В первом Android 12 прогоне тест перестановки завершился таймаутом lifecycle при закрытии ActivityScenario; после переустановки актуального APK и явного назначения HOME оба окончательных прогона прошли.

Результаты smoke итогового подписанного APK в портрете, узком окне/font scale 1.3 и landscape на API 31 и API 36, проверки подписи, состава и SHA-256 фиксируются в GitHub Release.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Геометрия проверена с нативным тестовым провайдером. Физический телефон пользователя, Todoist и погодный провайдер со скриншота не проверены. Полная проверка TalkBack и рабочих профилей не выполнена; полный паритет Niagara не заявляется.
