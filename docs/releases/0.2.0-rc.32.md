# Better Launcher 0.2.0-rc.32

Единый стиль меню по всплывающей панели долгого удержания ярлыка. Version code — 41; Android 12+ (API 31), target API 36.

## Изменения

- В AGENTS.md закреплён общий стиль всех меню Better Launcher: тёмно-синяя нижняя панель, светло-голубые подписи и контурные значки, скруглённые верхние углы, растущие строки и одинаковая анимация.
- Общие компоненты заголовка, поверхности, действия и показа используются в меню приложения/виджета, папок, уведомлений/shortcuts, выбора приложений и вариантов, управления избранным, выбора виджета, погоды/календаря и редактирования названий.
- Полноэкранные настройки используют ту же палитру; поля, checkboxes, Material-переключатели и алфавит выбора виджетов согласованы с ней. Настоящие значки приложений и внешний вид сторонних превью сохраняются.
- Все нижние панели поднимаются с одинаковой анимацией, учитывают системные bars/cutouts и клавиатуру, ограничивают высоту и сохраняют прокрутку. Выбор виджета держит заголовок отдельно от внутреннего списка. Back/HOME, закрытие и автосохранение сохраняют прежние сценарии.
- Сохранены системный CLOCK_TICK при изменении размера виджета из rc.30 и перестановка прямо на экранах из rc.31. IDs приложений/профилей/виджетов, формат backup, разрешения и зависимости сохранены.
- Системные разрешения, выбор файлов, внешняя конфигурация и содержимое сторонних виджетов оформляются их владельцами.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов; lint — 0 ошибок и 27 прежних предупреждений, новых нет. Layout detector на изменённых исходниках не нашёл замечаний. `git diff --check` и ссылки документации проверены.

Итоговый полный instrumentation suite на выделенных Android 12/API 31 и Android 16/API 36 прошёл: по 30 из 30 тестов, включая системную транслитерацию, сохранность backup/профилей/виджетов, переименование, Back/HOME и inline-перестановку из rc.31. В первых прогонах встречались остановка тестового процесса, оставшиеся fixture-виджеты, таймауты ActivityScenario и превью. Повторные изолированные проверки прошли. Проверка переименования теперь дожидается домашней строки, принимающей долгое нажатие: закрывающаяся панель могла кратко возвращать прежний accessibility-заголовок. Проверки сохранения/сброса имени и отмены Back/HOME сохранены; после исправления ожидания оба полных набора успешны.

Визуальные сценарии на API 31 и API 36 проверены в портрете, на узком экране с font scale 1.3 и в landscape: настройки, выбор шрифта, управление избранным, редактор с клавиатурой, выбор виджета, погода, меню приложения, уведомления/shortcuts и выбор приложений. В landscape системная клавиатура может использовать собственный полноэкранный редактор. После проверки восстановлены размер экрана, масштаб шрифта и настройки клавиатуры. Итоговые параметры подписанного APK и результат smoke-сценария публикуются в описании GitHub Release.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. APK собирается из чистого коммита main, опубликованного в origin/main; тег указывает на этот коммит. Сохраняется прежний сертификат для совместимых обновлений.

Физические устройства, OEM, рабочие профили и полная проверка TalkBack остаются вне подтверждённого покрытия. Production-сертификат и магазин не настроены; полный паритет Niagara не заявляется.
