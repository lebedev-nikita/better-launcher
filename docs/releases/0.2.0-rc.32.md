# Better Launcher 0.2.0-rc.32

Unified menus based on the shortcut long-press bottom panel. Version code: 41; Android 12+ (API 31), target API 36.

## Changes

- AGENTS.md specifies shared Better Launcher menu styling: navy bottom panel, light-blue labels/outline icons, rounded top corners, growing rows and matching animation.
- Shared heading/surface/action/presentation components serve app/widget menus, folders, notifications/shortcuts, app/option selection, favorites management, widget picker, weather/calendar and name editing.
- Full-screen Settings uses the same palette; fields, checkboxes, Material toggles and widget-picker alphabet match. Real app icons/third-party previews retain their appearance.
- Bottom panels use matching rise animations, respect bars/cutouts/keyboard, limit height and preserve scrolling. Widget picker keeps heading outside the list. Back/HOME, dismissal/autosave retain behavior.
- Preserves rc.30 CLOCK_TICK resizing and rc.31 in-place ordering. App/profile/widget IDs, backup format, permissions/dependencies unchanged.
- System permissions, file selection, external configuration and third-party widget content remain owner-styled.
