# Better Launcher 0.2.0-rc.32

Единый стиль меню по всплывающей панели долгого удержания ярлыка. Version code — 41; Android 12+ (API 31), target API 36.

## Изменения

- В AGENTS.md закреплён общий стиль всех меню Better Launcher: тёмно-синяя нижняя панель, светло-голубые подписи и контурные значки, скруглённые верхние углы, растущие строки и одинаковая анимация.
- Общие компоненты заголовка, поверхности, действия и показа используются в меню приложения/виджета, папок, уведомлений/shortcuts, выбора приложений и вариантов, порядка избранного/виджетов, выбора виджета, погоды/календаря и редактирования названий.
- Полноэкранные настройки используют ту же палитру; поля, checkboxes, Material-переключатели и алфавит выбора виджетов согласованы с ней. Настоящие значки приложений и внешний вид сторонних превью сохраняются.
- Все нижние панели поднимаются с одинаковой анимацией, учитывают системные bars/cutouts и клавиатуру, ограничивают высоту и сохраняют прокрутку. Редакторы порядка и выбор виджета держат заголовок/действия отдельно от внутреннего списка. Back/HOME, закрытие и автосохранение сохраняют прежние сценарии.
- Сохранён системный CLOCK_TICK при изменении размера виджета из rc.30. IDs приложений/профилей/виджетов, формат backup, разрешения и зависимости сохранены.
- Системные разрешения, выбор файлов, внешняя конфигурация и содержимое сторонних виджетов оформляются их владельцами.

## Проверки

Результаты итоговой проверки будут зафиксированы перед публикацией.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. APK собирается из чистого коммита main, опубликованного в origin/main; тег указывает на этот коммит. Сохраняется прежний сертификат для совместимых обновлений.

Физические устройства, OEM, рабочие профили и полная проверка TalkBack остаются вне подтверждённого покрытия. Production-сертификат и магазин не настроены; полный паритет Niagara не заявляется.
