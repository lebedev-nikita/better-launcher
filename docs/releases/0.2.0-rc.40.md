# Better Launcher 0.2.0-rc.40

Плоский список действий в меню долгого удержания приложения. Version code — 49; Android 12+ (API 31), target API 36.

## Изменения

- Пункт «Дополнительно» удалён. «Приложения во всплывающем меню» и «Скрыть приложение» доступны в общем списке сразу при открытии меню.
- Сохранены порядок остальных команд, вход в перестановку избранного, переименование по нажатию на заголовок, разделитель перед настройками, общие оформление и анимация.
- На небольших экранах и при крупном шрифте команды доступны через прокрутку панели.
- Проверки меню обновлены: они проверяют доступность команд без раскрытия дополнительного раздела и отсутствие самого пункта.

## Проверки

Результаты сборки, unit/instrumentation-тестов, lint и native UI записываются после завершения проверок. Локальные логи и снимки: `.impeccable/review/flat-menu/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного коммита main; размер, коммит и SHA-256 указаны в GitHub Release. Прежний сертификат сохраняется для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
