# Better Launcher 0.2.0-rc.31

Ordering directly on favorites and widget pages. Version code: 40; Android 12+ (API 31), target API 36.

## Changes

- Change favorites order activates home editing. Apps/folders remain in their list; each row gets ≡ and up/down arrows. Done stays in footer.
- Widget-page heading ≡ enables in-place ordering of live widgets. Content stays visible; bindings/sizes remain. Done in heading.
- Drag shows the real item's new position; edge scrolling available. Release/arrows save order. Cancellation restores positions without writing. Back finishes; HOME returns normal home.
- Arrows have 48dp areas, named keyboard/accessibility actions and disabled boundary states. Unavailable apps/profiles stay saved. App-selection/folder-creation settings remain.
- Removes separate ordering popup.
