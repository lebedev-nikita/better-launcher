# Better Launcher 0.2.0-rc.31

Перестановка прямо на экране избранного и странице виджетов. Version code — 40; Android 12+ (API 31), target API 36.

## Изменения

- «Изменить порядок избранного» включает режим на главном экране. Сами приложения и папки остаются в списке; под каждой строкой появляются ручка ≡ и стрелки вверх/вниз. «Готово» закреплено в нижней панели.
- ≡ в заголовке страницы виджетов включает перестановку работающих виджетов прямо на этой странице. Их содержимое остаётся видимым, привязки и размеры сохраняются. «Готово» находится в заголовке.
- Перетаскивание показывает новое положение реального элемента; возле краёв списка работает прокрутка. Отпускание и стрелки сохраняют порядок. Отмена жеста восстанавливает прежние позиции без записи. Back завершает режим, HOME возвращает обычный главный экран.
- Стрелки имеют 48dp области, именованные keyboard/accessibility-действия и отключённые граничные состояния. Недоступные приложения/профили остаются в сохранённом списке. Настройки выбора приложений и создания папок сохраняются.
- Отдельное всплывающее окно перестановки удалено.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов, lint — 0 ошибок и 27 существующих предупреждений, новых нет. Layout detector — без замечаний.

Полный instrumentation suite прошёл на выделенных Android 12/API 31 и Android 16/API 36: по 30 из 30 тестов. Обновлённые FavoritesOrderTest и WidgetOrderTest проверяют настоящие touch drag и доступные стрелки, отмену жеста, папки и недоступные профили, сохранение после пересоздания/backup, Back/HOME, неизменность home ID и геометрии, те же экземпляры AppWidgetHostView и живые RemoteViews-обновления.

В первых запусках были сбой System UI при холодном старте, таймауты завершения ActivityScenario и ожидания существующего теста переименования. Эмуляторы перезапущены с программным рендерером; тест выхода из inline-режима ожидает исчезновения его ручек, прежде чем читать новую accessibility-геометрию. Финальные полные прогоны успешны.

На обеих версиях прошёл UI-сценарий реальных приложений/виджетов: drag и стрелки на месте, сохранение после остановки процесса, Back/HOME, портрет, 945×2100/font scale 1.3, landscape и левосторонний алфавит. Проверены нативные снимки; настройки экрана восстановлены, тестовые виджеты удалены. Локальные материалы — `.impeccable/review/inline-order/`.

## APK и ограничения

На обоих эмуляторах прошли перестановка избранного в release-сборке и `scripts/smoke-test.py`: навигация, Back/HOME, поиск/IME, запуск Camera, меню/переименование и алфавит.
