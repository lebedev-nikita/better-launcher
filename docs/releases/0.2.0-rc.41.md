# Better Launcher 0.2.0-rc.41

Локальная подготовка; отдельно не опубликована. Изменение вошло в [опубликованный rc.42](https://github.com/better-launcher/better-launcher/releases/tag/v0.2.0-rc.42).

Плоский список действий в меню долгого удержания приложения. Version code — 50; Android 12+ (API 31), target API 36.

## Изменения

- Пункт «Дополнительно» удалён. «Приложения во всплывающем меню» и «Скрыть приложение» доступны в общем списке сразу при открытии меню.
- Сохранены порядок остальных команд, вход в перестановку избранного, переименование по нажатию на заголовок, разделитель перед настройками, общие оформление и анимация.
- На небольших экранах и при крупном шрифте команды доступны через прокрутку панели.
- Сохранены изменения main: поиск виджетов, поиск скрытых приложений с действием «Показывать снова» и упрощённое меню виджета из rc.38–rc.40.
- Проверки меню обновлены: они проверяют доступность команд без раскрытия дополнительного раздела и отсутствие самого пункта.

## Проверки

- После интеграции rc.38–rc.40 debug APK и test APK собраны; все 15 unit-тестов прошли.
- Debug lint: 0 ошибок и 27 прежних предупреждений; новых предупреждений нет.
- Ссылки изменённой документации, JSON sidecar и `git diff --check` проверены.
- Android 12/API 31: полный instrumentation-прогон завершён с результатом 30/32. Проверка стартовой анимации меню прошла отдельно. У проверки алфавита виджетов исправлен критерий для последнего раздела: целевая строка должна быть видимой, но не обязана находиться сверху при ограничении прокрутки концом списка; исправленная проверка прошла отдельно.
- Начальный прогон с HOME лаунчера прервался после ошибок тестов и системной ошибки Activity transaction; полный повтор использовал системный HOME. Первоначальный холодный запуск эмулятора и UI Automation также были нестабильны при нагрузке. Эти попытки не считаются успешными.
- Подписанный APK на Android 12/API 31: полный smoke прошёл в портрете и на экране 945×2100/font scale 1.3. В landscape 2340×1080 проверены плоское меню, прокрутка к нижним командам, редактор имени и отмена через HOME; полный smoke остановился на жесте алфавита, этот шаг не считается проверенным. Размер, масштаб и ориентация восстановлены.
- UI-скрипт использует свободный промежуток footer для перехода между страницами в коротких окнах и скрывает IME перед проверкой «Сохранить». Изменения относятся к проверке; логика этих жестов и редактора не менялась.
- Подписанный локальный rc.41 на Android 16/API 36: полный smoke прошёл в портрете, на узком экране/font scale 1.3 и в landscape после уточнения координат проверочного жеста и обработки IME.
- Скачанный опубликованный rc.42: подпись и контрольная сумма из опубликованного SHA256SUMS.txt подтверждены. Реализация showAppMenu совпадает с проверенным rc.41; плоское меню отдельно проверено на API 36 во всех трёх конфигурациях и при левом алфавите. Native-снимки основной матрицы проверены; снимок левого режима попал в анимацию и не используется как визуальное подтверждение. Локальные логи и снимки: `.impeccable/review/flat-menu/`.

## APK и ограничения

Локальный подписанный rc.41 с R8 и удалением неиспользуемых ресурсов собран из чистого коммита main `2c2196c`, уже опубликованного в origin/main. После публикации rc.42 устаревший rc.41 отдельно не выпускался. Подписанный APK rc.42 доступен в GitHub Release; прежний сертификат подтверждён для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
