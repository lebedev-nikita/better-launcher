# Better Launcher 0.2.0-rc.8

Релиз-кандидат плавного меню приложения и переименования через заголовок.

## Изменения

- Меню долгого удержания после расчёта системных отступов поднимается снизу за 300 мс с мягким замедлением и уходит вниз за 180 мс. Панель использует нативный property animator, затемнение и закрытие — анимацию окна Android; кадровые изменения размеров не используются.
- При отключённых системных анимациях меню открывается сразу.
- Нажатие на название приложения в заголовке открывает переименование. Название имеет доступную подпись, фокус с клавиатуры, ripple и минимальную высоту касания 48 dp.
- Отдельный пункт «Переименовать» удалён. В «Дополнительно» остались прикреплённые приложения и скрытие.
- Сохраняются системная Android ICU, оптимизация R8 и удаление неиспользуемых ресурсов, исправление нижней границы алфавита и превью виджетов с общим алфавитным выбором из текущей ветки разработки.

## Установка

Скачайте `better-launcher-0.2.0-rc.8-release.apk` из [этого релиз-кандидата](https://github.com/better-launcher/better-launcher/releases/tag/v0.2.0-rc.8). versionCode — 17, minSdk — 31, targetSdk — 36. Это подписанная release-сборка с прежним сертификатом для совместимости обновлений, без отладочного режима. `SHA256SUMS.txt` содержит SHA-256 APK.

Релиз помечен как pre-release. Стабильные выпуски сохраняются отдельно; этот релиз-кандидат не меняет Latest. Полный паритет Niagara и точное совпадение его таймингов не заявляются: исходный образец предоставлен статическим скриншотом.

## Проверки

Сборка debug/release, 4 unit-теста, 19 тестов на выделенном Android 12 и lint прошли. Lint: 0 ошибок, 27 существующих предупреждений; новых от изменения меню нет.

Подписанный APK прошёл полный smoke и сценарии меню на Android 12: портрет, 320 dp ширины / font scale 1.3, landscape, отключённые анимации, клавиатура и алфавит слева. Открытие/закрытие проверено по записи кадров. На Android 16 прошли сценарии меню в портрете, landscape и без анимаций; полный smoke и узкий экран не подтверждены из-за нестабильности System UI/UI Automator и незавершённого сценария свайпа pop-up. Физический телефон отдельно не проверен.

Подробный отчёт: [проверка меню](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.8/docs/app-menu-motion-verification.md).
