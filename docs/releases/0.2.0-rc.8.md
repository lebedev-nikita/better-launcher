# Better Launcher 0.2.0-rc.8

Release candidate for smooth app menus and renaming through the heading.

## Changes

- After system-inset calculation, the long-press menu rises from below over 300 ms with gentle deceleration and exits downward over 180 ms. The panel uses a native property animator; dimming/dismissal use Android window animation. No per-frame size changes.
- With system animations disabled, the menu opens immediately.
- Tapping the app-name heading opens renaming. It has an accessible label, keyboard focus, ripple and minimum 48 dp touch height.
- Removes the separate Rename action. More retains attached apps and hiding.
- Preserves system Android ICU, R8/unused-resource removal, the lower alphabet-boundary fix and widget previews with shared alphabet selection from current development.

## Installation

Download `better-launcher-0.2.0-rc.8-release.apk` from [this candidate](https://github.com/better-launcher/better-launcher/releases/tag/v0.2.0-rc.8). versionCode: 17, minSdk: 31, targetSdk: 36. Signed release build with the previous compatible certificate and no debug mode. `SHA256SUMS.txt` contains the APK SHA-256.

Marked pre-release. Stable releases remain separate; this candidate does not change Latest. Full Niagara parity or exact timing equivalence is not claimed: the reference was a static screenshot.

## Verification

Debug/release builds, 4 unit tests, 19 tests on dedicated Android 12 and lint passed. Lint: 0 errors, 27 existing warnings; no new menu warnings.

Signed APK passed full smoke and Android 12 menu scenarios: portrait, 320 dp width/font scale 1.3, landscape, animations disabled, keyboard and left alphabet. Opening/closing was checked through frame recording. Android 16 passed menu scenarios in portrait, landscape and without animations; full smoke/narrow screen remain unconfirmed due to System UI/UI Automator instability and an incomplete popup-swipe scenario. A physical phone was not independently checked.
