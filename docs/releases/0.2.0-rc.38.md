# Better Launcher 0.2.0-rc.38

Text search when adding widgets. Version code: 47; Android 12+ (API 31), target API 36.

## Changes

- Search widgets stays above previews for home/widget-page selection. Results update as typed; adjacent button clears query.
- Matches widget/app names, case/diacritics insensitive. All query words must occur across these names. Empty query restores full list.
- Alphabet matches results; no matches hides it and offers changing/clearing query. Queries entered before catalog loading apply after completion.
- Keyboard opens on field tap; Done hides it without adding. Field/heading stay above scroll previews; system binding/configuration unchanged.
- Existing search index normalizes names in background. Search allocates no widget IDs; result changes cancel stale preview loads, closing cancels all work.
- Preserves rc.35–rc.37: no duplicate favorites-order button, transparent dragged rows, empty alphabet sections including # hidden.
