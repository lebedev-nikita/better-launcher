# Better Launcher 0.2.0-rc.38

Текстовый поиск при добавлении виджета. Version code — 47; Android 12+ (API 31), target API 36.

## Изменения

- Поле «Поиск виджетов» закреплено над превью в выборе виджета для главного экрана и страницы виджетов. Результаты обновляются при вводе; кнопка рядом очищает запрос.
- Поиск учитывает название виджета и приложения, регистр и диакритика не влияют на совпадение. Все слова запроса должны встречаться в одном из этих названий. Пустой запрос возвращает весь список.
- Алфавит соответствует результатам. Если совпадений нет, он скрывается, а панель предлагает изменить или очистить запрос. Запрос, введённый до загрузки каталога, применяется после её завершения.
- Клавиатура появляется при нажатии на поле. «Готово» скрывает её без добавления виджета. Поле и заголовок остаются над прокручиваемыми превью; существующие системные привязка и конфигурация сохранены.
- Нормализация названий готовится в фоне через существующий поисковый индекс. Поиск не выделяет widget IDs; смена результатов отменяет устаревшие загрузки превью, закрытие отменяет все работы.
- Сохранены изменения rc.35–rc.37: убрана дублирующая кнопка порядка избранного, строки при перетаскивании прозрачны, пустые разделы алфавита скрыты, включая #.

## Проверки

- До интеграции rc.37 debug assembly, 14 unit-тестов и debug lint — успешно: 0 ошибок, 27 прежних предупреждений, новых нет.
- Поиск и системная нормализация на Android 12/API 31 — 7/7: запрос до загрузки, название приложения и виджета, несколько слов, кириллица, очистка, пустой результат, возврат полного списка, выбор отфильтрованного провайдера и сохранение набора widget IDs.
- Первый тест превью на API 31 остановился при ожидании картинки после прокрутки. Повторный полный набор выбора/нормализации прошёл; ожидание перехода к разделу уточнено, чтобы не удерживать строку, ещё ожидающую переиспользования.
- Холодные эмуляторы и UI Automation прерывались на перегруженной машине; начальный connected-запуск API 36 не нашёл выключенное устройство. Эти попытки не считаются успешными. Финальные проверки объединённого кода, матрица native UI, smoke и проверка подписанного APK записываются в GitHub Release. Локальные логи и снимки — `.impeccable/review/widget-search/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. APK собирается из чистого опубликованного коммита main; точные коммит, размер и SHA-256 указаны в GitHub Release. Прежний сертификат сохраняется для совместимости обновлений. Физический телефон/OEM, полный TalkBack-сеанс и все сторонние провайдеры не проверены; полный паритет Niagara не заявляется.
