# Better Launcher 0.2.0-rc.38

Поиск скрытых приложений и возврат через меню удержания. Version code — 47; Android 12+ (API 31), target API 36.

## Изменения

- Скрытые приложения доступны в результатах непустого поиска по исходному названию и псевдониму. Пустой список всех приложений и алфавит по-прежнему исключают их.
- В меню долгого удержания скрытого результата сразу доступно «Показывать снова» с контурным значком глаза. Действие снимает скрытие, сохраняет текущий запрос и список результатов, не добавляет приложение в избранное.
- Для видимых приложений сохранено «Скрыть приложение» в «Дополнительно» и отмена скрытия. Формат backup и идентификаторы приложений с профилем не меняются.
- Сохранены изменения main: прозрачное перетаскивание избранного из rc.36 и только заполненные разделы алфавита, включая #, из rc.37.

## Проверки

- Регрессионный unit-тест сначала воспроизвёл отсутствие скрытого результата: приложение исключалось до сопоставления запроса. Теперь единый подготовленный индекс хранит все приложения, а фильтр скрытия применяется к пустому списку и разделам.
- Объединённый исходник: `:app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug` — успешно; 15 unit-тестов, 0 ошибок lint, 27 прежних предупреждений, новых нет.
- Добавлены инструментальные проверки поиска по имени/псевдониму, пустого запроса, перезагрузки каталога и полного пути «скрыть → найти → удержать → показывать снова» с сохранением запроса и избранного.
- Запуск connected/UI на выделенных Android 12/API 31 и Android 16/API 36 задержан сбоями тестовой среды: Watchdog перезапускал system_server до запуска лаунчера, установка APK обрывалась; один эмулятор завершился со сбоем графического backend. Эти попытки не являются успешными проверками. Фактический результат последующих запусков и signed-APK проверок указан в GitHub Release; непрошедшие сценарии остаются непроверенными.
- `git diff --check`, локальные ссылки и JSON sidecar проверены. Логи и native UI evidence хранятся локально в `.impeccable/review/hidden-search/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного main; коммит, размер, SHA-256, сертификат и состав указаны в GitHub Release. Прежний сертификат Android Debug сохраняется для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM, рабочие профили и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
