# Better Launcher 0.2.0-rc.46

Swipe-dismissable messages lasting at most three seconds. Version code: 55; Android 12+ (API 31), target API 36.

## Changes

- All Better Launcher messages, including App hidden, dismiss with horizontal swipes either way. Text follows finger/fades; short/canceled gestures restore position.
- Messages with Undo or no action disappear within three seconds. Holding does not extend expiry. New messages replace old; old timers cannot close new ones.
- Swipe/dismiss preserves action result; Undo restores hidden apps. Focused Escape/Delete and accessibility dismissal available.
- Messages respect system/cutout/IME insets, wrap long text and remove timers on dismissal/leaving screen.
- Preserves current main: hidden-app/widget-provider search, simplified widget/flat app menus.
