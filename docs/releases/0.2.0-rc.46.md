# Better Launcher 0.2.0-rc.46

Раздельные меню иконки и названия, свайп вправо к виджетам и стабильное удержание при обновлении каталога. Version code — 55; Android 12+ (API 31), target API 36.

## Изменения

- Удержание иконки открывает уведомления, быстрые действия и прикреплённые приложения; удержание названия — управление ярлыком.
- Свайп вправо на главном экране, включая иконки, названия и папки, открывает виджеты. Горизонтальное движение больше не открывает меню и отменяет обычное нажатие, чтобы не запустить приложение случайно. Свайп влево на странице виджетов возвращает домой.
- Иконка остаётся 38dp внутри отдельной области 48dp; область названия имеет высоту минимум 48dp. Нажатия запускают приложение, режим перестановки и жесты сторонних виджетов сохраняются.
- При скрытых иконках быстрые действия доступны через именованное accessibility-действие названия и команду меню управления.
- Обновление каталога или уведомлений больше не удаляет строку из-под удерживаемого пальца: главный экран обновляется после окончания касания и закрытия меню, сохраняя прокрутку. Ошибка подтверждена диагностикой на холодном запуске и отдельным регрессионным тестом.
- Сохранены изменения main, включая плоское меню управления, отсутствие дублирующей команды запуска, свайпы временных сообщений и компактный поиск виджетов. Обновлены документация, sidecar и smoke-сценарий.

## Проверки

До итогового объединения прошли debug/test APK, все 15 unit-тестов и lint: 0 ошибок, прежние 27 предупреждений. После исправления обновления экрана на Android 12 прошли все 9 тестов жестов, навигации, перестановки и меню. Регрессионный тест обновления во время удержания сначала воспроизвёл ошибку, затем прошёл с исправлением. В существующих UI-тестах добавлено ожидание фокуса диалога и завершённой раскладки после Back.

Итоговые проверки объединённого исходника, native UI подписанного APK на Android 12/API 31 и Android 16/API 36, release lint и характеристики опубликованного APK записаны в GitHub Release. Локальные логи и снимки: `.impeccable/review/menus/`. Ранние прогоны прерывались из-за перегрузки машины; чужие эмуляторы не останавливались. Отдельные первые прогоны выявили и подтвердили исправленную ошибку обновления каталога и преждевременные UI-проверки; они не считаются успешными.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита main, уже опубликованного в origin/main; тег указывает на этот коммит. Сертификат совместим с предыдущими выпусками. SHA-256, размер и сравнение состава приведены в GitHub Release. Прежний сертификат Android Debug сохранён для совместимости; production-сертификат и магазин не настроены. Физические телефоны/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется. Формат backup, профили приложений и widget IDs не меняются.
