# Better Launcher 0.1.5

Updates the app long-press menu using the supplied Niagara reference.

## Changes

- Dark navy surface with rounded top corners, light-blue text and original outline icons.
- The installed-app icon appears beside its name; Back, HOME or an outside tap dismisses the menu.
- Favorites, app information, notifications/quick actions and uninstall are immediately available. More expands renaming, attached apps and hiding in place.
- Better Launcher settings sit below a divider. Rows grow with text; the menu scrolls on short screens and with large fonts.
- Preserves alphabet transliteration and adjustable wallpaper dimming from previous patches, as well as the separate left widget screen and single home widget previously added to `main`. See [widget verification](https://github.com/better-launcher/better-launcher/blob/v0.1.5/docs/widgets-verification.md).

## Installation

Download `better-launcher-0.1.5-debug.apk` from the release assets and install over 0.1.3 or 0.1.4. Signing matches the previous published APK; normal updates preserve settings. Minimum: Android 12 (API 31), versionCode: 7, targetSdk: 36. `SHA256SUMS.txt` contains the APK SHA-256.

Uses the previous debug key. Production signing and store publishing are not configured yet.

## Verification and limitations

The build, 9 unit tests, 11 connected tests on Android 12 and lint pass: 0 errors, 27 existing warnings, no new warnings. Appearance was checked on Android 12 in portrait, on a narrow screen with font scale 1.3 and in landscape before the final alphabet/dimming merge. The final APK passed a full Android 12 UI smoke rerun. Android 16 UI runs were interrupted by system-process restarts and System UI ANRs. Actual device/UI checks are described in the [menu report](https://github.com/better-launcher/better-launcher/blob/v0.1.5/docs/app-menu-verification.md).

Physical phones, full TalkBack coverage and work profiles were not checked. The menu color matches the supplied reference and does not yet adapt to other wallpapers. Niagara screen time and categories are not implemented; full functional parity is not claimed. Current coverage: [features.md](https://github.com/better-launcher/better-launcher/blob/v0.1.5/docs/features.md).
