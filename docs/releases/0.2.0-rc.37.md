# Better Launcher 0.2.0-rc.37

Контекстное меню виджета без лишних действий. Version code — 46; Android 12+ (API 31), target API 36.

## Изменения

- Из меню долгого удержания виджета убраны «О приложении» и «Добавить виджет» на главном экране и странице виджетов.
- Сохранены перемещение и изменение размера, настройки провайдера при наличии, удаление и переход в настройки Better Launcher. На странице виджетов также доступны назначение на главный экран и порядок нескольких виджетов.
- Добавление доступно через кнопку «+» и пустое состояние страницы виджетов, а выбор главного виджета — через настройки. «О приложении» остаётся в меню приложения.
- Сохранены изменения rc.35–rc.36: вход в порядок избранного через меню удержания и прозрачный фон избранного при перетаскивании.

## Проверки

- Debug APK собран; 14 unit-тестов прошли.
- Итоговые результаты debug/release lint, connected-тестов и native UI на Android 12/API 31 и Android 16/API 36 записываются в GitHub Release. Локальные снимки и логи: `.impeccable/review/rc37/`.
- Размер подписанного APK, коммит и SHA-256 указываются в GitHub Release.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного main; тег указывает на этот коммит. Прежний сертификат сохранён для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
