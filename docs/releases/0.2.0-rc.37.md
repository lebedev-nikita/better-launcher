# Better Launcher 0.2.0-rc.37

Скрытие всех пустых разделов алфавитного индекса, включая #. Version code — 46; Android 12+ (API 31), target API 36.

## Изменения

- Индекс приложений и выбора виджетов показывает только заполненные разделы A–Z и #. Решётка больше не добавляется безусловно и исчезает, когда соответствующих видимых приложений или виджетов нет.
- ★ сохраняет действие возврата к избранному или началу списка. Отпускание пальца ниже индекса выбирает последний заполненный раздел; обе стороны, отмена жеста и тактильный отклик сохраняются.
- Добавлены регрессионные проверки пустого каталога, индекса без #, заполненного #, скрытия и переименования последнего приложения этого раздела и отпускания ниже последней буквы.
- Сохранены изменения rc.35 и rc.36: вход в перестановку через меню удержания без дублирующей кнопки и прозрачные строки избранного во время перетаскивания.

## Проверки

- Новый unit-сценарий воспроизвёл ошибку до исправления: для раздела B возвращалось ★, B, #. После исправления он проходит.
- Debug assembly, 14 unit-тестов и debug lint после исправления и интеграции rc.35 — успешно. Lint: 0 ошибок, 27 прежних предупреждений; новых нет.
- Начальный полный instrumentation-прогон API 31 прерван после таймаутов существующих тестов меню на перегруженном эмуляторе. Этот прогон не считается успешным; устройство перезапущено с меньшим объёмом памяти.
- Результаты повторных проверок итогового кода, native UI на Android 12/API 31 и Android 16/API 36 и подписанного APK записываются в GitHub Release. Локальные логи и снимки сохраняются в `.impeccable/review/empty-index/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного коммита main; размер, коммит и SHA-256 указаны в GitHub Release. Прежний сертификат сохраняется для совместимости обновлений. Production-сертификат, магазин, физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
