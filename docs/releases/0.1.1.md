# Better Launcher 0.1.1

Patch release for Android 12+.

## Changes

- The home screen uses Android's system wallpaper; choosing wallpaper opens the Android system screen.
- Built-in home-screen clock and date were removed; the time remains in Android's status bar.
- Favorites occupy the released space. A gap before the list remains only when weather, a widget or music is present.
- Clock-size and 24-hour-format settings and the system-time-change handler were removed. Weather refresh remains.
- Calendar is available through Settings → Calendar. Old backups containing clock options are still accepted.

## Installation

Download `better-launcher-0.1.1-debug.apk` from the release assets and install it on Android 12+. Select Better Launcher as the home app in Android settings after installation. `SHA256SUMS.txt` contains the APK checksum.

The APK uses the previous local debug key and is intended for testing. Production signing and store distribution are not configured yet.

## Verification and limitations

- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` passed; 3 unit tests, 0 errors.
- Lint: 0 errors, 27 warnings; no new warnings. Version 0.1.0 had 35 warnings.
- Updating the published 0.1.0 APK on Android 12 and Android 16 preserves SharedPreferences; the signing certificate is unchanged.
- Smoke tests on Android 12 / API 31 (`emulator-5586`) and Android 16 / API 36 (`emulator-5584`) covered absent clock/date, Settings/Back, search, Camera launch/HOME, swipe menu, long press and alphabet navigation; no Better Launcher crashes occurred.
- Home was checked in portrait, on a narrow 945×2100 screen with font scale 1.3, in landscape, and with the left alphabet. Calendar and weather are available in Settings; clock toggles are absent. Temporary size, font scale and orientation changes were restored.
- `apksigner verify`: valid v2 signature; the APK SHA-256 is in `SHA256SUMS.txt`.

Alphabet geometry limitations remain: on a narrow screen with font scale 1.3 it approaches the Settings button, and in landscape it approaches side system navigation. Physical-device and TalkBack checks were not performed; connected storage tests were not run for this patch.

Full Niagara parity and physical-device verification remain incomplete. See [features](https://github.com/better-launcher/better-launcher/blob/v0.1.1/docs/features.md) and the [historical 0.1.0 report](https://github.com/better-launcher/better-launcher/blob/v0.1.0/docs/verification.md).
