# Better Launcher 0.1.1

Патч-релиз для Android 12+.

## Изменения

- Главный экран использует системные обои Android; выбор обоев открывает системный экран Android.
- Удалены встроенные часы и дата с главного экрана; время остаётся в статус-баре Android.
- Избранное занимает освободившееся место. Промежуток перед списком остаётся только при наличии погоды, виджета или музыки.
- Удалены настройки размера часов и 24-часового формата, а также обработчик изменения системного времени. Обновление погоды сохранено.
- Календарь доступен через настройки → «Календарь». Старые резервные копии с параметрами часов по-прежнему принимаются.

## Установка

Скачайте `better-launcher-0.1.1-debug.apk` из файлов релиза и установите на Android 12+. После установки выберите Better Launcher домашним приложением в настройках Android. `SHA256SUMS.txt` содержит контрольную сумму APK.

APK подписан прежним локальным отладочным ключом и предназначен для тестирования. Production-подпись и выпуск в магазине пока не настроены.

## Проверки и ограничения

- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` — успешно; 3 unit-теста, 0 ошибок.
- Lint: 0 ошибок, 27 предупреждений; новых предупреждений нет. В 0.1.0 было 35 предупреждений.
- Обновление поверх опубликованного APK 0.1.0 на Android 12 и Android 16 сохраняет SharedPreferences; сертификат подписи тот же.
- Smoke-тесты на Android 12 / API 31 (`emulator-5586`) и Android 16 / API 36 (`emulator-5584`): отсутствие часов и даты, настройки/Back, поиск, запуск Camera/HOME, свайп меню, долгое нажатие, алфавит; аварий Better Launcher нет.
- Главный экран проверен в портрете, на узком экране 945×2100 с font scale 1.3, в landscape и с левым алфавитом. Календарь и погода доступны в настройках, переключателей часов нет. Временные размер, масштаб и ориентация восстановлены.
- `apksigner verify`: подпись v2 действительна; SHA-256 APK находится в `SHA256SUMS.txt`.

Сохраняются ограничения геометрии алфавита: на узком экране при font scale 1.3 он сближается с кнопкой настроек, а в landscape — с боковой системной навигацией. Проверка физических устройств и TalkBack не выполнялась; connected-тесты хранения в этом патче не запускались.

Полный паритет Niagara и проверка физических устройств не завершены. Подробности: [возможности](https://github.com/better-launcher/better-launcher/blob/v0.1.1/docs/features.md), [исторический отчёт 0.1.0](https://github.com/better-launcher/better-launcher/blob/v0.1.0/docs/verification.md).
