# Better Launcher 0.2.0-rc.34

Одна ручка перестановки рядом с названием избранного. Version code — 43; Android 12+ (API 31), target API 36.

## Изменения

- Включены изменения rc.32 и rc.33: единое оформление меню/настроек, ожидание свежей строки в тесте переименования и упрощённое меню виджета с четырёхнаправленной иконкой перемещения.

- Ручка ≡ расположена справа на одном уровне с названием приложения или папки, включая длинные названия и предпросмотр уведомления ниже. Дополнительная строка управления убрана; высота избранного снова определяется содержимым строки.
- Видимые кнопки вверх/вниз удалены у избранного и виджетов. На странице виджетов остаётся одна ручка под реальным содержимым.
- При фокусе на ручке клавиши ↑/↓ меняют порядок; экранный диктор предлагает именованные действия перемещения. Граничное действие не предлагается. Дополнительные кнопки и меню для этого не нужны.
- Сохраняются drag/drop, прокрутка у края, отмена незавершённого жеста, автосохранение, Back/HOME и закреплённое «Готово». Привязки/геометрия виджетов, недоступные профили и формат backup сохранены.

## Проверки

- После интеграции rc.32: `:app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов, 0 ошибок и 27 прежних lint warnings, новых предупреждений нет.
- До интеграции rc.33 полные instrumentation suites на выделенных Android 12/API 31 и Android 16/API 36 — по 30/30. Для connected-прогона API 31 временно назначался системный HOME; Better Launcher возвращается как HOME после переустановки основного APK.
- Проверки перестановки подтверждают выравнивание ручки с длинным названием, отсутствие видимых стрелок, drag/drop и отмену, клавиатуру и именованные accessibility-действия, полный список с недоступным ID, backup/recreation, сохранность папки, home-widget ID, геометрии и тех же живых AppWidgetHostView, а также последующее обновление RemoteViews.
- Native UI на обоих эмуляторах: portrait, 945×2100/font scale 1.3, landscape (API 31 — 2160×1080; API 36 — 2400×1080) и левый алфавит. Выравнивание названий/ручек, отсутствие видимых стрелок, drag, прокрутка к последней ручке, Done/Back/HOME и порядок после перезапуска прошли. Размер экрана, font scale, ориентация и сторона алфавита восстановлены, тестовые виджеты удалены. Локальные снимки — `.impeccable/review/handle-order/`.
- До интеграции rc.32 на API 31 встречались таймаут закрытия ActivityScenario (`PAUSED`), системная ошибка `Activity client record must not be null` и таймауты HOME. С временным системным HOME полный набор прошёл 29/30; старый тест переименования не нашёл долгого нажатия на Phone, его отдельный повтор прошёл. Из rc.32 сохранено ожидание свежей домашней строки в этом тесте. Итоговые объединённые наборы прошли целиком; прерванные прогоны не считаются успешными.
- `git diff --check`, JSON sidecar и ссылки документации проверены. Матрица UI выполнена до интеграции rc.32; diff подтверждает сохранение проверенной разметки home/widgets. Итоговые проверки после интеграции rc.33 и подписанного APK записываются в GitHub Release.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного main; точные размер, Git-коммит и SHA-256 указаны в GitHub Release. Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон/OEM и полный TalkBack-сеанс пока не проверены; полный паритет Niagara не заявляется.
