# Better Launcher 0.2.0-rc.59

## Changes

- Icon-menu quick actions show app-supplied icons. Telegram may supply chat avatars with shortcuts; other apps supported too.
- 32 dp icon replaces arrow in existing 48 dp slot. Original colors/shape/system profile badge retained. Loading does not shift text; rows grow with fonts.
- Icons load off main thread. Unavailable icons retain arrow. Results ignored after menu closure/replacement or Activity destruction. No extra permissions/contact reads; launch stays in app profile.
