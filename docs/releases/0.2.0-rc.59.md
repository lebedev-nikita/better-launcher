# Better Launcher 0.2.0-rc.59

## Изменения

- Быстрые действия в меню иконки приложения показывают предоставленные приложением значки. В Telegram это могут быть аватарки бесед, если они опубликованы вместе с shortcut; поддержка работает также для других приложений.
- Значок 32 dp занимает прежний слот 48 dp вместо стрелки. Исходные цвета, форма и системная отметка профиля сохраняются. Текст не смещается при загрузке, строки продолжают расти с крупным шрифтом.
- Значки загружаются вне главного потока. Если значок недоступен, остаётся стрелка. Результат не применяется после закрытия/замены меню или уничтожения Activity. Дополнительные разрешения и чтение контактов не нужны; запуск остаётся в профиле приложения.

## Проверки

Debug APK, 15 unit-тестов и lint прошли. Lint: 0 ошибок, 27 предупреждений. Сравнение с локальным `HEAD` выявило только изменяемое уведомление `GradleDependency` о доступной версии Material 1.14.0; зависимость осталась 1.13.0, остальные предупреждения совпадают. Предыдущий опубликованный rc.58 также фиксировал 27 предупреждений.

Полный инструментальный прогон на выделенных эмуляторах Android 12/API 31 и Android 16/API 36: по 48 тестов, по одному тайм-ауту существующих тестов `HomeSurfaceTest` (API 31) и `WidgetPickerTest` (API 36). Отдельный повтор обоих классов вместе с новым `ShortcutIconTest` прошёл: 4/4 на каждой версии. Новый тест значков прошёл также в полном прогоне: bitmap/resource, отсутствие значка, недоступный shortcut, выравнивание и открытие правильного быстрого действия. Полный первый прогон не считается успешным.

Нативные снимки меню с тестовой аватаркой проверены на обеих версиях Android. Подробности первоначальных проверок — в [отчёте](../shortcut-icons-verification.md). Итоговый smoke подписанного release APK в портрете, узком окне/font scale 1.3 и landscape, проверки подписи, размера, состава и SHA-256 фиксируются в GitHub Release.

## APK и ограничения

Версия: `0.2.0-rc.59`, versionCode `68`. Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин не настроены. Telegram с пользовательским аккаунтом, реальные рабочие профили, TalkBack и OEM не проверены. Аватарка зависит от значка, предоставленного приложением; запросы к Telegram API не выполняются. Полный паритет Niagara не заявляется.
