# Better Launcher 0.1.7

Патч размера APK и процесса публикации.

## Изменения

- Отдельная ICU4J удалена из зависимостей APK. Транслитерация использует системную библиотеку Android ICU (Russian-Latin/BGN), доступную на поддерживаемых Android 12+.
- Сохранены Яндекс → Y, созвучные кириллические группы и заключительный «#».
- Публикуется release APK с R8 и удалением неиспользуемых ресурсов; debug APK больше не публикуются. Правило закреплено в AGENTS.md.
- Настройка подписи вынесена в приватный properties-файл вне Git. Сохранён прежний сертификат для обновления поверх опубликованных APK.
- Сохранены актуальные изменения main, включая регулируемое затемнение системных обоев, новое меню приложения и экран виджетов.

## Установка

Скачайте `better-launcher-0.1.7-release.apk`. versionCode — 10, minSdk — 31, targetSdk — 36. Установите поверх 0.1.3–0.1.5 без удаления приложения; подпись совместима. Прежний сертификат Android Debug используется для совместимости, хотя тип APK теперь release и отладка отключена. Выпуск в магазине пока не настроен.

`SHA256SUMS.txt` содержит SHA-256 опубликованного APK. Полный паритет Niagara не заявляется.

## Проверки

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно; 4 unit-теста, 0 ошибок. Тесты транслитерации перенесены на устройство, чтобы проверять настоящую системную ICU.
- `ANDROID_SERIAL=emulator-5602 ./gradlew :app:connectedDebugAndroidTest` — 16/16 успешно на Android 12, включая все 5 тестов системной транслитерации. После проверки установлен итоговый release APK и назначен HOME.
- Debug/release lint: 0 ошибок и 27 прежних предупреждений; новых предупреждений нет.
- APK: 2 415 027 байт (2,42 МБ), вместо 28 943 432 байт в 0.1.3. Данные ICU4J в APK отсутствуют. R8 и resource shrinking включены; manifest не содержит `debuggable=true`, подпись проверена `apksigner`.
- SHA-256: `0b61cdc325b5d48370fbd638e84b0790d69397bfca4f840357b18a8f9dbad0b9`.
- На Android 12 обновление с опубликованного debug APK 0.1.3 на release APK прошло без удаления приложения; избранное и переименование сохранились. Этот сценарий и первоначальная UI-проверка выполнены до изменения номера патча на 0.1.7; код приложения совпадает с итоговым.
- На Android 12 проверены касания B/Банк, V/Видео, Y/Яндекс и Йога, заключительный «#»/123; узкий экран с font scale 1.3, landscape и левосторонний режим. Размер, шрифт, ориентация и настройки после сценариев восстановлены.

После сценариев восстановлены размер, шрифт, ориентация и настройки. Полный smoke на Android 16 не запускался.
