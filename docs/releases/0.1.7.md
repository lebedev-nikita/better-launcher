# Better Launcher 0.1.7

APK-size and publication-process patch.

## Changes

- Removes the separate ICU4J dependency from the APK. Transliteration uses Android's system ICU library (Russian-Latin/BGN), available on supported Android 12+ versions.
- Preserves Яндекс → Y, corresponding Cyrillic groups and the final “#”.
- Publishes a release APK with R8 and unused-resource removal; debug APKs are no longer published. AGENTS.md records this rule.
- Signing configuration moves to a private properties file outside Git. The previous certificate is retained for upgrading published APKs.
- Preserves current main changes, including adjustable wallpaper dimming, the new app menu and widget screen.

## Installation

Download `better-launcher-0.1.7-release.apk`. versionCode: 10, minSdk: 31, targetSdk: 36. Install over 0.1.3–0.1.5 without uninstalling; signing is compatible. The previous Android Debug certificate is retained for compatibility, although the APK is now a release build with debugging disabled. Store distribution is not configured yet.

`SHA256SUMS.txt` contains the published APK SHA-256. Full Niagara parity is not claimed.
