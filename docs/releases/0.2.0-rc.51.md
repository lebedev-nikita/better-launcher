# Better Launcher 0.2.0-rc.51

Full-width app search. Version code: 60; Android 12+ (API 31), target API 36.

## Changes

- Search no longer inherits the alphabet list's side reservation: fills system-inset width with equal 20dp margins. Field stretches between separate 48dp Back/Clear buttons.
- Left alphabet does not narrow/shift search. Results retain letter margins.
- Short windows place letters, selected-section pointer and touch-start area below search. Alphabet View bounds/bottom anchoring stay stable between home/list; normal portrait letters unchanged.
- Search, keyboard launch, clear, Back/HOME/system/IME insets remain. Backup format/profiles/widget IDs/settings unchanged.
