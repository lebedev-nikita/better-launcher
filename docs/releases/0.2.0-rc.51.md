# Better Launcher 0.2.0-rc.51

Поиск приложений на всю доступную ширину. Version code — 60; Android 12+ (API 31), target API 36.

## Изменения

- Строка поиска больше не наследует боковой резерв алфавитного списка: она занимает всю ширину внутри системных insets с одинаковыми отступами 20dp по краям. Поле растягивается между отдельными 48dp кнопками возврата и очистки.
- Переключение алфавита налево не сужает и не смещает поиск. Результаты сохраняют прежние отступы для букв.
- В коротком окне буквы, указатель выбранного раздела и область начала касания алфавита располагаются ниже строки поиска. Границы самого алфавитного View и нижняя привязка сохраняются при переходе между главным экраном и списком; в обычном портрете положение букв не меняется.
- Поиск, запуск через клавиатуру, очистка, Back/HOME и системные/IME insets сохранены. Формат backup, профили приложений, widget IDs и пользовательские настройки не меняются.

## Проверки

Debug assembly, все 15 unit-тестов и debug lint прошли: 0 ошибок, 27 прежних предупреждений, новых нет. Полные инструментальные наборы прошли на выделенных Android 12/API 31 и Android 16/API 36: по 42 теста без падений и пропусков. На API 31 использован `connectedDebugAndroidTest`, на API 36 — тот же test APK через AndroidJUnitRunner.

Предварительный прогон API 31 прервался на системной Activity-транзакции (`Activity client record must not be null`); повторный полный прогон после установки APK и запуска назначенного HOME прошёл. Предварительный API 36 выявил смещение границ алфавита; финальная реализация сохранила его View и резервирует верхнюю область внутри него, после чего полный набор прошёл.

Результаты native-проверки поиска с обеими сторонами алфавита, smoke подписанного APK в портрете, узком окне/font scale 1.3 и landscape, release lint и характеристики итогового APK приведены в GitHub Release. Локальные логи, UI hierarchy и снимки: `.impeccable/review/search-width/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Совпадение сертификата с rc.50, отсутствие debuggable, размер, состав и SHA-256 проверяются перед публикацией и записываются в GitHub Release.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон пользователя, OEM и полный TalkBack-сеанс не проверены. Полный паритет Niagara не заявляется.
