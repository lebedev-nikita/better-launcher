# Better Launcher 0.2.0-rc.45

Clearer widget-picker search. Version code: 54; Android 12+ (API 31), target API 36.

## Changes

- Removes separate Add widget/Home widget heading and close cross: duplicate context competing with search.
- One tonal Search widgets field with magnifier remains at top, distinct from provider names and a second heading.
- Only cross sits inside the field, clears nonempty query and hides when empty; text width stays stable. Back/outside tap dismiss; HOME returns home.
- Preserves app/widget-name search, clearing, previews/right result alphabet. Landscape uses standard system input; Back/Done return to results.
- Accessible panel name retained for screen readers; catalog/binding/configuration/IDs follow existing rules.
