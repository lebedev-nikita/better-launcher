# Better Launcher 0.2.0-rc.45

Понятный поиск при добавлении виджета. Version code — 54; Android 12+ (API 31), target API 36.

## Изменения

- Убраны отдельный заголовок «Добавить виджет»/«Виджет на главном экране» и крестик закрытия: они дублировали контекст и конкурировали с поиском.
- Вверху остаётся одно тональное поле «Поиск виджетов» с лупой. Оно визуально отличается от названий провайдеров и не похоже на второй заголовок.
- Единственный крестик находится внутри поля и очищает непустой запрос. При пустом поле он скрыт; ширина текста не меняется при его появлении. Закрытие доступно через системный Back и нажатие вне панели, HOME возвращает домой.
- Сохранены поиск по названиям виджета/приложения, очистка, превью и алфавит результатов справа. В горизонтальном режиме клавиатура не заменяет список полноэкранным редактором.
- Доступное название панели сохранено для screen reader; каталог, binding, configuration и AppWidget IDs работают по прежним правилам.

## Проверки

Результаты сборки, unit/lint, instrumentation и проверки подписанного release APK на Android 12/API 31 и Android 16/API 36, его коммит, размер и SHA-256 записываются в GitHub Release. Локальные журналы и native screenshots: `.impeccable/review/widget-search-simplified/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного коммита main; тег указывает на него и проверяется как предок origin/main перед публикацией. Прежний сертификат сохранён для совместимости обновлений. Физический телефон/OEM, полный TalkBack-сеанс, production-сертификат и магазин не проверены; полный паритет Niagara не заявляется.
