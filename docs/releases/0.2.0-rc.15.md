# Better Launcher 0.2.0-rc.15

Android 12+ candidate; `versionCode=24`, `versionName=0.2.0-rc.15`, minSdk 31, targetSdk 36.

## Changes

- Tapping the long-press menu name switches the same Dialog to an editor without closing/reopening a menu.
- Editor follows the supplied reference: app icon, Rename … heading, selected name in a blue-bordered field and one Save button above the keyboard.
- IME Done also saves. Empty names restore the original; Back, outside taps and HOME discard unsaved input.
- Window height accounts for IME insets; short-window content scrolls. Names/search update after save; home scrolling is preserved.
- Rebased onto `origin/main` (`a04e631`); retains rc.11 widget-loading fixes.

- Post-rebase code before final versionCode/versionName-only change: `:app:connectedDebugAndroidTest` with explicit serials `emulator-5672` (Android 12 / API 31) and `emulator-5670` (Android 16 / API 36) passed 20 tests each, 0 errors. ## Limitations

Checks used dedicated emulators. Physical phones, OEMs, work profiles, Private Space, TalkBack and tablets were not independently checked. Full Niagara parity is not claimed; other gaps in [features.md](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.15/docs/features.md). Early emulator boots had system ANRs. Two full smoke attempts stopped when all ADB devices disappeared together; not counted successful. Results above describe completed reruns. Stable 0.1.9 remains Latest.
