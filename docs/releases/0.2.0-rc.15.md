# Better Launcher 0.2.0-rc.15

Релиз-кандидат для Android 12+; `versionCode=24`, `versionName=0.2.0-rc.15`, minSdk 31, targetSdk 36.

## Изменения

- Нажатие на название в меню удержания переключает содержимое того же Dialog на редактор, без закрытия окна и открытия нового меню.
- Редактор следует предоставленному образцу: значок приложения, заголовок «Переименовать …», выделенное имя в поле с голубой рамкой и одна кнопка «Сохранить» над клавиатурой.
- IME Done также сохраняет. Пустое имя возвращает исходное название; Back, нажатие снаружи и HOME отбрасывают несохранённое имя.
- Высота окна учитывает IME-insets; в коротком окне содержимое прокручивается. Названия и поиск обновляются после сохранения, прокрутка главного экрана сохраняется.
- Выполнен rebase на `origin/main` (`a04e631`); сохранены исправления загрузки виджетов из 0.2.0-rc.11.

## Проверки

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно после rebase. 4 unit-теста, 0 ошибок.
- Debug/release lint: 0 ошибок, 27 прежних предупреждений; новых нет.
- На коде после rebase, до финального изменения только versionCode/versionName, `:app:connectedDebugAndroidTest` с явными serial `emulator-5672` (Android 12 / API 31) и `emulator-5670` (Android 16 / API 36): по 20 тестов, 0 ошибок. Проверены сохранение в том же экземпляре меню, HOME/Back без записи, восстановление исходного имени через IME Done, хранение/backup, каталог и виджеты.
- Визуально проверен редактор с клавиатурой в портрете и при 840×1800 / font scale 1.3 на обоих API, landscape на обоих API. Снимки хранятся локально в `.impeccable/review/inline-*.png`.
- Итоговый подписанный APK 0.2.0-rc.15: `scripts/smoke-test.py --serial emulator-5672` — успешно на Android 12, включая редактор в том же меню и HOME без записи; аварий Better Launcher нет. Общий smoke Android 16 прерван исчезновением устройств из ADB и полностью не подтверждён. После connected-тестов release APK переустановлен, HOME назначен; размер, font scale и ориентация восстановлены.
- Подписанный APK: R8 и shrinkResources включены, APK не debuggable; `apksigner verify` успешен. Сертификат SHA-256 `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b` совпадает с предыдущим RC.
- Размер APK: 2 427 564 байта, на 2 060 байт (+0,08%) больше 0.2.0-rc.14; увеличение соответствует редактору имени. Необъяснённого прироста нет.

## Ограничения

Проверки выполнены на выделенных эмуляторах. Физические телефоны, OEM, рабочие профили, Private Space, TalkBack и планшеты отдельно не проверены. Полный паритет Niagara не заявляется; остальные пробелы перечислены в [features.md](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.15/docs/features.md). Ранние запуски эмуляторов сопровождались системными ANR при загрузке. Два общих smoke-прогона прерваны одновременным исчезновением всех устройств из ADB; они не считаются успешными. Результаты выше относятся к завершённым повторным прогонам. Стабильный выпуск 0.1.9 остаётся Latest.
