# Better Launcher 0.2.0-rc.4

Релиз-кандидат с компактным алфавитом для навигации одной рукой. Ветка перебазирована на `origin/main` (`3e11b26`) перед итоговой сборкой; `AGENTS.md` перечитан после rebase.

## Изменения

- В алфавите остаются только разделы, для которых есть видимые приложения. ★ сохраняется для избранного; «#» показывается последним только при наличии соответствующих приложений.
- Ряд расположен внизу над нижней панелью с отступом 8 dp; шаг букв уменьшен с 23 до 20 dp при обычном масштабе шрифта и адаптируется к крупному шрифту и короткому окну.
- Буквы сохраняют положение при переходе из избранного в список приложений, чтобы не смещаться под пальцем во время свайпа.
- Сохранены волна, клавиатура, accessibility-действия, левосторонний режим, system/IME insets и край системного Back.
- Включены анимация появления меню снизу и переименование приложения по нажатию на его заголовок из актуального main.
- Включены актуальные изменения main: системная Android ICU, оптимизированный release APK, обновлённое меню приложений, затемнение обоев и отдельная страница виджетов.

## Установка

Скачайте `better-launcher-0.2.0-rc.4-release.apk` и установите поверх предыдущего выпуска без удаления приложения. Минимальная версия — Android 12 (API 31), targetSdk — 36, versionCode — 12. `SHA256SUMS.txt` содержит SHA-256 APK.

Это подписанный release APK с R8 и удалением неиспользуемых ресурсов; отладка отключена. Прежний сертификат Android Debug сохранён для совместимости обновлений. Выпуск в магазине и отдельная production-подпись не настроены.

Выпуск публикуется как prerelease; стабильный 0.1.7 остаётся последним стабильным. Полный паритет Niagara не заявляется.

## Проверки и ограничения

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно; 4 unit-теста, 0 ошибок.
- `ANDROID_SERIAL=emulator-5580 ./gradlew :app:connectedDebugAndroidTest` — 19/19 успешно на выделенном Android 12 / API 31, включая алфавит, системную транслитерацию, сохранение данных и новое переименование по заголовку меню.
- Debug/release lint: 0 ошибок и 27 прежних предупреждений; новых нет.
- Подпись проверена `apksigner`, сертификат совпадает с опубликованным 0.1.7. Отладка отключена, R8 и resource shrinking включены.
- APK: 2 416 396 байт. Рост относительно 0.1.7 — 1369 байт; добавлены три XML-ресурса анимации/интерполятора из main. Отдельной ICU4J и её данных в APK нет.
- SHA-256: `4912a6c002b1de7bbc62994b2acc6a19cdb9193f81af025ab2f808f82e447e69`.

Полный `scripts/smoke-test.py` на итоговом release APK прошёл на Android 12: избранное, виджеты, Back/HOME, настройки, поиск, запуск Camera, меню, переименование по заголовку с отменой, алфавит и отсутствие аварий Better Launcher. На итоговом APK дополнительно проверены портрет 1080×2400, узкий экран 945×2100 с font scale 1.3, настоящий landscape 2400×1080 и левосторонний режим. Нижние разделы доступны, положение алфавита при переходе сохраняется, footer, клавиатура и Back работают. Снимки получены из эмулятора; временные настройки восстановлены.

Предварительная сборка с компактным алфавитом до последнего rebase прошла полный smoke на Android 12. На Android 16 её smoke прервался на UI-навигации после ошибок UI Automator `null root node`; этот прогон не объявляется успешным и не относится к итоговому APK. Итоговый APK на Android 16 не проверен.

Физические устройства, рабочие профили, Private Space, сторонние провайдеры виджетов и полная проверка TalkBack не проверены. Подробности ранних проверок компактного алфавита сохранены в [отчёте](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.4/docs/compact-alphabet-verification.md).
