# Better Launcher 0.2.0-rc.4

Release candidate with a compact alphabet for one-handed navigation. The branch was rebased onto `origin/main` (`3e11b26`) before the final build; `AGENTS.md` was reread afterward.

## Changes

- The alphabet includes only sections containing visible apps. ★ remains for favorites; “#” appears last only when matching apps exist.
- The rail sits 8 dp above the footer; normal-font letter spacing drops from 23 to 20 dp and adapts to large fonts/short windows.
- Letters retain their positions when switching from favorites to the app list, avoiding movement under a swiping finger.
- Preserves the wave, keyboard/accessibility actions, left-handed mode, system/IME insets and system Back edge.
- Includes main's bottom-entry menu animation and renaming by tapping the app-menu heading.
- Includes current main changes: system Android ICU, optimized release APK, updated app menus, wallpaper dimming and a separate widget page.

## Installation

Download `better-launcher-0.2.0-rc.4-release.apk` and install over the previous release without uninstalling. Minimum: Android 12 (API 31), targetSdk: 36, versionCode: 12. `SHA256SUMS.txt` contains the APK SHA-256.

Signed release APK with R8 and unused-resource removal; debugging disabled. The previous Android Debug certificate remains for upgrade compatibility. Store distribution and separate production signing are not configured.

Published as prerelease; stable 0.1.7 remains the latest stable release. Full Niagara parity is not claimed.
