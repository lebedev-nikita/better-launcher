# Better Launcher 0.2.0-rc.48

Hidden apps immediately leave the alphabet index. Version code: 57; Android 12+ (API 31), target API 36.

## Changes

- Hiding a section's last visible app immediately removes its A–Z/# entry. Sections with another visible app remain; hiding all leaves only ★.
- Undo/Show again restore the section. Nonempty search finds hidden apps but results do not add their letter until restoration.
- Cause: catalog already excluded hidden apps, but showing home after hide/undo did not refresh index. Every home display now obtains current visible sections.
- Adds real-menu/undo/search UI regression for both sides. README/coverage/DESIGN/sidecar updated.
