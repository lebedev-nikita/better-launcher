# Better Launcher 0.2.0-rc.48

Скрытые приложения сразу исключаются из алфавитного указателя. Version code — 57; Android 12+ (API 31), target API 36.

## Изменения

- Если последнее видимое приложение раздела скрыто, его буква сразу исчезает из указателя. Правило действует для A–Z и #; пока есть другое видимое приложение, раздел остаётся. При скрытии всех приложений остаётся только ★.
- Отмена скрытия и «Показывать снова» возвращают раздел. Скрытое приложение доступно по непустому запросу, но его результат поиска не добавляет букву в указатель до восстановления.
- Причина ошибки: каталог уже исключал скрытые приложения, однако показ главного экрана после скрытия и отмены не обновлял указатель. Теперь каждый показ главного экрана получает актуальные видимые разделы.
- Добавлен регрессионный UI-тест через настоящие команды меню, отмену и поиск для обеих сторон алфавита. Обновлены README, покрытие возможностей, DESIGN.md и sidecar.

## Проверки

Debug APK, все 15 unit-тестов и debug lint прошли: 0 ошибок, прежние 27 предупреждений, новых нет. Новый тест сначала воспроизвёл оставшуюся Z после скрытия единственного приложения; после исправления прошёл на Android 12/API 31 и Android 16/API 36. Проверены удаление последнего приложения из A–Z и #, сохранение непустого раздела, пустой указатель со звездой, отмена и восстановление через поиск без изменения запроса, обе стороны индекса.

Полный `connectedDebugAndroidTest` на выделенном Android 12/API 31 прошёл: 42 теста, 0 падений и пропусков. Итоговый прогон Android 16, native UI подписанного APK, smoke, release lint и характеристики опубликованного APK записаны в GitHub Release. Локальные логи и снимки: `.impeccable/review/hidden-index/`. Ранний повтор теста упёрся в проверку поисковой строки до раскладки ListView; тест теперь ожидает idle перед её удержанием. Первый тестовый эмулятор завершился до повторного прогона и был перезапущен; этот запуск не считается успешным.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита main, уже опубликованного в origin/main; тег указывает на этот коммит. Подпись должна быть совместима с предыдущими выпусками. SHA-256, размер и сравнение состава приведены в GitHub Release. Прежний сертификат Android Debug сохранён для совместимости; production-сертификат и магазин не настроены. Физические телефоны/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется. Формат backup, профили приложений и widget IDs не меняются.
