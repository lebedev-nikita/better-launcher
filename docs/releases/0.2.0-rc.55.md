# Better Launcher 0.2.0-rc.55

Исправление остаточного зазора при нулевом отступе. Version code — 64; Android 12+ (API 31), target API 36.

## Изменения

- Убран автоматический верхний и нижний padding AppWidgetHostView на странице виджетов и главном экране. При выбранных 0 dp содержимое соседних виджетов теперь соприкасается; при 8/32 dp расстояние соответствует настройке, включая промежуток перед избранным.
- Боковые отступы контейнера, собственная разметка провайдера и сохранённое перемещение/размер виджета сохраняются.
- Расчёт ограничений размера использует фактический padding контейнера. При передаче высоты провайдеру компенсируется вычитание стандартных отступов внутри Android API, поэтому RemoteViews получают реальный доступный размер.
- Живой предпросмотр и сохранённая настройка отступа остаются прежними; формат backup не меняется.

## Проверки

Регрессия воспроизведена на Android 12/API 31 и Android 16/API 36: при 0 dp контейнеры соприкасались, но между границами содержимого оставалось 42 px (16 dp). Прежняя проверка измеряла только контейнеры и пропускала этот зазор.

WidgetSpacingTest теперь измеряет границы реального RemoteViews-содержимого на странице и перед избранным, проверяет 0/8/32 dp при обеих сторонах алфавита и соответствие переданной провайдеру высоты. Тест падал до исправления и прошёл после него. Все шесть геометрических прогонов на API 31 и API 36 прошли: портрет, 945×2100/font scale 1.3 и горизонтальные окна (2160×1080/API 31, 2400×1080/API 36). Нативные снимки подтверждают отсутствие остаточного зазора на тестовом провайдере; параметры дисплея восстановлены.

На текущей версии прошли все 22 выбранных инструментальных теста на API 31: хранение/backup, ползунки, транслитерация, отступы, hosted widgets, размеры/жесты/отклик и перестановка.

Debug assembly, все 15 unit-тестов и debug lint текущей версии прошли: 0 ошибок, 27 прежних предупреждений, новых нет. Итоги connected-тестов, проверки разных окон и smoke итогового подписанного APK фиксируются в GitHub Release. Локальные логи и снимки: `.impeccable/review/zero-widget-gap/`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и `SHA256SUMS.txt`. APK собирается из чистого коммита `main`, уже опубликованного в `origin/main`; тег указывает на этот коммит. Перед публикацией проверяются сертификат предыдущего выпуска, отсутствие debuggable, размер, состав и SHA-256.

Прежний сертификат Android Debug сохранён для совместимости обновлений; production-сертификат и магазин не настроены. Сторонний провайдер может добавлять собственные внутренние отступы. Проверка выполнена с native тестовым провайдером; физический телефон пользователя, Todoist и погодный провайдер со скриншота не проверены. Полный паритет Niagara не заявляется.
