# Better Launcher 0.2.0-rc.22

On-screen widget resizing. Version code: 31; Android 12+ (API 31), target API 36.

## Changes

- Added widgets have no app-name label or permanent menu button. Long press opens an app-style navy icon menu: size, available provider configuration, cross-screen transfer, add/remove.
- Resize shows a frame around the live widget. Top/bottom handles change height; left/right change width. Widget remains centered; top-edge resizing preserves the bottom position. Window/provider limits apply.
- No circular reset arrows in the editor. Reset size remains a separate menu action. Footer displays size/Done; Back or outside taps also finish. HOME returns home.
- Size/top offset save immediately and survive restart. Old size format reads without migration; backup excludes local widget IDs/sizes and preserves them on import. Invalid imports validated before writes.
- Provider content/alphabet accept no actions during editing. Handles support keyboard/accessibility; canceled gestures restore prior size. Lifecycle removes editor; notification refresh waits until dismissal.

## Verification

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` passed: 10 unit tests; lint 0 errors, 27 existing warnings, no new warnings. `:app:connectedDebugAndroidTest`: all 26 tests passed separately on Android 12/API 31 and Android 16/API 36. Covers real edge drags, cancellation, accessible sizing, persistence, menus, transfer/removal and atomic backup. UI tests wait for current post-layout geometry instead of stale accessibility coordinates.

`python3 scripts/smoke-test.py --serial …` passed separately on both versions without launcher crashes.

Native scenarios on both: hold menu, four edges, persistence after restart, menu reset, Done, Back/HOME, home/widget page. Portrait, narrow 945×2100/font scale 1.3 and landscape (API 31: 2160×1080; API 36: 2400×1080) checked. Menu/editor screenshots shown to the user before publication. White task card is an explicitly identified test-only androidTest AppWidgetProvider, excluded from normal APK.
