# Better Launcher 0.2.0-rc.22

Редактирование размеров виджетов прямо на экране. Version code — 31; Android 12+ (API 31), target API 36.

## Изменения

- У добавленных виджетов нет названия приложения над содержимым и постоянной кнопки меню. Долгое удержание открывает navy-меню с иконками в стиле меню приложений: размер, доступная конфигурация провайдера, перенос между экранами, добавление и удаление.
- «Изменить размер» включает рамку вокруг живого виджета. Верхний и нижний маркеры изменяют высоту, левый и правый — ширину. Виджет остаётся по центру; верхняя граница сохраняет положение нижней. Размеры ограничены окном и возможностями провайдера.
- Круговых стрелок сброса в редакторе нет. «Сбросить размер» остаётся отдельным пунктом меню. Нижняя панель показывает размер и «Готово»; Back и касание вне виджета также завершают редактирование. HOME возвращает главный экран.
- Размеры и верхний отступ сохраняются немедленно и после перезапуска. Старый формат размеров читается без миграции; backup не переносит локальные widget IDs и размеры и сохраняет их при импорте. Некорректный импорт проверяется до записи.
- Во время редактирования содержимое провайдера и алфавит не принимают действия. Маркеры доступны с клавиатуры и через accessibility; отмена жеста восстанавливает прежний размер. Lifecycle удаляет редактор, а обновления уведомлений ждут его закрытия.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 10 unit-тестов; lint — 0 ошибок, 27 существующих предупреждений, новых нет. `:app:connectedDebugAndroidTest` — все 26 тестов прошли отдельно на Android 12/API 31 и Android 16/API 36. Проверены реальные drag-жесты по границам, отмена, accessibility-размеры, сохранение, меню, перенос, удаление и атомарность backup. UI-тесты ожидают актуальную геометрию после layout вместо старых accessibility-координат.

`python3 scripts/smoke-test.py --serial …` — успешно отдельно на обеих версиях Android, без аварий процесса лаунчера.

Нативные UI-сценарии проверены на обеих версиях: меню удержания, четыре границы, сохранение после перезапуска, reset из меню, «Готово», Back/HOME, главный экран и страница виджетов. Проверены портрет, узкий экран 945×2100 с font scale 1.3 и landscape (API 31: 2160×1080; API 36: 2400×1080). Скриншоты меню и редактора показаны пользователю до публикации. Белая карточка с задачами — явно обозначенный test-only AppWidgetProvider из androidTest; в обычный APK она не входит.

## APK и ограничения

Подписанный release APK собирается из чистого коммита main, уже опубликованного в origin/main, с R8 и удалением неиспользуемых ресурсов. Публикуются APK и SHA256SUMS.txt. Подпись совместима с предыдущим выпуском; прежний сертификат Android Debug сохранён, production-сертификат и магазин не настроены. Возможности resizeMode и ограничения провайдера соблюдаются: фиксированные виджеты не получают неподдерживаемые маркеры. Полный паритет Niagara, физические устройства/OEM, рабочие профили и TalkBack целиком не подтверждены.
