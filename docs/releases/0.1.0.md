# Better Launcher 0.1.0

Первая версия нативного Android-лаунчера на Kotlin для Android 12 и новее.

## Возможности

- Вертикальное избранное с настоящими значками установленных приложений.
- Алфавитная навигация с волной, поиск и запуск приложений.
- Меню приложений по свайпу, быстрые действия, переименование и скрытие.
- Предпросмотр уведомлений, действия и поле ответа.
- Папки и стопка Android-виджетов.
- Настройки оформления, собственные обои, экспорт и импорт настроек.
- Интеграции погоды, календаря и управления музыкой.

## Установка

1. Скачайте `better-launcher-0.1.0-debug.apk` из файлов релиза и установите на устройство с Android 12+.
2. Откройте Better Launcher → настройки → «Домашний экран» → выберите Better Launcher.
3. Для уведомлений включите доступ в настройках Android. Доступ к календарю запрашивается при открытии событий; погода включается после выбора города.

APK подписан отладочным ключом и предназначен для тестирования версии 0.1.0. Файл `SHA256SUMS.txt` содержит контрольную сумму APK.

## Проверки и текущие ограничения

Сборка и 3 unit-теста проходят; lint: 0 ошибок, 35 предупреждений. Ранее прошли 3 интеграционных теста на Android 16. Шесть основных UI-сценариев проверены на эмуляторах Android 12 и Android 16, включая запуск приложения и возврат HOME. На Android 16 также проверены системный виджет Clock и предпросмотр/скрытие уведомления Messages.

Полный паритет Niagara пока не достигнут. Наборы значков, пользовательские шрифты, виджеты во всплывающих меню и ряд других возможностей ещё не реализованы. Интеграции погоды, календаря, музыки и отправки ответа требуют дополнительных проверок с соответствующими данными и приложениями. Подробности: [возможности](../features.md), [отчёт о проверке](../verification.md).
