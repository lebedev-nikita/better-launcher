# Better Launcher 0.1.0

The first native Kotlin Android launcher release, for Android 12 and newer.

## Features

- Vertical favorites with real installed-app icons.
- Alphabet navigation with a wave, app search and launch.
- Swipe app menus, quick actions, renaming and hiding.
- Notification previews, actions and a reply field.
- Folders and an Android widget stack.
- Appearance settings, custom wallpaper, and settings export/import.
- Weather, calendar and music-control integrations.

## Installation

1. Download `better-launcher-0.1.0-debug.apk` from the release assets and install it on Android 12+.
2. Open Better Launcher → Settings → Home screen → select Better Launcher.
3. Enable notification access in Android settings. Calendar permission is requested when opening events; weather is enabled after selecting a city.

The APK uses a debug signing key and is intended for testing version 0.1.0. `SHA256SUMS.txt` contains its checksum.

## Verification and current limitations

The build and 3 unit tests pass; lint reports 0 errors and 35 warnings. Previously, 3 integration tests passed on Android 16. Six core UI scenarios were checked on Android 12 and Android 16 emulators, including app launch and HOME return. Android 16 also covered the system Clock widget and previewing/dismissing a Messages notification.

Full Niagara parity has not been reached. Icon packs, custom fonts, widgets in popup menus and several other features remain unimplemented. Weather, calendar, music and reply sending require further checks with appropriate data and apps. See [features](../features.md) and the [verification report](../verification.md).
