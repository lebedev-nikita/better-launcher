# Better Launcher 0.2.0-rc.12

Исправление нижнего отступа меню приложения перенесено ребейзом на main `795be66`. Код меню и его regression-тест совпадают с rc.10; включены последующие изменения main, в том числе отчёт проверки выбора виджетов. Публикуется новый APK с versionCode 21.

## Изменения

- Сохранено окно фиксированного размера и меню, прижатое к его нижнему краю. При открытии не требуется последующее изменение размера окна.
- Сохранены выезд снизу, системное отключение анимаций, системные отступы, раскрытие «Дополнительно», переименование по заголовку и закрытие через Back, HOME или нажатие снаружи.
- История опубликованного rc.10 и его тег сохранены. Результат ребейза публикуется в ветке `t3code/fix-app-menu-gap-rc12`.

## Установка

Установите `better-launcher-0.2.0-rc.12-release.apk` поверх предыдущего выпуска без удаления приложения. Минимальная версия — Android 12 (API 31), targetSdk — 36, versionCode — 21. Выпуск отмечен как prerelease и не заменяет стабильный релиз.

APK подписан совместимым сертификатом, собран с R8 и удалением неиспользуемых ресурсов; отладка отключена. SHA-256 сертификата: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Прежний сертификат Android Debug сохранён для совместимости обновлений.

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest :app:assembleRelease :app:lintRelease` — успешно. 4 unit-теста; Gradle повторно использовал их результат, поскольку код и входные данные не изменились. Debug/release lint: 0 ошибок, 27 прежних предупреждений, новых нет.
- `apksigner verify`: подпись v2 действительна, сертификат совпадает с rc.10. Manifest: versionCode 21, versionName 0.2.0-rc.12, minSdk 31, targetSdk 36, отладка отключена.
- APK: 2 425 672 байта — размер rc.10. Набор ZIP entries совпадает; содержимое отличается только AndroidManifest.xml с новой версией. DEX и ресурсы совпадают.
- SHA-256 APK: `6a12eb654390b34bf6d03c2d842889f9c6a112be09f4f3225822685aa0bb3093`. Файл `SHA256SUMS.txt` опубликован рядом с APK.
- На выделенном Android 12 debug APK и test APK установились, HOME назначен. Прямой instrumentation-прогон AppMenuTest/SystemTransliterationTest завершился неуспешно: тест нижней границы не дождался готовности главного экрана; следующий тест аварийно завершился с `RejectedExecutionException` в `MainActivity.refreshApps` после остановки executor. Успешного результата теста меню и системной транслитерации нет. В системе также зарегистрированы перезапуски SystemUI с `Could not find Telephony Service`. После проверки release APK переустановлен и HOME восстановлен; эмулятор остановлен.

На выделенном Android 16 первый instrumentation-прогон выполнил 7 тестов: 6 прошли (переименование приложения и 5 проверок системной транслитерации), тест нижней границы завершился тайм-аутом запуска Activity. После остановки приложения повторный отдельный `menuStaysAtScreenBottomThroughoutArrival` прошёл: нижняя граница меню совпадала с нижней границей экрана во всех наблюдаемых кадрах открытия. После instrumentation release APK переустановлен и HOME восстановлен.

На release APK Android 16 проверены портретный режим, раскрытие «Дополнительно», переход в настройки, Back и закрытие нажатием снаружи; сохранены снимки интерфейса. Полный `scripts/smoke-test.py` прошёл главную поверхность без часов/даты, навигацию страницы виджетов, настройки/Back, поиск и запуск Camera/HOME, затем завершился с `Missing UI element: Открыть Phone` после горизонтального свайпа. Полный smoke не считается успешным.

Попытка проверки узкого экрана 840×1867 с font scale 1.3 не завершилась: вместо меню открылось Phone, UI Automator завершился с кодом 137. Восстановление HOME через UI Automator также закончилось кодом 137. Landscape, левосторонний режим и отключённые анимации в этом прогоне не проверены. Размер, font scale и ориентация восстановлены отдельно; эмулятор остановлен.

Визуальная проверка исходного скачка на физическом телефоне, рабочие профили, Private Space и полный TalkBack отдельно не выполнены. Полный паритет Niagara не заявляется.
