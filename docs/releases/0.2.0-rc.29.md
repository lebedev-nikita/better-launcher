# Better Launcher 0.2.0-rc.29

Home without an empty area above content. Version code: 38; Android 12+ (API 31), target API 36.

## Changes

- Removes extra home top spacing: 56 dp above widgets, 24 dp in short windows and the old 14% height above favorites without widgets. Content starts immediately below system insets at every size. Status bar/cutouts remain respected; no launcher-specific top reservation.
- Near the status bar, the editor's top handle shifts inside the widget. Its full 48dp touch area stays below bars/cutouts without adding widget padding.
- Saved custom sizes/offsets remain valid. Move manually lowered widgets upward or use Reset size and position; zero now means the usable top boundary.
- Preserves centering, full-width expansion, 12 dp grid, keyboard/accessibility, rc.27 soft haptics, AppWidgetHost ID and backup format. Height depends on provider/chosen size.
- Widget-page swipe smoke starts on free wallpaper above footer because the empty top strip is gone.
