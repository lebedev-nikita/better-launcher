## Changes

- Picker shows widget name, app and `previewLayout`/`previewImage`. Missing/broken previews show an icon and Preview unavailable.
- Right wave alphabet matches the app list. Heading/close stay above the list; large fonts/short windows show available sections.
- Preserves background loading, row reuse, close-time cancellation and keyboard/accessibility actions. Previewing allocates no widget IDs; selection starts system binding/configuration.
- Includes main changes published in 0.1.9: bottom-entry app menu, heading renaming and lower alphabet-boundary fix.
- Includes main's third-party RemoteViews fix: added widgets/previews use a separate framework context instead of AppCompat/Material inflation. Live updates, cross-screen transfer, AppWidgetHost ID 1201 and existing widget IDs remain.
