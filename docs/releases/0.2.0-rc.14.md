# Better Launcher 0.2.0-rc.14

Релиз-кандидат выбора виджетов после rebase на `origin/main` (`a04e631771005d3dcfa3f10ec323363b527072d4`). Первый rebase на `795be66` не требовал изменений; во время проверки main обновился, поэтому выпуск повторно перенесён на новый commit. Конфликт ссылки на выпуск в README разрешён с сохранением документации main. Код приложения совпадает с исправлением 0.2.0-rc.11; изменены версия и документация выпуска.

## Изменения

- При выборе виджета видны название, приложение и превью `previewLayout` или `previewImage`. Если превью отсутствует или повреждено, отображаются значок и подпись «Превью недоступно».
- Справа расположен алфавитный скролл с волной, как в списке приложений. Заголовок и закрытие закреплены над списком; крупный шрифт и короткое окно используют доступные разделы.
- Сохранены фоновые загрузки, переиспользование строк, отмена загрузки при закрытии, клавиатурные и accessibility-действия. Просмотр не выделяет widget IDs; выбор запускает системную привязку и конфигурацию.
- Включены изменения main, опубликованные в 0.1.9: появление меню приложения снизу, переименование через заголовок и исправление нижней границы алфавита.
- Включено исправление main для сторонних RemoteViews: добавленные виджеты и превью используют отдельный framework-контекст вместо фабрики AppCompat/Material. Сохранены живые обновления, перенос между экранами, AppWidgetHost ID 1201 и существующие widget IDs.

## Установка

Установите `better-launcher-0.2.0-rc.14-release.apk` поверх предыдущего выпуска без удаления приложения. versionCode — 23, minSdk — 31, targetSdk — 36. Выпуск отмечен как prerelease; стабильный 0.1.9 остаётся последним стабильным релизом.

APK собран с R8 и удалением неиспользуемых ресурсов; отладка отключена. Совместимый сертификат первых APK сохранён для обновлений (Android Debug). SHA-256 сертификата: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`.

## Проверки и ограничения

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest :app:assembleRelease :app:lintRelease` — успешно. 4 unit-теста выполнены, ошибок нет. Debug/release lint: 0 ошибок, 27 прежних предупреждений, новых нет.
- На выделенном Android 12 (`emulator-5622`) прямой instrumentation-прогон `WidgetPickerTest,WidgetHostTest,SystemTransliterationTest` прошёл: 7/7 тестов. Проверены layout/image, отсутствие и повреждение превью, последняя строка многострочного layout, алфавит, accessibility, переиспользование строк, выбранный провайдер, отсутствие выделения widget IDs, живые обновления настоящего AppWidgetHost, перенос виджета между экранами и системная транслитерация.
- На итоговом подписанном release APK Android 12 `scripts/smoke-test.py` прошёл полностью: навигация виджетов, Back/HOME, настройки, поиск, Camera, свайп и удержание Phone, переименование через заголовок и нижняя граница алфавита. Аварий Better Launcher в AndroidRuntime нет. После тестов release APK установлен, HOME назначен; размер 1080×2400, font scale 1.0 и портрет сохранены.
- `apksigner verify` подтвердил подпись v2 и совместимость сертификата с 0.1.9. Manifest: versionCode 23, versionName 0.2.0-rc.14, minSdk 31, targetSdk 36; `debuggable=true` отсутствует.
- APK — 2 425 504 байта, 719 ZIP-записей. По сравнению с 0.1.9 размер вырос на 144 байта; набор записей совпадает. Изменены `classes.dex`, профиль `assets/dexopt/baseline.prof` и `AndroidManifest.xml`: прирост соответствует исправлению контекста RemoteViews и новой версии. Ресурсы и зависимости сохранены; тестовые провайдеры в основной APK не включены.
- SHA-256 APK: `95cc045e5927baca0cad2d3a02d142124f8351f4e60594fe3bfbc05a75f9f72f`. Файл `SHA256SUMS.txt` опубликован рядом с APK.

Первый smoke на сборке до повторного rebase прошёл навигацию, настройки, поиск и Camera, но не нашёл меню Phone после свайпа; этот прогон не считается успешным. Итоговый smoke после rebase прошёл весь сценарий. В начале итогового прогона UI Automator вернул null root; повтор получил свежую иерархию и проверка продолжилась успешно.

Исторические проверки выбора виджетов сохранены в [заметках 0.1.9](0.1.9.md), проверки исправления RemoteViews на Android 12/16 — в [заметках 0.2.0-rc.11](0.2.0-rc.11.md). Полный connected-набор, Android 16, узкий экран/font scale 1.3 и landscape в этом RC повторно не запускались. Физический телефон, рабочие профили, Private Space и полный TalkBack отдельно не проверены. Полный паритет Niagara не заявляется.
