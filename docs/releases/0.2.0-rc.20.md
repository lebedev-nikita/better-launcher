# Better Launcher 0.2.0-rc.20

Widget-management candidate based on `origin/main` (`cebe433`).

## Changes

- Removes app-name labels and ⋮ buttons above added widgets on both screens.
- Holding a widget opens size, provider settings when available, cross-screen transfer and removal.
- Native width/height sliders save immediately; size reset available. Provider directions/min/max respected. Narrow widgets center; width limited to current window.
- Normal taps/content scrolling remain. Holding does not press provider buttons; movement, cancellation, window-focus loss and detachment cancel pending holds.
- Accessible Configure widget action and Menu/Shift+F10 when focused open the menu. Sliders support keyboard/accessibility.
- Sizes belong to local widget IDs: retained across transfer/backup import, excluded from export, deleted with widgets. Invalid import rejected before writes; backup format remains 1.

## Installation

Install `better-launcher-0.2.0-rc.20-release.apk` without uninstalling. versionCode: 29, minSdk: 31, targetSdk: 36. Prerelease; stable 0.1.9 remains latest.

Follows `origin/main`; separate rc.19 alphabet change excluded. Renumbered after concurrent rc.19 publication so versionCode permits upgrades over it.

R8/resource shrinking enabled, debugging disabled, previous compatible certificate retained. Production store signing not configured.
