# Better Launcher 0.2.0-rc.20

Релиз-кандидат управления виджетами на основе `origin/main` (`cebe433`).

## Изменения

- Названия приложений и кнопки «⋮» над добавленными виджетами убраны на обоих экранах.
- Удержание самого виджета открывает управление: размер, настройки провайдера при их наличии, перенос между экранами и удаление.
- Ширина и высота настраиваются нативными ползунками и сохраняются сразу; есть сброс размера. Учитываются доступные направления и min/max провайдера. Более узкие виджеты центрируются; ширина ограничена текущим окном.
- Обычные нажатия и прокрутка содержимого сохранены. После удержания кнопка провайдера не нажимается; движение, отмена, потеря фокуса окна и отсоединение отменяют ожидающее удержание.
- Меню доступно через accessibility-действие «Настроить виджет» и Menu/Shift+F10 при фокусе на виджете. Ползунки поддерживают клавиатуру и accessibility.
- Размеры привязаны к локальным widget IDs: сохраняются при переносе и импорте backup, исключаются из экспорта и удаляются вместе с виджетом. Некорректный импорт отклоняется до изменения данных; формат backup остаётся версии 1.

## Установка

Установите `better-launcher-0.2.0-rc.20-release.apk` без удаления приложения. versionCode — 29, minSdk — 31, targetSdk — 36. Выпуск — prerelease; стабильный 0.1.9 остаётся latest.

Кандидат следует составу `origin/main`. Отдельная правка алфавита из rc.19 в него не включена. Номер повышен после параллельной публикации rc.19, чтобы versionCode позволял обновление поверх него.

APK использует R8 и удаление неиспользуемых ресурсов, отладка отключена. Для обновления сохранён сертификат предыдущих выпусков. Производственная подпись для магазина не настроена.

## APK и SHA-256

Проверенная сборка `better-launcher-0.2.0-rc.20-release.apk` перед финальным обновлением документации: **2 435 128 байт**, 719 ZIP-записей. Прирост относительно rc.17 — **9 252 байта (0,381%)**, преимущественно DEX с обработкой удержания и размеров; набор файлов совпадает. Размер итогового APK и исходный коммит указаны в GitHub Release.

SHA-256 итогового APK опубликован рядом с ним в `SHA256SUMS.txt` и указан в GitHub Release. Это позволяет собрать APK из того же опубликованного коммита main, на который поставлен тег, без последующего изменения исходного коммита ради записи checksum в документацию.

Физические устройства, рабочие профили, Private Space, конкретные виджеты ChatGPT/Todoist и полный TalkBack не проверены. Полный паритет Niagara не заявляется.
