# Better Launcher 0.2.0-rc.35

Главный экран без дублирующей кнопки порядка избранного. Version code — 44; Android 12+ (API 31), target API 36.

## Изменения

- Удалена кнопка «Изменить порядок избранного» под списком главного экрана.
- Режим перестановки по-прежнему включается пунктом «Изменить порядок» в меню долгого удержания избранного приложения. Сохраняются ручки перетаскивания, клавиатурные/accessibility-действия, автосохранение и выход через «Готово», Back и HOME.
- Инструментальный тест входит в режим через меню и проверяет отсутствие дублирующей кнопки до и после перестановки.

## Проверки

- `:app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug` — успешно; 14 unit-тестов, 0 lint errors и 27 warnings. Список предупреждений совпадает с предыдущим отчётом, новых нет.
- Полный `:app:connectedDebugAndroidTest` на выделенном Android 12/API 31 — 30/30. На Android 16/API 36 первый полный прогон — 29/30: WidgetOrderTest не дождался сохранения порядка после drag; отдельный повтор этого теста прошёл. Тест избранного прошёл на обеих версиях. Результат повторного полного набора указан в GitHub Release.
- Проверяются главный экран без кнопки, сохранённый вход через меню, footer и Back/HOME в portrait, 945×2100/font scale 1.3, landscape и с левым алфавитом. Итоговые результаты native UI и smoke подписанного APK указаны в GitHub Release; снимки и логи остаются локально в `.impeccable/review/rc35/`.
- `git diff --check`, ссылки документации и JSON sidecar проверены. Формат backup, избранное и размещение виджетов не меняются.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. Итоговый APK собирается из чистого опубликованного main; точные размер, коммит, SHA-256, сравнение подписи/состава с rc.34 и результаты установки указаны в GitHub Release. Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин не настроены. Физический телефон/OEM и полный TalkBack-сеанс не проверены; полный паритет Niagara не заявляется.
