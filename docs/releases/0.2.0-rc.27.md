# Better Launcher 0.2.0-rc.27

Softer widget-resize haptic feedback. Version code: 36; Android 12+ (API 31), target API 36.

## Changes

- Android 14+ requests `SEGMENT_FREQUENT_TICK` instead of `CLOCK_TICK` for actual width/height changes. Designed for frequent, very soft steps; Android may omit vibration if hardware cannot produce a suitable effect.
- Uses existing AndroidX. Android 12–13 fall back to compatible `CLOCK_TICK`; the softer effect is unavailable there. No new dependencies/permissions.
- Preserves four edges, keyboard/accessibility, one request per new size, silent within-step/bound repeats, release without new size, cancellation/movement. System haptic settings respected; alphabet feedback unchanged.

Effect/fallback: [AndroidX HapticFeedbackConstantsCompat](https://developer.android.com/reference/androidx/core/view/HapticFeedbackConstantsCompat#SEGMENT_FREQUENT_TICK).
