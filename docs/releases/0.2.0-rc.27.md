# Better Launcher 0.2.0-rc.27

Мягкий тактильный отклик при изменении размера виджета. Version code — 36; Android 12+ (API 31), target API 36.

## Изменения

- На Android 14+ каждое фактическое изменение ширины или высоты запрашивает `SEGMENT_FREQUENT_TICK` вместо `CLOCK_TICK`. Эффект предназначен для частых шагов и ожидается очень мягким; если устройство не умеет воспроизвести подходящий эффект, Android может оставить шаг без вибрации.
- Вызов проходит через существующую библиотеку AndroidX. На Android 12–13 она использует совместимый `CLOCK_TICK`: новый мягкий эффект на этих версиях недоступен. Новых зависимостей и разрешений нет.
- Сохранены четыре границы, клавиатура и accessibility, один запрос на новое значение размера, тихие повторы внутри шага/на пределе, отпускание без нового размера, отмена и перемещение. Системные настройки тактильного отклика учитываются. Буквенный индекс сохраняет прежний отклик.

Описание эффекта и fallback: [AndroidX HapticFeedbackConstantsCompat](https://developer.android.com/reference/androidx/core/view/HapticFeedbackConstantsCompat#SEGMENT_FREQUENT_TICK).

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов; lint — 0 ошибок, 27 прежних предупреждений, новых нет.

Обновлённый WidgetResizeHapticTest прошёл на выделенных Android 12/API 31 и Android 16/API 36: точный тип/число запросов для всех четырёх границ, следующего шага и возврата, отпускания, отмены/второго пальца, пределов, клавиатуры/accessibility и тихого перемещения. На API 36 проверен `SEGMENT_FREQUENT_TICK`, на API 31 — `CLOCK_TICK`.

## APK и ограничения

Публикуются подписанный release APK с R8 и удалением неиспользуемых ресурсов и SHA256SUMS.txt. APK собирается из чистого опубликованного коммита main; тег указывает на этот коммит. Сохраняется прежний сертификат для совместимости обновлений.

Эмуляторы подтверждают запрос эффекта, а не ощущение его силы на телефоне. Физические устройства/OEM и полный TalkBack остаются вне подтверждённого покрытия. Production-сертификат и магазин не настроены; полный паритет Niagara не заявляется.
