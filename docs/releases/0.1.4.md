# Better Launcher 0.1.4

A patch based on stable 0.1.3 adds adjustable system-wallpaper dimming. The feature is also merged into `main`, which retains version 0.2.0-rc.1.

## Changes

- A Wallpaper dimming slider replaces the settings toggle, ranging from 0 to 100% in 1% steps and displaying the selected percentage.
- Removes mandatory minimum dimming: 0% fully shows the system wallpaper; 100% makes the background black. Default: 20%.
- Changes are saved immediately and applied to home and the app list. Keyboard and accessibility actions are supported.
- The percentage is stored in backup format 1. Legacy `dimWallpaper: true` maps to 20%, `false` to 0%; an explicit percentage takes precedence. Invalid types or values outside 0–100 are rejected before data changes.

## Installation

Download `better-launcher-0.1.4-debug.apk` from the release assets and install over 0.1.3 on Android 12+. The APK uses the same local debug key. `SHA256SUMS.txt` contains its SHA-256.

The APK is intended for testing; production signing and store publishing are not configured yet.
