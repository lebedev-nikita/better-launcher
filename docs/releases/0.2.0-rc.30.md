# Better Launcher 0.2.0-rc.30

Возвращён системный CLOCK_TICK при изменении размера виджета. Version code — 39; Android 12+ (API 31), target API 36.

## Изменения

- Каждое фактическое изменение ширины или высоты виджета снова запрашивает `CLOCK_TICK` на всех поддерживаемых версиях Android, включая клавиатуру и accessibility.
- Сохраняются сетка 12 dp, тихие повторы внутри шага/на пределе, перемещение и отмена, автосохранение и четыре границы. Сохранены перестановка виджетов/избранного из rc.28 и главный экран без верхнего отступа из rc.29.
- Публичный `View.performHapticFeedback` не предоставляет параметра амплитуды для `CLOCK_TICK`. Сила эффекта остаётся под управлением устройства и системных настроек; уменьшение амплитуды в приложении не заявляется. Новых разрешений или зависимостей нет.

API и системные настройки: [Android haptic feedback](https://developer.android.com/develop/ui/views/haptics/haptic-feedback).

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов; lint — 0 ошибок и 27 прежних предупреждений. На изменённом исходнике замечаний нет.

Целевой набор из 10 инструментальных тестов прошёл на каждой версии: WidgetHostTest, WidgetHomeLayoutTest, WidgetGestureTest, SystemTransliterationTest, AlphabetHapticTest и WidgetResizeHapticTest. На Android 12/API 31 использован `:app:connectedDebugAndroidTest` с фильтром классов; на Android 16/API 36 — AndroidJUnitRunner. Тест точного типа/числа запросов подтверждает CLOCK_TICK на всех четырёх границах, следующий шаг и возврат, пределы, отпускание, отмену/второго пальца, клавиатуру/accessibility и тихое перемещение. Первые запуски на обоих эмуляторах прервались с `Process crashed`; после повторной установки и назначения HOME целевой набор прошёл без изменения исходников. Полный набор всех инструментальных тестов не запускался.

Подписанный release APK прошёл `scripts/smoke-test.py` на Android 12/API 31 и Android 16/API 36: навигация виджетов, поиск/IME, запуск/HOME, меню/rename, алфавит и отсутствие аварий лаунчера. Первый smoke API 36 остановился на ожидании страницы после свайпа; отдельный повтор жеста и повтор всего smoke прошли на том же APK. Это не считается успешным первым прогоном.

Нативный редактор реального AppWidgetHost проверен на обеих версиях в портрете, 945×2100/font scale 1.3 и фактическом 2400×1080 landscape. Изменение ширины/высоты и закрытие через Done, Back и HOME прошли. Осмотрены снимки всех трёх конфигураций; геометрия не меняется от возврата CLOCK_TICK. Размер экрана, шрифт и поворот восстановлены; тестовый виджет и тестовый APK удалены, временная привязка отозвана. Провайдер находится только в androidTest. Снимки и логи остаются локально в `.impeccable/review/rc30/`. Рабочие Markdown-пути, JSON и `git diff --check` проверены.
