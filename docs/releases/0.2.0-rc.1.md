# Better Launcher 0.2.0-rc.1

The first 0.2.0 minor-version release candidate, with a separate left widget screen. Marked as prerelease; 0.1.x is the stable release line.

## Changes

- Swiping right on empty home space opens widgets; swiping left returns home. Navigation buttons, Back and HOME are available.
- One widget occupies home; others appear in a scrollable list on the left. Menus move/remove widgets. Choosing a new home widget keeps the previous one on the left screen.
- Upgrading the old stack keeps its first widget on home and moves others left. Backup import preserves local widget IDs, home selection and pending binding; format 1 stays compatible.
- App gestures and widget-content interaction remain. The alphabet reserves bottom-button space with large fonts; transition animations respect system animation disabling.
- Includes 0.1.5's updated app long-press menu: primary actions immediately available; More expands others in place.
- Includes 0.1.4's wallpaper-dimming slider: 0–100%, saved percentage and legacy-backup compatibility.
- Includes 0.1.3's Latin navigation: A–Z and final “#”; ICU4J Russian-Latin/BGN groups Cyrillic names (Яндекс → Y).

## Installation

Download `better-launcher-0.2.0-rc.1-debug.apk` and install over 0.1.0–0.1.5. Signing matches the previous release; normal updates preserve settings. Minimum: Android 12 (API 31), versionCode: 8. `SHA256SUMS.txt` contains the APK SHA-256.

Uses the previous debug key. Permanent production signing and store publishing are not configured. This is a preview release for testing.

## Verification and limitations

The final build passed 9 unit tests, all 11 connected tests and full Android 12 smoke. Lint: 0 errors, 27 previous warnings, no new warnings. APK v2 signing was verified and is compatible with previous releases.

Final APK on Android 16 is unverified: preparation retries were interrupted by `uiautomator` and system package-service failures. Narrow screen/font scale 1.3, landscape and left-handed mode after the last merge are also unconfirmed; historical Android 12/16 widget checks are retained separately.

Details: [release-candidate verification](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/verification-0.2.0-rc.1.md), [widget verification](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/widgets-verification.md), [current coverage](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/features.md).

Physical phones, third-party widget providers and full TalkBack coverage are unverified. Full Niagara parity is not claimed.
