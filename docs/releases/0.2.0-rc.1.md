# Better Launcher 0.2.0-rc.1

Первый релиз-кандидат минорной версии 0.2.0 с отдельным экраном виджетов слева. Выпуск отмечен как prerelease; стабильная ветка выпуска — 0.1.x.

## Изменения

- Свайп вправо по свободному месту главного экрана открывает экран виджетов; свайп влево возвращает домой. Доступны кнопки перехода, Back и HOME.
- На главном экране размещается один виджет; остальные находятся в прокручиваемом списке слева. Меню позволяет переносить и удалять виджеты. При выборе нового главного прежний остаётся на левом экране.
- При обновлении прежней стопки первый виджет остаётся на главном, остальные переходят налево. Локальные widget IDs, выбор главного и незавершённая привязка сохраняются при импорте backup; формат 1 остаётся совместимым.
- Жесты приложений и содержимого виджетов сохранены. Алфавит резервирует место нижних кнопок при крупном шрифте; анимации перехода учитывают системное отключение анимаций.
- Включено обновлённое меню удержания приложения из 0.1.5: основные действия доступны сразу, «Дополнительно» раскрывает остальные на месте.
- Включена регулировка затемнения системных обоев из 0.1.4: ползунок 0–100%, сохранение выбранного процента и совместимость прежних резервных копий.
- Включена латинская навигация из 0.1.3: A–Z и заключительный «#»; кириллические названия группируются через ICU4J Russian-Latin/BGN (Яндекс → Y).

## Установка

Скачайте `better-launcher-0.2.0-rc.1-debug.apk` из файлов этого релиза и установите поверх 0.1.0–0.1.5. Подпись совпадает с предыдущим выпуском; обычное обновление сохраняет настройки. Минимальная версия — Android 12 (API 31), versionCode — 8. Файл `SHA256SUMS.txt` содержит SHA-256 APK.

APK подписан прежним отладочным ключом. Постоянная production-подпись и публикация в магазине не настроены. Это предварительный выпуск для тестирования.

## Проверки и ограничения

Итоговая сборка прошла 9 unit-тестов, все 11 connected-тестов и полный smoke-прогон на Android 12. Lint: 0 ошибок, 27 прежних предупреждений, новых нет. Подпись APK v2 проверена и совместима с предыдущими выпусками.

Итоговый APK на Android 16 не проверен: повторные попытки во время подготовки прерывались сбоем `uiautomator` и системного package service. Узкий экран/font scale 1.3, landscape и левосторонний режим после последнего объединения также не подтверждены; исторические проверки виджетов на Android 12/16 сохранены отдельно.

Подробности: [проверка релиз-кандидата](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/verification-0.2.0-rc.1.md), [проверка виджетов](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/widgets-verification.md), [текущее покрытие](https://github.com/better-launcher/better-launcher/blob/v0.2.0-rc.1/docs/features.md).

Физические телефоны, сторонние провайдеры виджетов и полная проверка TalkBack ещё не проверены. Полный паритет Niagara не заявляется.
