# Better Launcher 0.2.0-rc.18

Релиз-кандидат более читаемого алфавитного индекса на основе main с 0.2.0-rc.17.

## Изменения

- Обычный размер букв увеличен с 11sp до 16sp, шаг — с 16dp до 22dp. При крупном системном шрифте шаг растёт; короткое окно ограничивает размер букв, чтобы они не накладывались друг на друга.
- Во всех размерах окна показаны только буквенные разделы, содержащие видимые приложения. Скрытие, восстановление и переименование приложения обновляют набор букв; группировка кириллицы через Android ICU сохранена.
- То же оформление и фильтрация действуют в алфавите выбора виджета, по доступным провайдерам.
- Сохранены нижнее положение полосы с отступом над footer, волна, левосторонний режим, системный Back, клавиатура и accessibility. «★» возвращает к избранному, конечный «#» остаётся навигационным пунктом, включая каталог без буквенных разделов.

## Установка

Установите `better-launcher-0.2.0-rc.18-release.apk` поверх предыдущей версии. versionCode — 27, minSdk — 31, targetSdk — 36. Выпуск помечен как prerelease; стабильный 0.1.9 остаётся latest.

Release использует R8 и удаление неиспользуемых ресурсов, отладка отключена. Прежний сертификат сохранён для совместимости обновлений; производственная подпись для магазина не настроена.
