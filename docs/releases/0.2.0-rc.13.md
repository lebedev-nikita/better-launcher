# Better Launcher 0.2.0-rc.13

Candidate rebased onto main (`795be66`) with Save on the right of the rename form. Stable 0.1.9 remains Latest; earlier candidates retained.

## Changes

- Save aligns with the name field's right edge for right-thumb access. Width follows text; minimum 52 dp touch height and 16 dp horizontal margins remain. The shared folder form uses the same placement.
- Preserves rc.4/rc.6's compact alphabet: nonempty sections only, bottom placement and matching footer reservation on home/list. Release below letters selects the last available section; cancellation does not navigate.
- Includes main's widget-provider previews, content-measured multiline layouts, row reuse and alphabet picker; app-menu entry after size/inset measurement and heading renaming. Widget selection adapts to the shared compact alphabet; binding/configuration remain.
- Publishes a signed release APK with R8/unused-resource removal.

## Installation

Download `better-launcher-0.2.0-rc.13-release.apk` and update without uninstalling. versionCode: 22, minSdk: 31 (Android 12), targetSdk: 36. `SHA256SUMS.txt` contains the APK SHA-256.

Previous Android Debug certificate retained for compatibility; release build, debugging disabled. Private signing configuration outside Git. Separate production certificate/store publishing not configured.
