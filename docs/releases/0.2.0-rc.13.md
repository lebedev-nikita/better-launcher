# Better Launcher 0.2.0-rc.13

Релиз-кандидат после rebase на main (`795be66`) с кнопкой «Сохранить» справа в форме переименования. Стабильный выпуск 0.1.9 остаётся Latest; прежние кандидаты сохранены.

## Изменения

- Кнопка «Сохранить» выровнена по правому краю поля названия, чтобы её было удобнее нажимать большим пальцем правой руки. Ширина зависит от текста; минимальная высота области нажатия 52 dp и горизонтальные отступы 16 dp сохранены. Общая форма использует это расположение и для папок.
- Сохранён компактный алфавит из rc.4/rc.6: только непустые разделы, расположение внизу и одинаковое резервирование footer на главном экране и в списке. Отпускание ниже букв выбирает последний доступный раздел; отмена жеста не запускает навигацию.
- Включены изменения main: превью провайдеров виджетов, измерение многострочного layout по содержимому, переиспользование строк и алфавитная прокрутка выбора виджета; появление меню приложения после расчёта размеров/insets и переименование по заголовку. Выбор виджета адаптирован к общему компактному алфавиту; привязка и конфигурация сохранены.
- Публикуется подписанный release APK с R8 и удалением неиспользуемых ресурсов.

## Установка

Скачайте `better-launcher-0.2.0-rc.13-release.apk` и установите поверх предыдущего выпуска без удаления приложения. versionCode — 22, minSdk — 31 (Android 12), targetSdk — 36. `SHA256SUMS.txt` содержит SHA-256 APK.

Сохранён прежний сертификат Android Debug для совместимости обновлений; сам APK является release-сборкой с отключённой отладкой. Приватная настройка подписи хранится вне Git. Отдельный production-сертификат и публикация в магазине пока не настроены.

- Итоговый подписанный APK установлен на Android 12 и Android 16 / API 36 (`BetterLauncher_Rename_API_36`); HOME и запуск MainActivity успешны. На обоих устройствах проверены правый край кнопки относительно поля, минимальная высота 52 dp, доступность действия, портрет с клавиатурой, 840×1866/font scale 1.3, landscape, Back/HOME, сохранение после перезапуска, отмена и восстановление исходного имени. В landscape клавиатура закрывалась для проверки действия формы. Размер, шрифт и ориентация восстановлены.
- Первые UI-прогоны остановились из-за проверки отсутствующего окна IME в XML-дереве, хотя клавиатура видна на скриншоте; повтор использует состояние InputMethodManager и визуальную проверку. Первый smoke на обоих Android остановился при попытке нажать Camera за полноэкранной IME. Сценарий дополнен закрытием клавиатуры перед нажатием результата.
- Оба эмулятора с GPU host затем завершились с кодом 134 после ошибок ColorBuffer; прерванные сценарии не считаются успешными. Повтор на программном рендерере описан ниже.

На Android 12 с программным рендерером полный smoke итогового APK и проверка переименования при алфавите слева прошли; сторона алфавита восстановлена. Аварий процесса Better Launcher в успешном smoke нет. Последний повтор на Android 12 и Android 16 остановлен после проблем получения UI-дерева (`null root node` / `Unable to obtain a fresh UI hierarchy`). Полный smoke и левосторонний режим на Android 16 не подтверждены; успешные сценарии переименования и размеров окна на этом Android перечислены выше. Тестовые настройки размера, шрифта и ориентации восстановлены. На Android 12 данные приложения очищены до исходного тестового состояния, итоговый release APK оставлен установленным, назначен HOME и запущен. На Android 16 итоговая очистка тестовых данных и повторный запуск не подтверждены: команды package/am завершились по тайм-ауту. Успешные установка и назначение HOME до UI-проверок подтверждены. Локальные логи и снимки находятся в `.impeccable/review/rename-save-rc13/` и не входят в Git.

Физические устройства, рабочие профили, Private Space и полная проверка TalkBack в этом кандидате не проверены. Полный паритет Niagara не заявляется.
