# Better Launcher 0.2.0-rc.6

Релиз-кандидат с кнопкой «Сохранить» справа в окне переименования.

## Изменения

- Кнопка «Сохранить» выровнена по правому краю формы названия, чтобы её было удобнее нажимать большим пальцем правой руки. Ширина зависит от текста, прежние отступы и минимальная высота области нажатия 52 dp сохранены.
- Общая форма редактирования названий использует это расположение и для папок. Сохранение и отмена работают по-прежнему; сторона алфавита не меняет расположение кнопки.
- Сохранён компактный алфавит из 0.2.0-rc.4. Включены исправления актуального main (`9d9d503`): отпускание ниже букв выбирает последний доступный раздел, а анимация меню начинается после расчёта размеров и insets.
- Тест нижней границы алфавита адаптирован к компактному варианту: проверяются короткое/высокое окно, обе стороны, наличие/отсутствие `#`, последнее MOVE и отмена жеста.

## Установка

Скачайте `better-launcher-0.2.0-rc.6-release.apk` и установите поверх предыдущего выпуска без удаления приложения. Минимальная версия — Android 12 (API 31), targetSdk — 36, versionCode — 15. Коды 13 и 14 зарезервированы параллельными выпусками; версия этого кандидата позволяет обычное обновление поверх них.

APK подписан прежним сертификатом для совместимости обновлений. R8 и удаление неиспользуемых ресурсов включены, отладка отключена. `SHA256SUMS.txt` содержит SHA-256 APK. Выпуск публикуется как prerelease и не меняет последний стабильный релиз. Полный паритет Niagara не заявляется.

## Проверки и ограничения

- `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease` — успешно после объединения исходников; все 4 unit-теста прошли. После изменения зарезервированного номера версии итоговые debug/release APK 0.2.0-rc.6 пересобраны успешно.
- Debug/release lint: 0 ошибок и 27 прежних предупреждений. Состав сообщений сравнен с отчётами rc.4; новых предупреждений нет.
- Подпись проверена `apksigner`; сертификат SHA-256 совпадает с rc.4: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Manifest не содержит `debuggable=true`; R8 и resource shrinking включены.
- APK: 2 417 480 байт, на 1084 байта больше rc.4. Набор файлов APK совпадает. Изменены manifest с номером версии, DEX/профили и XML анимации меню; прирост соответствует исправлениям из main и выравниванию кнопки. Данных ICU4J нет.
- SHA-256 APK: `6e7817ec53aff5b4f694e53e10082875ff9d5e2bdcc5617e95439430018a0d50`.
- Итоговый подписанный APK установлен через `adb install -r --no-streaming` на выделенном Android 16 / API 36 (`BetterLauncher_FooterRC_API_36`, `emulator-5632`). Назначение HOME и запуск MainActivity вернули успех.

Connected-тесты и визуальная проверка **не подтверждены**. Первый connected-прогон выявил несовместимость теста из main с API компактного алфавита; она исправлена, test APK компилируется. Следующие прогоны на Android 12 (`BetterLauncher_Rename_API_31`, затем `BetterLauncher_API_31`) остановились при установке APK из-за исчезнувшего сервиса package / Broken pipe; выполнено 0 тестов. Хост был перегружен параллельными сборками и эмуляторами, наблюдались ANR системных приложений.

На Android 16 установка и запуск release APK прошли, но затем исчезли сервис settings и текущий фокус окна. UI-сценарий остановился до изменения масштаба, размера или ориентации. Расположение кнопки, сохранение/отмена, полный smoke, крупный шрифт, landscape и левосторонний режим на итоговом APK остались непроверенными. Успех прежних выпусков не считается проверкой этого кандидата.

Физические устройства, рабочие профили, Private Space и полная проверка TalkBack в этом кандидате не проверены.
