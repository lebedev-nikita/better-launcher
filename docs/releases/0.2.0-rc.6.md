# Better Launcher 0.2.0-rc.6

Release candidate with a right-aligned Save button in the rename dialog.

## Changes

- Save aligns with the form's right edge for easier right-thumb access. Width follows text; existing margins and the minimum 52 dp touch height remain.
- The shared name-editing form uses the same placement for folders. Save/cancel behavior is unchanged; alphabet side does not move the button.
- Preserves rc.4's compact alphabet and includes current main (`9d9d503`) fixes: release below letters selects the last available section; menu animation starts after measurement/insets.
- Adapts the lower-boundary test to the compact alphabet: short/tall window, both sides, presence/absence of `#`, final MOVE and cancellation.

## Installation

Download `better-launcher-0.2.0-rc.6-release.apk` and update without uninstalling. Minimum: Android 12 (API 31), targetSdk: 36, versionCode: 15. Codes 13 and 14 are reserved for concurrent releases; this candidate can update over them.

Uses the previous compatible certificate. R8/resource shrinking enabled, debugging disabled. `SHA256SUMS.txt` contains the APK SHA-256. Published as prerelease without replacing the latest stable release. Full Niagara parity is not claimed.
