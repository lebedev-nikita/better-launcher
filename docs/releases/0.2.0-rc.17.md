# Better Launcher 0.2.0-rc.17

Релиз-кандидат компактного алфавита на основе `origin/main` (`a04e631771005d3dcfa3f10ec323363b527072d4`).

## Изменения

- Алфавит закреплён у нижней границы доступной области с отступом 24dp над нижними кнопками и системными insets.
- Шаг между буквами уменьшен с 23dp до 16dp. При крупном системном шрифте он растёт, а короткое окно ограничивает высоту полосы.
- Рисование и выбор пальцем используют одну геометрию; сохранены волна, конечный «#», системный Back, управление клавиатурой, accessibility и левосторонний режим.
- Smoke-скрипт использует реальные границы полосы, учитывая поворот и боковую системную панель.
- Сохранены изменения main: превью виджетов, исправление загрузки RemoteViews, меню приложения и переименование через заголовок.

## Установка

Установите `better-launcher-0.2.0-rc.17-release.apk` без удаления приложения. versionCode — 26, minSdk — 31, targetSdk — 36. Выпуск помечен как prerelease; стабильный 0.1.9 остаётся latest.

Кандидат следует составу main. Отдельный редактор сортировки избранного из rc.16 и правки других отдельных RC-веток не включены; версия Android повышена для обновления поверх предыдущих APK.

APK использует R8 и удаление неиспользуемых ресурсов, отладка отключена. Сохранён прежний сертификат для совместимости обновлений. Производственная подпись для магазина не настроена.
