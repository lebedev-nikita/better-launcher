# Better Launcher 0.2.0-rc.17

Compact-alphabet candidate based on `origin/main` (`a04e631771005d3dcfa3f10ec323363b527072d4`).

## Changes

- Alphabet anchors to the usable area's bottom, 24dp above footer buttons/system insets.
- Letter spacing decreases from 23dp to 16dp, grows with system font scale, and is height-limited in short windows.
- Drawing/touch selection share geometry; wave, final “#”, system Back, keyboard, accessibility and left-handed mode remain.
- Smoke uses actual rail bounds, accounting for rotation/side system navigation.
- Preserves main's widget previews, RemoteViews loading fix, app menus and heading renaming.

## Installation

Install `better-launcher-0.2.0-rc.17-release.apk` without uninstalling. versionCode: 26, minSdk: 31, targetSdk: 36. Prerelease; stable 0.1.9 remains latest.

Follows main's feature set. Separate rc.16 favorites-order editor and other RC-branch changes are excluded; Android version code raised to allow upgrades over prior APKs.

R8/resource shrinking enabled, debugging disabled. Previous certificate retained for compatibility. Production store signing not configured.
