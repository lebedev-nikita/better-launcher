# Better Launcher 0.2.0-rc.33

Упрощённое меню виджета. Version code — 42; Android 12+ (API 31), target API 36.

## Изменения

- Удалены пункты «Сбросить размер и положение» и «На экран виджетов» из меню удержания виджета.
- «Переместить и изменить размер» использует контурную иконку с четырьмя стрелками перемещения.
- На странице виджетов сохранено действие «На главный экран». Размеры, положение и существующие widget IDs сохраняются; редактор четырёх границ работает как прежде.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов, lint — 0 ошибок и 27 существующих предупреждений. Сравнение с rc.32 не выявило новых предупреждений.

На выделенных Android 12/API 31 и Android 16/API 36 прошли по 6/6 выбранных instrumentation-тестов: WidgetHostTest и SystemTransliterationTest. Обновлённый тест проверяет отсутствие удалённых команд на обоих экранах, изменение размера/перемещение, сохранность геометрии и главного ID после закрытия редактора, живые RemoteViews-обновления и удаление.

До объединения с актуальным main/rc.32 на предварительной подписанной сборке на Android 12 и Android 16 прошёл `scripts/smoke-test.py`: навигация, поиск/IME, запуск Camera, меню приложения, переименование и алфавит. Реальный виджет Clock на Android 12 проверен в портрете, 945×2100/font scale 1.3, landscape и с левым алфавитом: удержание открывает новое меню, редактор запускается, Back/HOME завершают редактирование. Нативные снимки проверены, настройки размера, шрифта, ориентации и стороны алфавита восстановлены. Локальные материалы — `.impeccable/review/widget-menu/`.

Первый API 31 прогон остановился до действий с меню при ожидании фокуса окна; повторный прогон после перезапуска прошёл. Горизонтальный UI-прогон прервался системным ANR/NullPointerException в панели навигации Android при подключении accessibility; сценарий прошёл с жестовой навигацией. Исходный режим навигации восстановлен. Старый API 36 эмулятор также показывал ANR System UI; для проверки создан новый выделенный AVD. После объединения с rc.32 первый API 31 повтор столкнулся с оставшимся Clock из визуального сценария; данные выделенного тестового приложения очищены перед повтором.

## APK и ограничения

Итоговый APK собирается из чистого опубликованного main и использует R8 и удаление неиспользуемых ресурсов. Проверки итоговой подписанной сборки, точный размер и SHA-256 публикуются в GitHub Release и SHA256SUMS.txt. Сертификат SHA-256 совместимости: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин пока не настроены.

Release lint и состав итогового APK проверяются перед публикацией; debug APK не прикрепляются к релизу.

Точный размер и SHA-256 итогового APK публикуются в GitHub Release и SHA256SUMS.txt. Gradle добавляет в APK метаданные исходного Git-коммита; финальный файл содержит коммит тега.

Физический телефон и Todoist/OEM-провайдеры вне подтверждённого покрытия этого изменения. Полный паритет Niagara не заявляется.
