# Better Launcher 0.2.0-rc.33

Упрощённое меню виджета. Version code — 42; Android 12+ (API 31), target API 36.

## Изменения

- Удалены пункты «Сбросить размер и положение» и «На экран виджетов» из меню удержания виджета.
- «Переместить и изменить размер» использует контурную иконку с четырьмя стрелками перемещения.
- На странице виджетов сохранено действие «На главный экран». Размеры, положение и существующие widget IDs сохраняются; редактор четырёх границ работает как прежде.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 14 unit-тестов, lint — 0 ошибок и 27 существующих предупреждений. Сравнение с rc.31 не выявило новых предупреждений.

На выделенных Android 12/API 31 и Android 16/API 36 прошли по 6/6 выбранных instrumentation-тестов: WidgetHostTest и SystemTransliterationTest. Обновлённый тест проверяет отсутствие удалённых команд на обоих экранах, изменение размера/перемещение, сохранность геометрии и главного ID после закрытия редактора, живые RemoteViews-обновления и удаление.

На подписанной сборке Android 12 прошёл `scripts/smoke-test.py`: навигация, поиск/IME, запуск Camera, меню приложения, переименование и алфавит. Реальный виджет Clock проверен в портрете, 945×2100/font scale 1.3, landscape и с левым алфавитом: удержание открывает новое меню, редактор запускается, Back/HOME завершают редактирование. Нативные снимки проверены, настройки размера, шрифта, ориентации и стороны алфавита восстановлены. Локальные материалы — `.impeccable/review/widget-menu/`.

Первый API 31 прогон остановился до действий с меню при ожидании фокуса окна; повторный прогон после перезапуска прошёл. Горизонтальный UI-прогон прервался системным ANR/NullPointerException в панели навигации Android при подключении accessibility; сценарий прошёл с жестовой навигацией. Исходный режим навигации восстановлен. Старый API 36 эмулятор также показывал ANR System UI; для проверки создан новый выделенный AVD.

## APK и ограничения

Release APK использует R8 и удаление неиспользуемых ресурсов. Сертификат SHA-256 совпадает с rc.31: `7618fbcfaeec605563e1f7b8200be66d60c923c268cbeebdbbbc98b54fd71b5b`. Прежний сертификат Android Debug сохраняется для совместимости обновлений; production-сертификат и магазин пока не настроены.

Предварительная подписанная сборка: 2 456 272 байта против 2 456 708 в rc.31; 719 ZIP entries, 1 364 932 байта DEX, native libraries нет. Уменьшение соответствует удалению двух команд и их callbacks. Release lint — 0 ошибок и те же 27 предупреждений.

Точный размер и SHA-256 итогового APK публикуются в GitHub Release и SHA256SUMS.txt. Gradle добавляет в APK метаданные исходного Git-коммита; финальный файл содержит коммит тега.

Физический телефон и Todoist/OEM-провайдеры вне подтверждённого покрытия этого изменения. Полный паритет Niagara не заявляется.
