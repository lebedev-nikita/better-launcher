# Better Launcher 0.2.0-rc.50

Separate icon/name menus, right swipe to widgets and stable holds during catalog refresh. Version code: 59; Android 12+ (API 31), target API 36.

## Changes

- Icon hold opens notifications/quick actions/attached apps; name hold opens shortcut management.
- Home right swipe, including icons/names/folders and app rows in All apps/search, opens widgets. Search field retains editing gestures. Horizontal movement no longer opens menus and cancels taps to avoid launch. Widget-page left swipe returns home.
- Icon remains 38dp in 48dp area; name area minimum 48dp high. Taps launch; ordering/third-party widget gestures remain.
- Hidden icons retain named name-row accessibility/existing management action for quick actions.
- Catalog/notification refresh no longer removes rows under a held finger: home refresh waits for touch completion/menu dismissal and preserves scrolling. Diagnosed on cold start and confirmed by regression.
- Preserves main's flat management/no duplicate launch, swipe messages/compact widget search. Documentation/sidecar/smoke updated.

- Smoke Back hides only the actually visible keyboard: mInputShown may remain stale after its window disappears. Confirmed by landscape screenshot/dumpsys.
- Includes main fix immediately removing hidden apps from the alphabet.
