# Better Launcher 0.2.0-rc.60

## Changes

- Separate cross beside each icon-menu quick action hides it only in Better Launcher without closing menu; source-app shortcut not deleted/disabled.
- Undo hiding restores latest hidden action in open menu. Show hidden actions restores all for that app. If all shortcuts hidden/no other content, menu explains it.
- Hidden state keyed by shortcut ID separately for app/profile; survives Activity recreation/action renaming and belongs to backup version 1. Old backups show all; malformed lists rejected atomically before writes, local widget IDs preserved.
- Crosses have separate accessible labels/48 dp areas and keyboard access. Rows grow with text; avatars/app icons retained. No extra permissions.
