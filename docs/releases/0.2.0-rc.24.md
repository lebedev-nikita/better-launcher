# Better Launcher 0.2.0-rc.24

Widget dragging in the resize mode, with a fine 12 dp grid. Version code: 33; Android 12+ (API 31), target API 36.

## Changes

- Hold menu offers Move and resize. Drag widget content along both axes; four handles resize. No additional mode/dialog or circular widget arrows.
- Width/height and movement snap to 12 dp, four times finer than a 48 dp icon. Window-change width limits also follow the grid. Unsupported resizeMode directions stay fixed; provider limits take precedence if a narrow range contains no grid point.
- Widget stays within its column and above the editor footer. Reduce width for horizontal movement room. Increasing width clamps horizontal offset to the column.
- Position/size save immediately, surviving restart, home/widget transfer, rotation and backup import. Legacy two/three-field records default horizontal offset to zero; local IDs/parameters remain excluded from export. New field validated before atomic import.
- Keyboard arrows/four named accessibility actions move the widget area; handles still resize. Canceled gestures restore size/both offsets. Reset size and position restores original geometry. Done, outside tap, Back/HOME and lifecycle retain completion behavior.
