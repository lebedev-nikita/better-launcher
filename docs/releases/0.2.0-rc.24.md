# Better Launcher 0.2.0-rc.24

Перетаскивание виджета в том же режиме, где меняется размер, и мелкая сетка 12 dp. Version code — 33; Android 12+ (API 31), target API 36.

## Изменения

- Меню удержания предлагает «Переместить и изменить размер». В редакторе тяните содержимое виджета для перемещения по двум осям, а четыре маркера — для размера. Дополнительный режим или диалог не нужен; круговых стрелок на виджете нет.
- Изменяемые ширина/высота и движение привязаны к сетке 12 dp — в 4 раза мельче иконки 48 dp. Ограничение ширины при смене окна также учитывает сетку. Неподдерживаемые направления resizeMode остаются фиксированными; если узкий диапазон провайдера не содержит точки сетки, его ограничения имеют приоритет.
- Виджет остаётся внутри своей колонки и области над панелью редактора. Уменьшите ширину, чтобы освободить место для движения по горизонтали. При расширении горизонтальный отступ ограничивается, чтобы виджет не вышел за колонку.
- Положение сохраняется сразу вместе с размером и переживает перезапуск, перенос между главным экраном и страницей виджетов, поворот и импорт backup. Старые записи из двух/трёх полей читаются с нулевым горизонтальным отступом; локальные widget IDs и параметры по-прежнему не экспортируются. Новое поле проверяется до атомарного импорта.
- Стрелки клавиатуры и четыре именованных accessibility-действия перемещают область виджета; маркеры продолжают менять размер. Отмена жеста восстанавливает размер и оба отступа. «Сбросить размер и положение» в меню возвращает исходную геометрию. Done, внешний tap, Back/HOME и lifecycle сохраняют прежнее поведение завершения.

## Проверки

`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug` — успешно: 13 unit-тестов; lint — 0 ошибок, 27 существующих предупреждений, новых нет. Проверены fine-grid snapping, узкие ограничения провайдера, границы движения, размер перемещённого виджета и legacy/атомарный импорт горизонтального отступа.

## APK и ограничения

Подписанный release APK с R8 и удалением неиспользуемых ресурсов собирается из чистого main, уже опубликованного в origin/main; публикуются APK и SHA256SUMS.txt. Используется прежний сертификат для совместимого обновления. Production-сертификат и магазин не настроены. Проверка физических устройств/OEM, рабочих профилей и TalkBack целиком остаётся вне подтверждённого покрытия. Полный паритет Niagara не заявляется.
