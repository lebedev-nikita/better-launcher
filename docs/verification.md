# Проверка 0.1.0

Основная платформа: выделенный Android Emulator `BetterLauncher_API_36`, Android 16 / API 36, образ Google APIs arm64-v8a, профиль Pixel 7. Дополнительно проверена минимальная версия Android 12 / API 31 на `BetterLauncher_API_31` с тем же профилем и Google APIs arm64-v8a. Проверка на физическом телефоне ещё не выполнена.

## Сборка и автоматические проверки

- `:app:assembleDebug` — успешно.
- `:app:testDebugUnitTest` — 3 теста, 0 ошибок: поиск, группировка латиницы и кириллицы, изменение порядка избранного.
- `:app:connectedDebugAndroidTest` — 3 теста, 0 ошибок: сохранение папок и настроек, резервная копия, атомарное отклонение повреждённого файла, настоящий каталог приложений, переименование и скрытие.
- `:app:lintDebug` — 0 ошибок, 35 предупреждений. Основные предупреждения относятся к устаревшим API совместимости, созданию небольших объектов в Canvas, версиям инструментов и стандартным View touch listeners. Отчёт генерируется в `app/build/reports/lint-results-debug.html`.

## Проверка UI через adb

`python3 scripts/smoke-test.py --serial emulator-5580`:

1. Кнопка настроек открывает настройки; системная кнопка «Назад» возвращает домой.
2. Поиск `camera` оставляет Camera и убирает Phone из результатов.
3. Нажатие действительно запускает Camera; HOME возвращает в Better Launcher.
4. Горизонтальный свайп по Phone открывает меню приложения.
5. Долгое нажатие показывает переименование и скрытие приложения.
6. Вертикальное движение по алфавиту открывает список приложений и выбирает раздел.
7. В AndroidRuntime logcat после проверок нет аварий процесса Better Launcher.

Все шесть сценариев и проверка отсутствия аварий также прошли на Android 12. Скрипт учитывает разные названия поля активного приложения в `dumpsys` Android 12 и Android 16.

Край системного жеста «Назад» сохранён. Буквы расположены в 32 dp от края экрана; полоса касания имеет ширину 48 dp.

Дополнительно проверены реальные системные интеграции на этом же эмуляторе:

- тестовый SMS появился в настоящем Messages и в предпросмотре на главном экране;
- меню уведомления показывает действия Messages; Reply открывает нативное поле ответа, отправка не выполнялась;
- скрытие уведомления удаляет его предпросмотр после закрытия меню;
- виджет Digital из системных часов добавлен через разрешение Android, настроен во внешнем экране Clock, показан через AppWidgetHost и затем удалён.

## Визуальная проверка

Скриншоты получены непосредственно из эмулятора, без браузерного макета:

- обычный телефон 1080×2400, плотность 420 dpi;
- узкий телефон 945×2100, плотность 420 dpi, системный масштаб шрифта 1.3;
- горизонтальный телефон 2400×1080;
- главный экран, список приложений, настройки.

Файлы находятся в `.impeccable/review/` и не добавляются в git. После проверки масштаб и поворот восстановлены.

Независимое ревью исправлений завершено с `disposition: ship`: все пять замечаний признаны исправленными — пересечение списка с нижними кнопками, прозрачность встроенных обоев, контраст вторичного текста, переключатели Material 3 и ширина касания алфавита. Расчётная нижняя граница контраста вторичного текста для встроенных обоев и белых системных обоев составляет 4.60:1 при обоих состояниях затемнения. Этот вердикт относится к пяти исправлениям; точное визуальное совпадение с Niagara и полный функциональный паритет не подтверждены.

## Границы проверки

Связка LauncherApps и настройки проверены на эмуляторе. Отправка через Direct reply, разные музыкальные приложения, рабочие профили, календарные провайдеры, запросы погоды и сторонние виджеты требуют отдельной проверки с соответствующими данными и приложениями. UI не содержит фиктивных уведомлений, погоды или событий.

Debug APK подписан локальным отладочным ключом; `apksigner verify` подтверждает подпись v2. Готовая копия: `artifacts/better-launcher-debug.apk`. Production-подпись и публикация не настроены. На Android 13–15 код проверен по уровню API и lint, но на устройствах этих версий ещё не запускался.
