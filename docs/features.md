# Возможности Better Launcher

Релиз-кандидат 0.2.0-rc.59 — рабочая начальная реализация основных сценариев Niagara, а не полный функциональный паритет.

| Область | Реализовано | Осталось для полного паритета |
| --- | --- | --- |
| Главный экран | Вертикальное избранное, настоящие значки приложений; время — в статус-баре Android; алфавит с крупными буквами только разделов с видимыми приложениями, включая #; скрытие последнего приложения сразу убирает букву, отмена возвращает её; без нижних кнопок и резерва 66 dp, вся безопасная высота доступна избранному; указатель прижат вниз с отступом 24 dp над системной навигацией, footer появляется только при перестановке | Полная настройка геометрии |
| Приложения | HOME role, запуск, латинский алфавит с волной без повторной навигации внутри буквы, одинаковый тактильный тик при смене раздела и отпускании пальца, группировка кириллицы через Android ICU, последний заполненный раздел при отпускании ниже букв (включая «#», когда он непустой), список с переиспользованием строк, подготовленный поиск со строкой на всю доступную ширину независимо от стороны алфавита, включая скрытые приложения по непустому запросу и возврат через «Показывать снова» в меню удержания, рабочие профили через LauncherApps | Отдельная проверка рабочих профилей и Private Space на физических устройствах |
| Избранное | Выбор, вход в перестановку через меню удержания без дублирующей кнопки под избранным, перетаскивание приложений и папок, единственная ручка на уровне названия, клавиши и accessibility-действия на ручке, перестановка прямо на главном экране без отдельного окна, автосохранение порядка, переименование, скрытие с отменой | — |
| Папки | Создание, название, выбор приложений, открытие без вложенных папок | Папки в общем списке и виджеты внутри папок |
| Меню приложения | Удержание иконки для быстрых действий и прикреплённых приложений без дублирующего пункта «Открыть …», удержание названия для управления ярлыком, свайп вправо к виджетам, прикреплённые приложения, динамические и manifest shortcuts со значками издателя (включая аватарки бесед, когда приложение их передаёт), со стрелкой при отсутствии значка; меню удержания с плавным подъёмом снизу, переименованием по нажатию на заголовок, значками действий, плоским списком избранного/порядка, скрытия, удаления и сведений в этом порядке без «Дополнительно» и переходом в настройки под разделителем; уведомления и выбор прикреплённых приложений доступны в меню иконки | Прикрепление shortcuts на главный экран через системный pin-request |
| Уведомления | Предпросмотр, открытие, скрытие, действия, ответ через RemoteInput | Все варианты отображения медиа, разговоров и OEM-уведомлений |
| Виджеты | Одно тональное поле поиска с лупой и очисткой непустого запроса без дублирующего заголовка/кнопки закрытия; поиск по названию виджета и приложения, превью провайдера и алфавит результатов справа при выборе; AppWidgetHost с исправленной загрузкой сторонних виджетов, системная привязка и конфигурация, один центрированный виджет сразу под статус-баром без верхнего отступа с отдельной областью и растягиванием на всю ширину, отдельный экран слева по свайпу на всю безопасную высоту без заголовка, панелей и кнопок, добавление удержанием пустого места с keyboard/accessibility-альтернативами, перестановка работающих виджетов прямо на их странице без непрозрачной подложки при перетаскивании через единственную ручку ≡ с keyboard/accessibility-действиями и автосохранением, меню по удержанию без подписей над виджетами, перемещение за содержимое и изменение ширины/высоты четырьмя границами с шагом 12 dp и системным CLOCK_TICK на Android 12+ на каждом изменении размера прямо на виджете, автосохранение и клавиатурные/accessibility-действия в пределах возможностей провайдера, повторная конфигурация, назначение виджета со страницы на главный экран и удаление; меню без «О приложении», «Добавить виджет», сброса размера/положения и переноса с главного экрана, иконка перемещения с четырьмя стрелками | Виджеты во всплывающих меню |
| Погода | Поиск города, температура и состояние, повтор загрузки, Open-Meteo | Почасовой прогноз, автоматическая геолокация, расширенное оформление виджета |
| Календарь | Ближайшие 12 событий за 7 дней, открытие события в календаре | События непосредственно на главном экране, выбор отдельных календарей |
| Музыка | Название, исполнитель, play/pause, следующий трек через MediaSession | Все музыкальные приложения, обложки и дополнительные действия |
| Оформление | Системные обои с прямым переходом к их выбору, затемнение 0–100% с автосохранением, встроенные шрифты, размер текста, плотность, значки, сторона алфавита, единый отступ между виджетами и перед избранным 0–32 dp (по умолчанию 8 dp) с живым предпросмотром в настройках; без дополнительных вертикальных отступов контейнера Android | Сторонние icon packs, пользовательские шрифты, изменение отдельных значков |
| Настройки | Единый тёмно-синий стиль меню/редакторов с голубыми подписями и контурными значками; фон настроек покрывает также статус-бар и системную навигацию; автосохранение и JSON-резервная копия; повреждённый файл не затирает данные | Миграции будущих версий резервной копии |
| Всплывающие сообщения | Закрытие свайпом в обе стороны, максимум три секунды даже при удержании, рабочая отмена, замена предыдущего сообщения, клавиатура/accessibility и system/IME insets | — |
| Дополнительно | Системная кнопка «Назад», поиск по свайпу вверх на пустом месте и клавише Search, настройки по удержанию/Menu/Shift+F10, именованные accessibility-действия поиска/виджетов/настроек и алфавита | Настраиваемая Niagara Button, Usage Breaker и полная проверка TalkBack |

Текущее покрытие таблицы соответствует релиз-кандидату 0.2.0-rc.59. Все меню используют общие оформление и анимацию меню долгого удержания ярлыка. Исправление загрузки виджетов и существующие IDs/размещение сохраняются.

Главный экран использует только установленные приложения. Сеть нужна только для выбранного пользователем города и прогноза. Платежей, рекламы, серверной регистрации и демонстрационных сообщений в основном APK нет.

История превью виджетов — в [0.1.9](releases/0.1.9.md). Исправление нижней границы алфавита сохранено из [0.1.8](releases/0.1.8.md). Исторические результаты 0.1.7 сохранены в [его отчёте](releases/0.1.7.md). Поддержка планшетов, всех OEM, Android Go и все специальные возможности ещё не подтверждены на устройствах. Публикуется оптимизированный release APK с прежним сертификатом для совместимости обновлений; debug APK используются локально. Выпуск в магазине и переход на отдельный production-сертификат не настроены.
