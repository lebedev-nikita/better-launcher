# Better Launcher features

Stable release 0.3.0 is a working initial implementation of Niagara's core workflows, with English and Russian UI. It does not claim full functional parity.

| Area | Implemented | Remaining for full parity |
| --- | --- | --- |
| Home screen | Vertical favorites with real app icons; time in Android's status bar; large alphabet letters only for populated sections, including #; hiding the last app removes its letter and undo restores it; full inset-safe height without bottom buttons or the former 66 dp reserve; alphabet aligned 24 dp above system navigation; footer only while reordering | Full geometry customization |
| Apps | HOME role, launch, Latin wave alphabet without repeated navigation within a section, identical haptic tick on section changes/release, Cyrillic grouping through Android ICU, final populated section when released below the letters, recycled app rows, prepared full-width search on either alphabet side, hidden apps searchable by nonempty query and restored through Show again, LauncherApps work profiles | Separate physical-device verification of work profiles and Private Space |
| Favorites | App selection; enter reorder through the hold menu without a duplicate button; drag apps/folders in place using one handle on the title line; keyboard/accessibility reorder actions; automatic order saving; rename; hide with undo | — |
| Folders | Creation, naming, app selection and opening without nested folders | Folders in the all-app list and widgets inside folders |
| App menus | Icon hold for quick actions/attached apps without a redundant owner Open action; name hold for management; right swipe to widgets; dynamic/manifest shortcuts with publisher icons/avatars or arrow fallback; trailing cross hides shortcuts, undo-last and restore-all; persistence by app/profile/shortcut ID with portable backup; animated bottom sheets, title-to-rename, flat favorites/reorder/hide/uninstall/info commands, settings below a divider; notifications and attached-app selection in the icon menu | System pin requests for placing shortcuts on home |
| Notifications | Preview, open, dismiss, actions and RemoteInput reply | All media, conversation and OEM display variants |
| Widgets | One tonal search field with magnifier and conditional clear button; widget/app-name search, provider previews and a right result alphabet; AppWidgetHost with external-widget inflation, Android binding/configuration; one centered full-width-capable home widget directly below the status bar; inset-safe left page without titles/buttons; add through empty-space hold with keyboard/accessibility alternatives; live in-place reordering with one ≡ handle, automatic saving and transparent dragged content; hold menu; content dragging plus four resize edges on a 12 dp grid with CLOCK_TICK for each applied size change; keyboard/accessibility geometry controls within provider bounds; reconfiguration, placement on home and removal; menu omits app info, add-widget, reset and home-to-page transfer actions | Widgets inside app pop-ups |
| Weather | City search, temperature/condition, retry and Open-Meteo | Hourly forecast, automatic location and richer weather-widget styling |
| Calendar | Up to 12 events over seven days; open the event in a calendar app | Events directly on home and selection of individual calendars |
| Music | Title/artist, play/pause and next through MediaSession | All music apps, artwork and additional actions |
| Appearance | System wallpaper picker, immediate 0–100% dimming, built-in fonts, text size, density, icons, alphabet side; one 0–32 dp gap between widgets/before favorites (default 8 dp) with a stable live preview; no extra container-top padding | Third-party icon packs, custom fonts and individual-icon replacement |
| Settings | Shared navy/pale blue menu/editor style; background under both system bars; automatic saving and JSON backup; invalid imports preserve data | Future backup-format migrations |
| Feedback | Dismiss by swiping either way, at most three seconds even while held, working undo, replacement by newer messages, keyboard/accessibility and system/IME insets | — |
| Languages | Complete English/Russian app-owned UI, English fallback, Android 13+ per-app language declaration, localized plural forms, calendar date/time formatting, weather labels and city-search language | Additional languages, locale-specific alphabets and complete RTL verification |
| Other | System Back; empty-space swipe-up/Search-key search; hold/Menu/Shift+F10 settings; named accessibility actions for search/widgets/settings/alphabet | Custom Niagara Button, Usage Breaker and full TalkBack verification |

The table reflects stable release 0.3.0. All menus share the app long-press menu's styling and animation. Existing widget IDs, placement and the external-widget loading fix are preserved. Installed apps and system data supply home content. Network access is used only for the selected city and forecast. The main APK has no payments, advertising, server registration or demonstration messages.

Current results and limitations are in [0.3.0](releases/0.3.0.md). Historical reports retain their original verification scope: [0.2.0](releases/0.2.0.md), [shortcut hiding in rc.60](releases/0.2.0-rc.60.md), [combined candidate rc.21](releases/0.2.0-rc.21.md), [widget previews in 0.1.9](releases/0.1.9.md), [alphabet lower bound in 0.1.8](releases/0.1.8.md) and [0.1.7](releases/0.1.7.md). Tablets, all OEMs, Android Go and all accessibility features remain unverified on devices. Published release APKs are optimized and signed with the previous certificate for update compatibility; debug APKs are for verification. Store distribution and migration to a separate production certificate are not configured.

Menu/four-edge-editor history is recorded in [rc.22](releases/0.2.0-rc.22.md); movement/grid and home width in [rc.26](releases/0.2.0-rc.26.md); alphabet-release haptics in [rc.23](releases/0.2.0-rc.23.md); in-place reordering in [rc.31](releases/0.2.0-rc.31.md); zero top reserve in [rc.29](releases/0.2.0-rc.29.md); soft resize feedback in [rc.27](releases/0.2.0-rc.27.md); CLOCK_TICK/amplitude limits in [rc.30](releases/0.2.0-rc.30.md); title-line handles in [rc.34](releases/0.2.0-rc.34.md); duplicate reorder-button removal in [rc.35](releases/0.2.0-rc.35.md); transparent favorite dragging in [rc.36](releases/0.2.0-rc.36.md); hidden-app search in [rc.39](releases/0.2.0-rc.39.md); and widget-menu cleanup in [rc.40](releases/0.2.0-rc.40.md).
