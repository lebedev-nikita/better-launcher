# Возможности первой версии

Версия 0.1.0 — рабочая начальная реализация основных сценариев Niagara, а не полный функциональный паритет.

| Область | Реализовано | Осталось для полного паритета |
| --- | --- | --- |
| Главный экран | Часы, дата, вертикальное избранное, настоящие значки приложений | Полная настройка геометрии и всех вариантов часов |
| Приложения | HOME role, запуск, алфавит с волной, поиск, рабочие профили через LauncherApps | Отдельная проверка рабочих профилей и Private Space на физических устройствах |
| Избранное | Выбор, порядок, переименование, скрытие с отменой | Перетаскивание порядка пальцем |
| Папки | Создание, название, выбор приложений, открытие без вложенных папок | Папки в общем списке и виджеты внутри папок |
| Меню приложения | Свайп, прикреплённые приложения, динамические и manifest shortcuts | Прикрепление shortcuts на главный экран через системный pin-request |
| Уведомления | Предпросмотр, открытие, скрытие, действия, ответ через RemoteInput | Все варианты отображения медиа, разговоров и OEM-уведомлений |
| Виджеты | AppWidgetHost, системная привязка и конфигурация, стопка до 4, переключение и удаление | Свободное изменение размеров, виджеты во всплывающих меню |
| Погода | Поиск города, температура и состояние, повтор загрузки, Open-Meteo | Почасовой прогноз, автоматическая геолокация, расширенное оформление виджета |
| Календарь | Ближайшие 12 событий за 7 дней, открытие события в календаре | События непосредственно под часами, выбор отдельных календарей |
| Музыка | Название, исполнитель, play/pause, следующий трек через MediaSession | Все музыкальные приложения, обложки и дополнительные действия |
| Оформление | Системные обои с прямым переходом к их выбору, затемнение для читаемости, встроенные шрифты, размер текста, плотность, значки, сторона алфавита | Сторонние icon packs, пользовательские шрифты, изменение отдельных значков |
| Настройки | Автосохранение и JSON-резервная копия; повреждённый файл не затирает данные | Миграции будущих версий резервной копии |
| Дополнительно | Системная кнопка «Назад», поиск с клавиатурой, accessibility-действия алфавита | Настраиваемая Niagara Button, Usage Breaker и полная проверка TalkBack |

Главный экран использует только установленные приложения. Сеть нужна только для выбранного пользователем города и прогноза. Платежей, рекламы, серверной регистрации и демонстрационных сообщений в основном APK нет.

Основные сценарии проверены на телефонных эмуляторах Android 12 и Android 16. Поддержка планшетов, всех OEM, Android Go и все специальные возможности ещё не подтверждены на устройствах. Debug APK предназначен для локального тестирования; выпуск в магазине и production-подпись не настроены.
