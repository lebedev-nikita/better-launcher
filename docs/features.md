# Возможности Better Launcher

Релиз-кандидат 0.2.0-rc.13 (стабильный выпуск — 0.1.9) — рабочая начальная реализация основных сценариев Niagara, а не полный функциональный паритет.

| Область | Реализовано | Осталось для полного паритета |
| --- | --- | --- |
| Главный экран | Вертикальное избранное, настоящие значки приложений; время — в статус-баре Android; компактный алфавит внизу резервирует место footer и системных insets | Полная настройка геометрии |
| Приложения | HOME role, запуск, латинский алфавит только с непустыми разделами, с волной без повторной навигации внутри буквы, группировка кириллицы через Android ICU, заключительный «#» при наличии приложений, отпускание ниже букв сохраняет последний раздел, список с переиспользованием строк, подготовленный поиск, рабочие профили через LauncherApps | Отдельная проверка рабочих профилей и Private Space на физических устройствах |
| Избранное | Выбор, порядок, переименование с кнопкой сохранения справа, скрытие с отменой | Перетаскивание порядка пальцем |
| Папки | Создание, название, выбор приложений, открытие без вложенных папок | Папки в общем списке и виджеты внутри папок |
| Меню приложения | Свайп, прикреплённые приложения, динамические и manifest shortcuts; меню удержания с анимацией снизу, переименованием по заголовку, значками действий, разделом «Дополнительно» и переходом в настройки | Прикрепление shortcuts на главный экран через системный pin-request |
| Уведомления | Предпросмотр, открытие, скрытие, действия, ответ через RemoteInput | Все варианты отображения медиа, разговоров и OEM-уведомлений |
| Виджеты | Превью провайдера и алфавит справа при выборе; AppWidgetHost, системная привязка и конфигурация, один виджет на главном, отдельный экран слева по свайпу, перенос между экранами и удаление | Свободное изменение размеров, виджеты во всплывающих меню |
| Погода | Поиск города, температура и состояние, повтор загрузки, Open-Meteo | Почасовой прогноз, автоматическая геолокация, расширенное оформление виджета |
| Календарь | Ближайшие 12 событий за 7 дней, открытие события в календаре | События непосредственно на главном экране, выбор отдельных календарей |
| Музыка | Название, исполнитель, play/pause, следующий трек через MediaSession | Все музыкальные приложения, обложки и дополнительные действия |
| Оформление | Системные обои с прямым переходом к их выбору, затемнение 0–100% с автосохранением, встроенные шрифты, размер текста, плотность, значки, сторона алфавита | Сторонние icon packs, пользовательские шрифты, изменение отдельных значков |
| Настройки | Автосохранение и JSON-резервная копия; повреждённый файл не затирает данные | Миграции будущих версий резервной копии |
| Дополнительно | Системная кнопка «Назад», поиск с клавиатурой, accessibility-действия алфавита | Настраиваемая Niagara Button, Usage Breaker и полная проверка TalkBack |

Таблица отражает релиз-кандидат 0.2.0-rc.13 после rebase на main. Его проверки и ограничения описаны в [release notes](releases/0.2.0-rc.13.md).

Главный экран использует только установленные приложения. Сеть нужна только для выбранного пользователем города и прогноза. Платежей, рекламы, серверной регистрации и демонстрационных сообщений в основном APK нет.

Проверки патча 0.1.9 и ограничения записаны в [release notes](releases/0.1.9.md). Исправление нижней границы алфавита сохранено из [0.1.8](releases/0.1.8.md). Исторические результаты 0.1.7 сохранены в [его отчёте](releases/0.1.7.md). Поддержка планшетов, всех OEM, Android Go и все специальные возможности ещё не подтверждены на устройствах. Публикуется оптимизированный release APK с прежним сертификатом для совместимости обновлений; debug APK используются локально. Выпуск в магазине и переход на отдельный production-сертификат не настроены.
