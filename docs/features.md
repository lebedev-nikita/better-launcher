# Возможности Better Launcher

Релиз-кандидат 0.2.0-rc.2 — рабочая начальная реализация основных сценариев Niagara, а не полный функциональный паритет.

| Область | Реализовано | Осталось для полного паритета |
| --- | --- | --- |
| Главный экран | Вертикальное избранное, настоящие значки приложений; время — в статус-баре Android; поиск слева внизу и настройки справа без подписи, симметричные области нажатия; виджеты по центру; алфавит над footer с учётом системных insets | Полная настройка геометрии |
| Приложения | HOME role, запуск, латинский алфавит с волной без повторной навигации внутри буквы, группировка кириллицы через ICU4J, заключительный «#», список с переиспользованием строк, подготовленный поиск, рабочие профили через LauncherApps | Отдельная проверка рабочих профилей и Private Space на физических устройствах |
| Избранное | Выбор, порядок, переименование, скрытие с отменой | Перетаскивание порядка пальцем |
| Папки | Создание, название, выбор приложений, открытие без вложенных папок | Папки в общем списке и виджеты внутри папок |
| Меню приложения | Свайп, прикреплённые приложения, динамические и manifest shortcuts; меню удержания со значками действий, разделом «Дополнительно» и переходом в настройки | Прикрепление shortcuts на главный экран через системный pin-request |
| Уведомления | Предпросмотр, открытие, скрытие, действия, ответ через RemoteInput | Все варианты отображения медиа, разговоров и OEM-уведомлений |
| Виджеты | AppWidgetHost, системная привязка и конфигурация, один виджет на главном, отдельный экран слева по свайпу, перенос между экранами и удаление | Свободное изменение размеров, виджеты во всплывающих меню |
| Погода | Поиск города, температура и состояние, повтор загрузки, Open-Meteo | Почасовой прогноз, автоматическая геолокация, расширенное оформление виджета |
| Календарь | Ближайшие 12 событий за 7 дней, открытие события в календаре | События непосредственно на главном экране, выбор отдельных календарей |
| Музыка | Название, исполнитель, play/pause, следующий трек через MediaSession | Все музыкальные приложения, обложки и дополнительные действия |
| Оформление | Системные обои с прямым переходом к их выбору, затемнение 0–100% с автосохранением, встроенные шрифты, размер текста, плотность, значки, сторона алфавита | Сторонние icon packs, пользовательские шрифты, изменение отдельных значков |
| Настройки | Автосохранение и JSON-резервная копия; повреждённый файл не затирает данные | Миграции будущих версий резервной копии |
| Дополнительно | Системная кнопка «Назад», поиск с клавиатурой, accessibility-действия алфавита | Настраиваемая Niagara Button, Usage Breaker и полная проверка TalkBack |

Текущее покрытие таблицы соответствует выпуску 0.1.5.

Главный экран использует только установленные приложения. Сеть нужна только для выбранного пользователем города и прогноза. Платежей, рекламы, серверной регистрации и демонстрационных сообщений в основном APK нет.

Основные сценарии прежних выпусков проверены на телефонных эмуляторах Android 12 и Android 16. Меню 0.1.5 проверено на Android 12; текущий Android 16 UI-прогон не завершён из-за системных сбоев эмулятора — см. [отчёт](app-menu-verification.md). Поддержка планшетов, всех OEM, Android Go и все специальные возможности ещё не подтверждены на устройствах. Debug APK предназначен для локального тестирования; выпуск в магазине и production-подпись не настроены.
